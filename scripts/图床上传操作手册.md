# 图床上传操作手册

将 `_posts/` 下 markdown 文件中的本地图片上传至阿里云 OSS 图床并替换路径。

## 前置条件

```bash
pip install oss2
```

## 一步完成（推荐）

将所有未上传的本地图片一键上传并替换路径：

```bash
cd /path/to/lixiongguo.github.io
python3 scripts/upload_and_replace.py
```

脚本自动完成：扫描 `_posts/` 中所有本地图片 → 上传到 OSS → 替换 .md 中的本地路径为 OSS URL。

## 分步操作

### 1. 扫描本地图片引用

```bash
python3 scripts/replace_imgs_to_oss.py --dry-run
```

输出内容包括：
- 每个文件有几处本地图片引用
- 涉及哪些唯一图片
- 生成上传清单 `scripts/oss_upload_manifest.txt`

### 2. 上传图片到 OSS

```bash
export OSS_ACCESS_KEY_ID="your-access-key-id"
export OSS_ACCESS_KEY_SECRET="your-access-key-secret"
python3 scripts/upload_to_oss.py
```

### 3. 替换 .md 文件中的路径

```bash
python3 scripts/replace_imgs_to_oss.py
```

## 手动上传单张图片

```python
import oss2

AK = os.environ['OSS_ACCESS_KEY_ID']
SK = os.environ['OSS_ACCESS_KEY_SECRET']
auth = oss2.Auth(AK, SK)
bucket = oss2.Bucket(auth, 'https://oss-cn-beijing.aliyuncs.com', 'lgximgs')

filename = 'image-xxx.png'
bucket.put_object_from_file(
    f'images/{filename}',
    f'imgs/{filename}',
    headers={'Content-Type': 'image/png'}
)
```

## OSS 信息

| 项目 | 值 |
|------|-----|
| Bucket | `lgximgs` |
| Endpoint | `oss-cn-beijing.aliyuncs.com` |
| 图片 URL 前缀 | `https://lgximgs.oss-cn-beijing.aliyuncs.com/images/` |
| 图片本地目录 | `imgs/` |

## 脚本说明

| 脚本 | 功能 |
|------|------|
| `upload_and_replace.py` | 一体脚本：扫描 + 上传 + 替换 |
| `replace_imgs_to_oss.py` | 扫描 md 文件并替换本地路径为 OSS URL |
| `upload_to_oss.py` | 根据清单 `oss_upload_manifest.txt` 上传图片 |
| `oss_credentials.md` | 凭证文件（已加入 .gitignore，勿提交） |
| `oss_upload_manifest.txt` | 待上传图片清单（由 replace 脚本自动生成） |
