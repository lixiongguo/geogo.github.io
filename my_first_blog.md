# How to Index MD Files with Jekyll

This guide explains how to properly index and process Markdown files using Jekyll.

## Key Points

- Place your `.md` files in the appropriate directories.
- Use the correct file naming convention for posts.
- Include necessary front matter at the top of each file.
- Write your content in Markdown format below the front matter.
