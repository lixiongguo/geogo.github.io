最常见的输入就是估计出来的主曲率方向，但只要满足正交关系，也可以换成用户指定的其他方向。

预处理：先把输入方向场变得更适合参数化

PGP 的流程图中，首先提到了两个可选的预处理：

第一，向量场平滑

如果输入的是主曲率方向，那么在各向同性区域或者脐点附近，主方向会不稳定，因为这些地方本来就不存在唯一的“最大/最小”弯曲方向。 所以需要先做平滑，把这些区域处理成更稳定、更适合后续计算的方向场。

第二，curl correction

如果方向场本身带有比较强的旋度，那么它通常不能直接积分成全局参数函数，这会迫使参数化产生很多奇异点。 因此可以先对输入向量场做一次重标定或修正，尽量减少 curl，从而减少后面不可避免的奇异点数量。

第三，PGP 把平移和旋转自由度显式纳入优化变量。

直接优化 UV 容易被“绕了几圈”“平移了多少”这些自由度干扰，而改用三角函数形式的替代变量，会让优化形式更稳定。

2.6 PGP 的输出不是直接一张图，而是先得到 chart layout

PGP 的后处理大致分成几步：

  1. 先从优化结果中恢复每个三角形上的局部参数化。
  2. 然后检测这些局部参数化中出现的奇异点。
  3. 接着根据每个三角形的参数化去定义全局的 chart layout。
  4. 最后再对每个 chart 重新组装或重参数化，得到真正可用的 per-chart parameterization。

这里最值得注意的是第 3 步。
PGP 的思想并不是“一开始就知道 chart 怎么切”，而是先在每个三角形上求出局部参数，再从这些局部结果中反推出一张全局图块布局。
也就是说，chart layout 不是先验输入，而是参数化结果里长出来的结构。
