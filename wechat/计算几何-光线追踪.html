5. SIMD 与 GPU 并行化

5.1 SIMD（单指令多数据）

CPU 上的 SIMD（SSE/AVX）可以同时处理多条光线：

// AVX：同时处理 8 条光线
__m256 ox = {ray[0].ox, ray[1].ox, ..., ray[7].ox};  // 8 个 x 原点
__m256 oy = {ray[0].oy, ray[1].oy, ..., ray[7].oy};  // 8 个 y 原点
// 一条指令完成 8 条光线的 AABB 相交测试
__m256 tmin = AABB_Intersect_8(ox, oy, oz, dx, dy, dz, bmin, bmax);

Packet Tracing：将多条光线打包为一组，同时对 BVH 的一个节点进行相交测试。当多条光线访问相同的 BVH 节点时，可以共享内存访问，减少 cache miss。

5.2 GPU 并行化

GPU 拥有数千个计算核心，天然适合光线追踪的大规模并行——每个像素/每条路径可以独立计算。

挑战与优化：

挑战 原因 优化策略
分支分化 不同路径的递归深度不同 减少分支，使用 wave-wide 操作
内存访问 BVH 遍历的访问模式不可预测 节点线性存储，合并访存
栈管理 递归遍历需要栈 使用紧凑的短栈（Wavefront tracing）
构建 BVH GPU 上构建 BVH 较复杂 使用 LBVH / HLSBVH

5.3 现代 GPU 光追

2018 年 NVIDIA RTX 20 系列引入了硬件光线追踪（RT Cores）：

  • 专用 BVH 遍历单元：硬件加速射线-AABB 和射线-三角形相交测试
  • API 支持：DXR（DirectX Raytracing）、Vulkan Ray Tracing、OptiX
  • 性能：相比纯软件实现，BVH 遍历加速约 10 倍
现代实时光追管线：
  GPU Compute Shader / Ray Generation Shader
    → 发射光线（TraceRay）
      → RT Core: BVH 遍历 + 三角形求交（硬件加速）
        → Hit/Miss Shader: 着色计算
          → 可能继续发射新光线（递归）
