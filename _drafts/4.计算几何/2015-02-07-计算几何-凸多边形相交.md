## 介绍

我们在执行运算时，依照从左至右，从下到上的规则，好像有一条扫描线推遍整个相关平面区域，这样的计算方法，就称为扫线法。

应用扫描线方法计算线段组交点(另外了凹多边形之间的相交判断，当然也可以应用于顶点与凹凸包、线段与凹凸包、凸包与凸包之间的相交判断也是类似的)

扫线法的典型作用是降维，将原本的二维空间数据，转化为一位空间数据，这样可以大大提升计算效率。

算法步骤：一、数据结构的设计；二、事件定义与扫描规则

### 凹形相交



凹多边形之间相交判断 在可以扫线判断顶点的情况下，已经非常接近最后的结果，针对凹多边形之间的处理，我们稍微改变一下规则，即：

 1、在开始的排序过程中，我们将凹包C1与凹包C2的顶点一起纳入扫描列表执行排序

 2、在每个扫线阶段，如果遭遇的是C1中的顶点，则会将其与C2当前的扫线栈执行区域判断，如果在其中，则完成算法退出，如果不在，则将顶点用作C1堆栈的维护，如果遭遇C2的顶点，则会将其与C1当前的扫线栈执行区域判断，如果在其中，则完成算法退出，如果不在，则将顶点用作C2堆栈的维护。

### 梯形图（Trapezoidal Map）

梯形图是平面细分的一种特殊形式，特别适合处理**线段集合**（而非多边形面片）的点定位。

对线段集 $S$ 中的每条线段，从其两个端点向上和向下延伸垂直射线到无穷远（或到包围盒边界），将平面划分为若干梯形。

**梯形 $\Delta$ 的定义**：由两条（非垂直）线段的部分边作为上下边界，由垂直线段（延伸线）作为左右边界，围成的区域。

### 5.2 随机增量构造

```
function BuildTrapezoidalMap(segments S):
    // 用包围盒初始化
    R = BoundingBox(S)
    T = {R 内的 1 个梯形}  // 初始梯形就是整个包围盒
    D = DAG 节点 = {R}

    // 随机排列线段
    random_shuffle(S)

    for each segment s_i in S:
        // 找到 s_i 穿过的所有梯形
        trapezoids = FollowSegment(s_i, D)

        // 删除旧梯形，创建新梯形
        // s_i 将每个穿过的梯形最多分为 4 个新梯形
        (new_traps, new_nodes) = SplitTrapezoids(trapezoids, s_i)

        T = (T - trapezoids) ∪ new_traps
        UpdateDAG(D, trapezoids, new_traps, new_nodes)

    return T, D  // 梯形图 + 搜索 DAG
```
