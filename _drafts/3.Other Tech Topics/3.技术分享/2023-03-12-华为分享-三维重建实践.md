本文记录一套**已上线**的物体级三维重建管线：从多视角 RGB 采集，到稀疏重建、稠密深度、点云融合与纹理贴图，并辅以 AR 引导采集与材质编辑。整体基于 **OpenMVS + Colmap + CasMVSNet**，在传统几何管线上叠深度学习模块，兼顾精度、鲁棒性与线上时延。

```
多视角图像
    │
    ▼
┌─────────── 预处理 ───────────┐
│  前景分割 → 3D 包围盒估计     │
└──────────────┬───────────────┘
               ▼
        特征提取 / 匹配
        (SiftGPU → SuperGlue)
               ▼
        稀疏重建 (Colmap)
               ▼
        深度估计 (CasMVSNet)
               ▼
        点云融合 (CUDA)
               ▼
        网格 + 纹理
        (Poisson / 图割 / Inpainting)
               ▼
            上线资产
```

---

## 1. 预处理

线上场景里，用户往往在杂乱背景前拍摄。若不做预处理，背景特征会污染匹配与稀疏点，后续深度与融合也会被「远处平面」带偏。

### 1.1 前景分割

采用 **U²-Net**（或同类显著目标分割网络）对每张输入图做前景 mask：

| 作用 | 说明 |
|:---|:---|
| **特征过滤** | 只在 mask 内提点 / 匹配，减少背景误匹配 |
| **深度约束** | 深度网络或融合阶段用 mask 屏蔽无效区域 |
| **包围盒估计** | 为后续 3D bbox 提供 2D 投影线索 |

实践注意：

- mask 边缘宜略**膨胀**，避免裁掉物体轮廓上的可用特征；
- 半透明、反光、细杆（线缆、支架）容易漏检，可对低置信区域保留少量背景特征作兜底；
- 分割失败时降级为「全图重建」，但成功率与点云干净程度会明显下降。

### 1.2 3D 包围盒估计

在得到多视角 mask 与初始位姿后，估计物体在世界系下的 **轴对齐 / 定向包围盒**：

1. 将各视角 mask 轮廓反投影为视锥；
2. 在公共体积内做投票或凸包求交，得到粗 bbox；
3. 用稀疏点云再 refine（剔除 bbox 外离群点）。

用途：

- **裁剪计算域**：MVS / 融合只在 bbox 内做，降显存与耗时；
- **尺度与摆放**：给 AR 预览、导出到引擎时提供合理默认尺寸与地面对齐；
- **质量门控**：点云若大量落在 bbox 外，判定采集失败并提示续扫。

## 2. 主 Pipeline

### 2.1 特征点提取与匹配

#### SiftGPU

线上主路径仍用 **SiftGPU**：成熟、可复现，GPU 上提点与描述子足够快，与 Colmap 生态兼容好。

典型流程：

```
图像 → SiftGPU 提点 → 暴力 / FLANN 匹配 → 比率测试 + RANSAC
     → 两视图几何 → 增量式加入 Colmap
```

局限：大视角差、弱纹理、运动模糊时匹配率骤降；旋转 / 尺度虽有一定不变性，但对「绕物体转半圈再对齐」仍吃力。

#### 未来方向：AI 特征与 SuperGlue

为支持更大角度的位姿变化，规划引入学习型特征：

| 模块 | 角色 |
|:---|:---|
| **SuperPoint / DISK 等** | 可重复关键点 + 描述子 |
| **SuperGlue** | 基于注意力的匹配，显式建模几何一致性 |

**SuperGlue** 要点：

- 输入两侧关键点坐标与描述子，用 **自注意力** 建模同图内结构，用 **交叉注意力** 做跨图匹配；
- 输出软匹配矩阵，再配合最优传输（Sinkhorn）得到一对一匹配；
- 对视角变化、重复纹理比传统最近邻 + 比率测试更稳，适合「用户绕物体随意拍」的线上场景。

工程上可做成 **双路径**：默认 SiftGPU；匹配不足或大基线时切换 / 融合 SuperGlue，再把匹配喂给 Colmap。

#### 增量补充与云端并行

完整重建不必等用户拍完再一次性跑：

1. 前端边拍边上传；
2. 云端对已到齐的图像做**增量 SfM**（新图对已有模型做定位与三角化）；
3. 算力池对多任务 / 多 tile **高并行**调度（特征、匹配、深度推理可拆批）。

好处：缩短首包反馈时间，方便「先出稀疏预览 → 引导用户补拍空洞视角」。

### 2.2 稀疏重建：Colmap

**Colmap** 负责相机内参（可选）、外参与稀疏点云：

| 阶段 | 内容 |
|:---|:---|
| **增量重建** | 选初始像对 → PnP + 三角化 → 局部 BA → 全局 BA |
| **位姿图** | 处理闭环与漂移，保证环绕拍摄后模型闭合 |
| **输出** | 相机矩阵、稀疏点、可选畸变模型 |

实践经验：

- **先验内参**：手机 / 固定镜头可用 EXIF 或标定表作初值，减少尺度与焦距耦合；
- **前景 mask**：提点阶段过滤背景，稀疏点更「贴物体」；
- **失败诊断**：匹配图连通性不足 → 提示补拍重叠；重投影误差过大 → 提示减少运动模糊 / 过曝。

稀疏结果是后续深度网络与融合的「骨架」：位姿错了，后面全错。

### 2.3 深度图：CasMVSNet

稠密阶段用 **Cascade MVSNet（CasMVSNet）** 估计每视角深度图。

相对传统 PatchMatch / SGM：

| | 传统 MVS | CasMVSNet |
|:---|:---|:---|
| **匹配线索** | 手工相似度（NCC 等） | CNN 特征代价体 |
| **弱纹理** | 易失败或糊成一片 | 金字塔 / 级联从粗到细补全 |
| **速度** | CPU 或简单 GPU | 端到端 GPU 推理，易上线 |

**级联与金字塔**：粗层在低分辨率、大深度范围上估计；细层缩小假设范围、提高分辨率。弱纹理区域在粗层被「大感受野」学成平滑合理的深度，再在细层恢复边界。

我们侧的改动（与产线 / 线上场景相关）：

- 特征 backbone 改为 **多尺度级联 U-Net**，增强缺纹理区域匹配；
- **NAS** 搜轻量化结构，精度达标前提下推理约 **+35%**；
- 深度输出与 mask、bbox 联合，减少背景深度泄漏。

### 2.4 点云融合

多视角深度含噪声、冲突与飞点，需融合成一致点云 / 截断符号距离，再提网格。

| 步骤 | 说明 |
|:---|:---|
| **一致性检验** | 投影到邻域视角，深度差超阈值则丢弃 |
| **加权融合** | 按视角夹角、梯度、置信度加权 |
| **离群剔除** | 统计滤波 / 半径滤波 |

**GPU 加速**：自研 **CUDA Kernel** 做高精度融合与相关后处理，将单帧相关耗时从约 **8s → 5s** 量级，满足线上吞吐。网格化侧常用 **Poisson** 重建得到封闭流形，再可选简化与补洞。

### 2.5 纹理重建

几何就绪后做贴图，目标是「接缝少、颜色一致、遮挡处可补」：

```
网格 + 多视角图像 + 相机位姿
        │
        ▼
  视角选择 / 图割（MRF）
        │
        ▼
  接缝融合 + 颜色校正
        │
        ▼
  遮挡 / 空洞 Inpainting
        │
        ▼
     UV 纹理图
```

| 技术 | 作用 |
|:---|:---|
| **图割（Graph Cut）** | 为每个面片选最优视角，最小化接缝代价（颜色差 + 梯度差） |
| **Inpainting** | 看不见的背面、高光烧掉的区域做纹理补全 |
| **Poisson（编辑）** | 接缝处做梯度域融合，减轻色块感 |

贴图质量高度依赖采集：重叠不足、曝光不均会直接变成接缝。因此辅助采集与材质编辑同样关键。

## 3. 辅助技术

### 3.1 AR 引导与交互式续扫

纯被动拍摄成功率不稳定。线上提供 **AR / OpenGL 预览**：

- 实时显示已覆盖视角（如球体上的已采样点）；
- 标出稀疏/深度置信度低的区域，引导用户补拍；
- 交互式**续扫**：新图增量进 SfM，再局部更新深度与纹理，无需全量重跑。

效果：重建成功率明显提升，也降低「拍完才发现缺面」的客诉。

### 3.2 交互式材质编辑

重建默认贴图偏「照片贴皮」。对电商 / 展示场景，提供轻量编辑：

- 调 albedo / 粗糙度等（走 PBR 参数更利于引擎）；
- 局部重投影换贴图、去高光；
- 简单分割后分区赋材质。

几何不动、只改外观时，用户可快速出可上架资产。

## 4. 新技术跟踪

传统 mesh + 纹理管线仍是上线主力（兼容引擎、可编辑、体积可控）。同时跟踪神经表示为后续能力预研。

### 4.1 NeRF

**NeRF** 用 MLP（或哈希网格等加速结构）表示场景辐射场，沿射线积分做可微体渲染：

| 组成 | 含义 |
|:---|:---|
| **场景表示** | $(\mathbf{x}, \mathbf{d}) \rightarrow (\mathbf{c}, \sigma)$ |
| **体渲染** | 沿 ray 数值积分得到像素色 |
| **优化** | 多视角光度损失反传 |

优点：新视角合成质量高、对复杂光影友好。  
代价：训练慢（Instant-NGP 等可加速）、导出 mesh / 可编辑资产仍需额外步骤（如 NeuS、曲面提取）。适合「先看效果 / 虚拟展陈」，尚未完全替代现有 mesh 管线。

### 4.2 3D Gaussian Splatting（3DGS）

流程概览：

1. SfM 得稀疏点与相机位姿；
2. 用各向异性 **3D 高斯**（位置、协方差、不透明度、球谐颜色）表示场景；
3. 投影为 2D splat，**tile-based** 排序 + α blending 光栅化；
4. 可微优化高斯参数。

相对 NeRF：训练与实时渲染更快，细节表达好。相对 mesh：编辑、物理、UV 工作流仍不成熟。可作为「高质量预览 / 新视角」旁路，与主 mesh 管线并行。

## 5. 其他实践

### 5.1 全景相机

环物或室内可用**全景 / 广角连续采集**：

- 视角重叠与连续性更好，利于匹配与贴图视角选择；
- 单帧信息量大，减少「漏拍死角」；
- 需处理好球面投影、畸变与曝光拼接，避免贴图接缝处亮度跳变。

### 5.2 光度立体（Photometric Stereo）

在**固定视角、多光源**（或已知光照变化）下，根据表面亮度变化估计：

- **法线**（可 refine 几何细节，如微结构）；
- **反射特性**（漫反射率等，辅助 PBR 材质）。

与多视角 MVS 互补：MVS 给宏观形状与遮挡关系；光度立体给高频法线与材质线索。线上若只有手持单灯手机，约束弱，更适合工作室 / 可控灯光场景作为增强模块。

## 6. 小结

| 模块 | 选型 | 解决的问题 |
|:---|:---|:---|
| 预处理 | U²-Net + 3D bbox | 去背景、缩计算域 |
| 特征 / SfM | SiftGPU + Colmap（规划 SuperGlue） | 位姿与稀疏骨架 |
| 深度 | CasMVSNet + 多尺度 / NAS | 弱纹理稠密深度 |
| 融合 | CUDA 点云融合 + Poisson | 时延与网格质量 |
| 纹理 | 图割 + Inpainting + Poisson 融合 | 接缝与空洞 |
| 产品 | AR 引导续扫 + 材质编辑 | 成功率与可交付 |
| 预研 | NeRF / 3DGS | 新视角与下一代表示 |

上线管线的核心不是「单点算法 SOTA」，而是 **采集闭环 + 传统几何骨架 + 深度网络补弱纹理 + GPU 工程化**，在精度、耗时与用户体验之间取平衡。
