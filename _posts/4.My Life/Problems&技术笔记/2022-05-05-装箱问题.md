## 3D Bin Packing 问题（三维装箱问题）

### 问题定义

**三维装箱问题（3D Bin Packing Problem, 3D-BPP）** 是经典的组合优化问题：

> 给定一个长方体容器和若干不同尺寸的长方体箱子，如何将箱子放入容器中，使得：
> - 箱子之间互不重叠
> - 所有箱子完全在容器内部
> - **目标：最大化空间利用率 / 最小化所需容器数量**

这是一个 **NP-hard** 问题，不存在已知的多项式时间精确算法。

### 数学形式化

给定容器 $C = (W, D, H)$ 和 $n$ 个箱子 $\{b_i = (w_i, d_i, h_i)\}_{i=1}^n$，求每个箱子的放置位置 $(x_i, y_i, z_i)$ 和方向，使得：

$$
\begin{aligned}
\text{maximize} \quad & \sum_{i} w_i \cdot d_i \cdot h_i \\
\text{subject to} \quad & x_i \geq 0,\; y_i \geq 0,\; z_i \geq 0 \\
& x_i + w_i \leq W,\; y_i + h_i \leq H,\; z_i + d_i \leq D \\
& \text{boxes do not overlap}
\end{aligned}
$$

### 常见算法

#### 1. 贪心启发式算法

**FFD（First Fit Decreasing）**：
- 将所有箱子按体积降序排列
- 对每个箱子，找到第一个能容纳它的位置放置
- 时间复杂度：$O(n^2)$

**BFD（Best Fit Decreasing）**：
- 同样按降序排列
- 选择使剩余空间最小的放置位置
- 通常比 FFD 效果更好

#### 2. 层架法（Shelf Algorithms）

将容器沿高度方向分层，每层内使用二维装箱策略：

```
for each layer:
    place boxes using 2D bin packing (e.g., NFDH)
    start new layer when current layer is full
```

**变体**：
- **NFDH（Next Fit Decreasing Height）**：简单的逐层填充
- **FNFH（First Fit Decreasing Height）**：选择最合适的已有层

#### 3. 最大空间分割法（Maximal Spaces）

维护一个"最大空闲空间"列表，每次放置后更新：

```python
def pack(boxes, container):
    free_spaces = [container]  # 初始只有一个完整空间
    placed = []

    for box in sorted(boxes, key=volume, reverse=True):
        for space in free_spaces:
            if fits(box, space):
                place(box, space)
                # 分割剩余空间为3个子空间
                split(space - box)
                break
    return placed
```

**优点**：空间利用率高；**缺点**：空间碎片化管理复杂。

#### 4. 极端点法（Extreme Points）

由 Crainic et al. 提出，利用已放置箱子的**极端角点**作为候选放置位置，大大减少了搜索空间。

## UV 装箱问题

### 问题特点

UV 装箱是计算机图形学/参数化领域中的特殊二维装箱问题：

> 将大量不规则多边形（通常是参数化后的 UV 岛屿）紧凑地排列在一个矩形区域内，目标是**最小化包围盒面积**。

与标准装箱问题的区别：

| 特征 | 标准装箱 | UV 装箱 |
|------|----------|---------|
| 形状 | 规则长方体 | 不规则多边形 |
| 允许旋转 | 90°倍数 | **任意角度旋转** |
| 目标函数 | 利用率最大化 | 包围面积最小化 |
| 约束 | 无重叠 | 无重叠 + 边界约束 |

### 常用方法

**纹理打包（Texture Atlas / Lightmap Packing）**：

1. **多边形凸包近似**：用凸包或矩形包围盒简化形状
2. **基于树的结构**：
   - **二叉树分割（Guillotine）**：递归二分可用空间
   - **Skyline 算法**：维护水平轮廓线，在最低可行位置放置
3. **基于密度的方法**：模拟物理堆积过程

**TreeMaker 中的应用**：

在 TreeMaker 参数化工具中，UV 岛屿的排列需要考虑：
- 各岛屿之间的连接关系（拓扑约束）
- 纹理空间的均衡分配
- 最小化拉伸失真后的重新分布

## TreeMaker 中的"圆河"装箱

### 背景

TreeMaker（[tree-maker](https://github.com/treemaker3d)）是一个用于网格处理的 C++ 工具库，其中包含多种几何处理算法。

### "圆河"装箱算法

"圆河"（Circle River / Circle Strip）是一种特殊的**一维/准二维**装箱策略，适用于以下场景：

- 大量圆形或近圆形区域的线性排列
- 类似于"河流"式的条状布局模式

**核心思想**：

$$
\text{将圆形区域沿着一条中心线（"河床"）交错排列}
$$

类似卵石铺成的河床——圆形区域像石头一样紧密排列在带状区域内。

### 算法描述

```
输入: n 个半径分别为 r_i 的圆
输出: 圆心坐标序列 {(x_i, y_i)}

1. 按 r_i 排序
2. 沿 x 轴方向依次放置
3. 相邻两行错开半个直径（六方密排）
4. 计算 y 方向偏移使相邻圆相切
```

### 密度分析

对于等半径 $r$ 的圆，六方密排的理论密度为：

$$ \rho_{hex} = \frac{\pi}{\sqrt{12}} \approx 0.9069 $$

即约 **90.69%** 的面积覆盖率——远高于正方形排列的 $\pi/4 \approx 78.54%$。

### 在图形学中的应用

- **纹理图集生成**中的圆形纹理元素排列
- **LOD（Level of Detail）** 中采样点的分布
- **粒子系统**的初始布局
- **图案填充**（pattern filling）中的圆盘排列
