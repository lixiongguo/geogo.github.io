## 1. 公共积木：IoU 与 NMS

### 1.1 IoU

```python
import torch

def box_iou(boxes1, boxes2):
    """
    boxes*: (N, 4) / (M, 4)，格式 xyxy
    return: (N, M)
    """
    area1 = (boxes1[:, 2] - boxes1[:, 0]) * (boxes1[:, 3] - boxes1[:, 1])
    area2 = (boxes2[:, 2] - boxes2[:, 0]) * (boxes2[:, 3] - boxes2[:, 1])

    lt = torch.max(boxes1[:, None, :2], boxes2[:, :2])  # (N,M,2)
    rb = torch.min(boxes1[:, None, 2:], boxes2[:, 2:])
    wh = (rb - lt).clamp(min=0)
    inter = wh[:, :, 0] * wh[:, :, 1]
    union = area1[:, None] + area2 - inter
    return inter / union.clamp(min=1e-6)
```

训练打标签时（R-CNN / RPN 同类逻辑）：

```python
# proposals: (K,4), gt_boxes: (G,4), gt_labels: (G,)
ious = box_iou(proposals, gt_boxes)          # (K,G)
max_iou, gt_idx = ious.max(dim=1)
pos = max_iou >= 0.5
neg = max_iou < 0.3
# 0.3~0.5 常忽略
labels = torch.zeros(len(proposals), dtype=torch.long)  # 0=背景
labels[pos] = gt_labels[gt_idx[pos]]
```

工程实现可直接用：

- `torchvision.ops.box_iou`
- `torchvision.ops.batched_nms`

### 1.2 NMS（推理后处理）

```python
def nms(boxes, scores, iou_thresh=0.5):
    """boxes: (N,4) xyxy, scores: (N,) → 保留索引"""
    order = scores.argsort(descending=True)
    keep = []
    while order.numel() > 0:
        i = order[0].item()
        keep.append(i)
        if order.numel() == 1:
            break
        ious = box_iou(boxes[i][None], boxes[order[1:]])[0]
        order = order[1:][ious <= iou_thresh]
    return keep

# 按类分别 NMS（推荐）
from torchvision.ops import batched_nms
keep = batched_nms(boxes, scores, class_ids, iou_threshold=0.5)
```

## 2. R-CNN：流程对照（理解用）

伪代码对应 Selective Search → 逐 proposal CNN → SVM / 回归：

```python
# 伪代码：经典 R-CNN，非端到端
proposals = selective_search(image)          # ~2000 框，xyxy
feats, boxes_kept = [], []
for box in proposals:
    crop = resize(crop_image(image, box), (227, 227))
    feats.append(cnn_backbone(crop))         # 每框一次前向 → 极慢
feats = torch.stack(feats)

# 每类一个 SVM；另有 bbox regressor
scores = [svm[c].decision_function(feats) for c in range(num_classes)]
# 再按类 NMS ...
```

痛点：同一图 **~2000 次** CNN；SVM 与 CNN **分步训**。代码学习价值主要在 IoU 打标与 NMS，实现上已被 Fast/Faster 取代。

Selective Search 可用 OpenCV：

```python
ss = cv2.ximgproc.segmentation.createSelectiveSearchSegmentation()
ss.setBaseImage(img)
ss.switchToSelectiveSearchFast()
rects = ss.process()  # (x,y,w,h)
```

## 3. Fast R-CNN：整图卷积 + RoI Pooling

核心：整图一次 Backbone → 在特征图上对每个 RoI 池化到固定 $H\times W$（如 $7\times 7$）。

### 3.1 RoI Pooling（示意）

```python
def roi_pool_single(feat, roi_xyxy, out_size=(7, 7), spatial_scale=1/16):
    """
    feat: (C,H,W)；roi 为原图像素坐标，先乘 spatial_scale 映到特征图
    注意：经典 RoIPool 会对边界取整 → 与像素不对齐（Mask 时改用 RoIAlign）
    """
    C, H, W = feat.shape
    x1, y1, x2, y2 = [int(v * spatial_scale) for v in roi_xyxy]
    x1, y1 = max(0, x1), max(0, y1)
    x2, y2 = min(W, x2), min(H, y2)
    roi_feat = feat[:, y1:y2, x1:x2]  # 简化：真实实现还要按 bin 做 max-pool
    # 再把 (y2-y1, x2-x1) 划成 out_size 网格，每格 max → (C,7,7)
    return torch.nn.functional.adaptive_max_pool2d(roi_feat.unsqueeze(0), out_size)[0]
```

PyTorch 正式 API：

```python
from torchvision.ops import roi_pool, roi_align

# rois: (N,5) = (batch_idx, x1,y1,x2,y2)
out = roi_pool(feat_maps, rois, output_size=(7, 7), spatial_scale=1/16)
out = roi_align(feat_maps, rois, output_size=(7, 7), spatial_scale=1/16, sampling_ratio=2)
```

Fast R-CNN 头（分类 + 框回归）示意：

```python
class FastRCNNHead(torch.nn.Module):
    def __init__(self, in_ch, num_classes):
        super().__init__()
        self.fc = torch.nn.Sequential(
            torch.nn.Flatten(),
            torch.nn.Linear(in_ch * 7 * 7, 1024),
            torch.nn.ReLU(inplace=True),
            torch.nn.Linear(1024, 1024),
            torch.nn.ReLU(inplace=True),
        )
        self.cls = torch.nn.Linear(1024, num_classes)      # 含背景
        self.bbox = torch.nn.Linear(1024, num_classes * 4) # 每类 4 个 delta

    def forward(self, roi_feats):
        x = self.fc(roi_feats)
        return self.cls(x), self.bbox(x)
```

多任务损失（概念）：

$$
L = L_{\mathrm{cls}} + \lambda\,[k\ge 1]\,L_{\mathrm{box}}
$$

背景类不做框回归；$L_{\mathrm{box}}$ 常用 Smooth $L_1$，目标是 **相对 proposal 的编码偏移**（不是绝对 xyxy）。

## 4. Faster R-CNN：RPN 替换 Selective Search

### 4.1 Anchor 与 RPN 头

在特征图每个位置放 $k$ 个 anchor（常用 3 尺度 × 3 比例 = 9）：

```python
# 伪代码：生成 anchors（特征步长 stride=16）
scales = [128, 256, 512]
ratios = [0.5, 1.0, 2.0]
anchors = []  # 每个 (y,x) 中心生成 k 个 xyxy
for s in scales:
    for r in ratios:
        w = s * (r ** 0.5)
        h = s / (r ** 0.5)
        # 以 (cx,cy) 为中心展开 ...
```

RPN：

```python
class RPNHead(torch.nn.Module):
    def __init__(self, in_ch, num_anchors=9):
        super().__init__()
        self.conv = torch.nn.Conv2d(in_ch, in_ch, 3, padding=1)
        self.cls = torch.nn.Conv2d(in_ch, num_anchors * 2, 1)   # objectness
        self.reg = torch.nn.Conv2d(in_ch, num_anchors * 4, 1)   # delta

    def forward(self, x):
        t = torch.relu(self.conv(x))
        return self.cls(t), self.reg(t)
```

RPN 损失：objectness（二类）+ 正样本框回归；正样本常用 $\mathrm{IoU}>0.7$，负样本 $<0.3$。

### 4.2 torchvision 一键 Faster / Mask

```python
import torchvision
from torchvision.models.detection import fasterrcnn_resnet50_fpn, FasterRCNN_ResNet50_FPN_Weights
from torchvision.models.detection.faster_rcnn import FastRCNNPredictor

# 预训练 COCO
model = fasterrcnn_resnet50_fpn(weights=FasterRCNN_ResNet50_FPN_Weights.DEFAULT)

# 改类别数（含背景）
in_feats = model.roi_heads.box_predictor.cls_score.in_features
model.roi_heads.box_predictor = FastRCNNPredictor(in_feats, num_classes=2)  # 例：背景+杂草

# 训练格式：list[dict]，每图 boxes (N,4) float、labels (N,) int64
images = [img_tensor]  # (C,H,W)，已 ToTensor
targets = [{"boxes": boxes, "labels": labels}]
loss_dict = model(images, targets)   # train 模式返回 loss 字典
losses = sum(loss_dict.values())
losses.backward()

# 推理
model.eval()
outputs = model(images)  # boxes / labels / scores
```

Mask R-CNN：


## 5. Mask R-CNN：RoIAlign + Mask 头

相对 Faster 的代码级增量：

1. **RoIAlign** 替代 RoIPool（`roi_align`，禁止坐标取整）；
2. 并联 **mask head**（小型 FCN），对每个 RoI 输出 $C\times m\times m$ 或每类一张二值图。

```python
# Detectron2 风格理解（概念）
# losses = loss_cls + loss_box + loss_mask
# mask 分支通常只对正样本 RoI 计算 BCE / 每像素损失
```

推荐完整可训仓库（比手写 Faster 省事）：

| 库 | 说明 | 链接 |
| :--- | :--- | :--- |
| **torchvision** | 官方 Faster/Mask，适合入门改头 | [detection](https://pytorch.org/vision/stable/models.html#object-detection) |
| **Detectron2** | FAIR，Mask/Cascade/FPN 配置丰富 | [facebookresearch/detectron2](https://github.com/facebookresearch/detectron2) |
| **MMDetection** | OpenMMLab，两阶段/单阶段配置统一 | [open-mmlab/mmdetection](https://github.com/open-mmlab/mmdetection) |

Detectron2 最小推理例：

## 6. 训练时数据流对照（Faster）

```text
batch 图像
  → Backbone(+FPN) 得多尺度特征
  → RPN：anchor 上算 objectness / delta → 解码为 proposals → NMS 截断 Top-N
  → 与 GT 匹配，采样正负 RoI
  → RoIAlign → box head → L_cls + L_box
  →（Mask）正样本再进 mask head → L_mask
```

框编码（Faster 原文常用，实现时看框架；torchvision 已封装）：

$$
\begin{aligned}
t_x &= (x - x_a)/w_a,\quad
t_y = (y - y_a)/h_a,\\
t_w &= \log(w/w_a),\quad
t_h = \log(h/h_a)
\end{aligned}
$$

其中下标 $a$ 为 anchor / proposal。

## 7. 和单阶段笔记的衔接

- 两阶段：**先提案再分类**，精度往往更好，速度慢于 YOLO/SSD。
- 单阶段直接密集预测，见 [激光除草-目标检测2-单阶段算法](激光除草-目标检测2-单阶段算法.md)；无锚点见 [目标检测3-无锚点检测](目标检测3-无锚点检测.md)。
- 田间杂草若要实时，工程上多落 YOLO；两阶段 / Mask R-CNN 适合要 **mask 质量** 或离线标注管线。
