> 路线：**VITON**（粗合成 + Shape-Context TPS）→ **CP-VTON**（CNN 学习 TPS + 掩码融合）→ **WUTON**（特征图几何形变，端到端）。这是 2D 图像虚拟试衣最具代表性的三篇工作，全部基于 GAN / 编码-解码生成，不依赖 3D 信息；后续工作（ACGPN、PF-AFN、DCI-Net 等）大多沿着"更好的几何对齐 + 更鲁棒的融合"这条线改进。相关 3D / SMPL 路线见 [Avatar-SMPL人体重建](Avatar-SMPL人体重建.md) 与 [基于GAN的三维重建](基于GAN的三维重建.md)。

## 任务与设定

**Image-based Virtual Try-On（VTON）**：给定

- 一张**人物图像** \(I\)（目标用户 / 模特，含姿态、面部、头发、身体）；
- 一张**服装商品图** \(c\)（电商产品图，平铺/模特展示的姿态各异）；

合成该人物**试穿这件衣服**后的图像 \(\hat{I}\)。评价的核心是：

- **服装细节保留**：纹理、logo、文字、图案必须忠实于商品图；
- **几何对齐**：衣物要贴合目标人体的姿态与体型；
- **身份保留**：脸、头发、肤色与身体形状不能变。

这一任务的**主要困难**在于商品图与目标人体姿态差异大，且没有"真实试穿"的成对监督（同一件衣服、同一模特的不同展示姿态极难采集）。

## VITON：Image-based Virtual Try-on Network（CVPR 2018）

> Han, Wu, Wu, Yu, Davis. *VITON: An Image-based Virtual Try-on Network*. CVPR 2018.  
> arXiv: 1711.08447。

### 核心思想：Coarse-to-Fine（由粗到精）

VITON 是该任务的开山之作，采用两阶段**coarse-to-fine**框架：

1. **Stage 1（粗合成 \(G_c\)）**：基于 U-Net，从人体表示 \(P\) 和目标衣物 \(c\) 生成一个**粗合成图 \(I'\) 与服装区域掩膜 \(M\)**。  
   因 L1 损失主导，\(I'\) 在服装区域是**模糊**的，丢失细节，但布局大致对齐。

2. **TPS Warping**：基于粗掩膜 \(M\) 与目标衣服 \(c\)，用 **Shape-Context Matching + Thin-Plate Spline (TPS)** 计算形变，把商品图 warp 成贴合人体的 \(c'\)。

3. **Stage 2（精修 \(G_R\)）**：以 warp 后的衣服 \(c'\) + 粗合成 \(I'\) 为输入，用 Refinement Network 恢复细节，输出最终图像 \(\hat{I}\)。

### 网络架构

```
Person Representation P (256×192×22) + Target Clothing C
                  ↓
        ┌──────────────────────┐
        │   Gc  (U-Net)        │ ──→  I' (粗合成) + M (掩膜)
        └──────────────────────┘
                  ↓ M
        ┌──────────────────────┐
        │ Shape-Context + TPS  │ ──→  c' (warp 后衣物)
        └──────────────────────┘
                  ↓
        ┌──────────────────────┐
        │   GR (Refinement)    │ ──→  Î (最终试穿结果)
        └──────────────────────┘
        输入: c' + I'
```

### Person Representation \(P\)（256×192×22）

为了让网络"忘记"原图衣物、保留身份信息，构造一份 22 通道的人体表征：

| 通道 | 内容 |
|----|----|
| **18 通道** | 18 个人体关键点的姿态热度图（每个关键点附近用 11×11 白块表示） |
| **1 通道** | 人体部位二值掩膜（避免形状混淆引入伪影） |
| **3 通道** | 面部 + 头发区域的 RGB（保留身份） |

#### 为什么叫 "Agnostic Person"？

"Agnostic" 直译是"不可知论"，但在虚拟试衣语境里指 **"与目标衣物无关的人体表征"**。具体含义：

- **Agnostic** = **agnostic to the target clothing**，即**不包含**参考图中人物当前所穿衣物的任何信息（颜色、纹理、款式、图案都已被剥离）；
- **保留**的信息：姿态、身材（粗略）、脸、头发 —— 这些是与"试穿哪件衣服"无关的**人物固有属性**。

为什么要做这个剥离？因为虚拟试衣的测试设定是：

> 输入 1：参考人物图（他/她**现在**穿的衣服 A）  
> 输入 2：目标衣物图（电商展示的衣物 B）  
> 输出：参考人物**换上衣物 B** 的图。

如果直接把参考图原图喂给网络，网络会倾向于"复制原图衣物"，而忽略目标衣物图。所以必须显式构造一个**与 A 无关、只保留人物身份**的表征 \(P\)，强制让网络以 \(P\) 为锚、以 \(C\) 为衣，生成新图。

#### 构造策略对比

| 方法 | 剥离目标衣物的方式 | 代表 |
|----|----|----|
| **遮盖（mask out）** | 用人体解析得到衣物区域 mask，把 mask 内像素置零/置灰 | VITON, CP-VTON |
| **裁剪保留区** | 只保留脸、头发、皮肤等"非衣"区域 | VITON |
| **解析图替换** | 把衣物区域替换为"标准服装形状"解析图（保留位置但不保留纹理） | ACGPN |
| **Parser-free** | 完全不用人体解析，靠网络自己学 | PF-AFN, WUTON 的后续工作 |

VITON 的做法是**遮盖 + 保留**：mask 区域用 0 填充，只保留脸/头发 RGB。  
WUTON 沿用类似设定（用 OpenPose + 简单身体掩膜），但通过 Siamese 双分支让网络有更大的自由度去隐式处理这种剥离。

### 损失函数

- **Stage 1**：\(\mathcal{L}_{L1}(I') = \| I' - I \|_1\)（粗合成图与真图之间的 L1）  
  L1 损失对 RGB 输出会自然产生模糊，因此只能做粗合成。
- **Stage 2**：  
  \[
  \mathcal{L}_{\text{total}} = \mathcal{L}_{L1}(\hat{I}, I) + \mathcal{L}_{\text{perceptual}}(\hat{I}, I)
  \]
  其中感知损失 \(\mathcal{L}_{\text{perceptual}}\) 用 **VGG19 多层特征**度量高层语义差异。

### 局限

- TPS 形变依赖**手工的 Shape-Context 匹配**，形变精度受限；
- Stage 1 必须额外依赖**人体解析器**（LIP-SSL/JPPNet）提供掩膜，pipeline 复杂；
- 粗合成的 L1 模糊+精修的细节恢复仍是"补救式"思路，**细节保留能力有限**。

## CP-VTON：Characteristic-Preserving VTON（ECCV 2018）

> Wang, Zhang, Zhou, Liu, Zhang, Liu, Li, Pu. *Toward Characteristic-Preserving Image-based Virtual Try-On Network*. ECCV 2018.  
> arXiv: 1807.07688。

CP-VTON 把 VITON 的两个短板同时解决：

1. **几何对齐**：用 **CNN 学习** TPS 参数，替代手工的 Shape-Context 匹配；
2. **细节融合**：引入**掩码引导的自适应融合**，让网络自己决定哪些区域"信任 warp 后的衣物"。

### Person Representation \(P\)

CP-VTON 直接沿用 [VITON 章节的 Person Representation](#person-representation-p25619222)（22 通道配方），目的与 VITON 一致——剥离原图衣物、只保留**人物固有属性**。两者差异仅在 mask 范围：

| 维度 | VITON | CP-VTON |
|:---:|:---|:---|
| **通道总数** | 22 | 22（一致） |
| **Mask 范围** | 几乎全上身 + 全身 | **仅上半身的服装相关标签**（upper-clothes / arms / dress / jumpsuit） |
| **保留的 RGB** | 头 + 发（其它全 mask） | 头 + 发 + 下装 / 皮肤 |

也就是说，CP-VTON 几乎原封不动沿用了 VITON 的 22 通道配方，只是 code-level 的 mask 策略更精细（明确指定要 mask 哪些服饰标签），避免把不必要的下半身 / 背景也清掉。

> **与 VITON 章节的关系**：22 通道 P 的完整起源、动机、Agnostic Person 命名等，详见 [VITON 一节的 Person Representation 子节](#person-representation-p25619222)。本节仅保留 CP-VTON 特有差异。

### 整体流程

```
Person Representation P + Target Clothing C
                  ↓
┌─────────────────────────────────────┐
│  GMM: Geometric Matching Module     │ ──→  ĉ (warp 后衣物)
│  - 双分支 CNN 提取特征              │
│  - Correlation Layer: 4D 软对应     │
│  - 3D 卷积 + FC 回归 TPS 参数 θ     │
│  - TPS 模块做形变                   │
└─────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────┐
│  TOM: Try-on Module (U-Net)         │ ──→  I_r (合成图) + M (融合掩膜)
└─────────────────────────────────────┘
                  ↓
    I_o = M ⊙ ĉ + (1 - M) ⊙ I_r
```

### 几何匹配模块 GMM

GMM 由 4 部分组成：

| 组件 | 功能 |
|----|----|
| **双 CNN** | 分别提取人体表征 \(p\) 与目标衣服 \(c\) 的高维特征 |
| **Correlation Layer** | 将两个特征两两内积，构造 4D 软对应张量（详见 [附录 A.3](#a3-correlation-layer--让匹配可微)） |
| **回归网络** | 从匹配张量回归 TPS 参数 \(\theta\) |
| **TPS 模块** | 将 \(\theta\) 应用到衣服 \(c\) 上，得到变形衣服 \(\hat{c} = T_\theta(c)\) |

**关键改进**：

- 摒弃手工 Shape-Context 匹配，TPS 参数完全由 CNN 回归；
- 端到端可训练，不再需要显式 landmark 对应；
- 损失：\(\mathcal{L}_{\text{GMM}}(\theta) = \| \hat{c} - c_t \|_1\)（warp 后衣物与"目标人物身上穿的同款衣物"之间的 L1）。

### Try-on 模块 TOM

TOM 是 U-Net 编码-解码，输入 \((p, \hat{c})\)，输出两个东西：

- 一张合成图像 \(I_r\)（U-Net 的常规"平滑"输出）；
- 一个**融合掩膜 \(M \in [0,1]^{H\times W}\)**（逐像素）。

最终的试穿图通过**自适应融合公式**生成：

\[
I_o = M \odot \hat{c} + (1 - M) \odot I_r
\]

- \(M\) 接近 1 的区域：直接采用 warp 后的衣物 \(\hat{c}\)，**保留商品细节**；
- \(M\) 接近 0 的区域：采用 U-Net 平滑合成的 \(I_r\)，**修复对齐误差**。

### 损失函数

TOM 的总损失为：

\[
\mathcal{L}_{\text{TOM}} = \lambda_{L_1} \| I_o - I_t \|_1 
+ \lambda_{\text{vgg}} \mathcal{L}_{\text{VGG}}(I_o, I_t)
+ \lambda_{\text{mask}} \| 1 - M \|_1
\]

| 损失项 | 作用 |
|----|----|
| L1 像素损失 | 保证整体像素级相似 |
| VGG 感知损失（VGG19 多层特征） | 保留高层语义与纹理风格 |
| **掩码正则 \(\|1-M\|_1\)** | **核心创新**：鼓励 \(M\) 接近 1，让网络把更多区域"让给"warp 后的衣物，**最大化保留服装特征**（logo、文字、图案） |

### 相对 VITON 的关键差异

| 维度 | VITON | CP-VTON |
|----|----|----|
| 几何匹配 | 手工 Shape-Context TPS | **CNN 学习 TPS**（端到端） |
| 外观融合 | 直接拼接 + 精修 | **掩码引导自适应融合** + 掩码正则 |
| 细节保留 | 易丢失 | 通过 \(\|1-M\|_1\) 显式最大化保留 |

CP-VTON 的融合公式已成为后续多篇工作的标准模板（如 PF-AFN、ACGPN 都沿用这一思路）。

## WUTON：Warping U-Net for Virtual Try-On（2019）

> Issenhuth, Mary, Clément. *End-to-End Learning of Geometric Deformations of Feature Maps for Virtual Try-On*. 2019.  
> arXiv: 1906.01347。

### 核心思想

VITON 和 CP-VTON 都在**像素层面**做几何形变（Warp 整张衣物图），但几何形变误差会被下游合成网络放大。WUTON 的关键转变：

> **把几何形变从像素级提升到特征级。**

具体做法：

- 把 **U-Net 的每个 skip connection 都做几何形变**（不同尺度都做一次 warp），而不是只在最深层做一次 TPS；
- 用一个 **Convolutional Geometric Matcher** 预测每一层的形变场，让形变成为网络本身的一部分；
- 整体网络**端到端训练**，多任务损失监督。

### 架构概览

```
                              ┌──────────────────┐
Agnostic Person Rep. P ──────→│                  │
                              │  Convolutional   │──→ 形变参数 (多尺度)
Target Clothing C ──────────→│  Geometric       │
                              │  Matcher (CGM)   │
                              └──────────────────┘
                                        ↓
                  ┌─────────────────────────────────────┐
                  │   Warping U-Net                     │
                  │   (Siamese Encoder + U-Net 解码)   │
                  │                                     │
                  │   编码器: 双分支 (人 / 衣)          │
                  │   skip connections: 每层都被 CGM    │
                  │              几何形变              │
                  └─────────────────────────────────────┘
                              ↓
                        Try-on Image Î
```

### Convolutional Geometric Matcher (CGM)

- 不再像 CP-VTON 那样把形变限制在 TPS（一种固定的参数化形变）；
- CGM 直接从两个特征图回归一个**稠密形变场**（或分层级的形变参数），通用性更强；
- 形变作用在 skip connection 的特征图上，因此**解码器"看到"的特征已是几何对齐后的**，上采样时不需要再做大幅度对齐。

### Siamese Encoder

编码器是双分支的，分别处理人体表征 \(P\) 和衣物 \(C\)：

- 不共享权重（或部分不共享），保证两路特征独立；
- 解码器以融合后的特征为输入；
- 多尺度特征都被形变 → 解码器从浅到深都"知道"对齐后的衣物在哪。

### 训练与损失

WUTON 使用**多任务损失**端到端训练（无需分阶段训练）：

| 损失项 | 监督目标 |
|----|----|
| **匹配损失（matching loss）** | CGM 输出的形变在像素/特征层面与"对齐真值"接近 |
| **形变正则（warping loss / smoothness）** | 形变场要平滑，避免不合理的扭曲 |
| **合成损失** | 最终图像的 L1 + VGG perceptual，与 VITON/CP-VTON 类似 |

不需要显式的人体解析 / shape-context 阶段，整个 pipeline **端到端**训练。

### 关键改进（相对 CP-VTON）

WUTON 把"几何形变"从 CP-VTON 的**像素级 TPS** 升级到**特征级稠密 flow**：

- **形变位置**：单次 TPS（仅最深层）→ 每层 skip connection 都做 warp；
- **形变参数化**：稀疏 TPS 控制点（5×5 = 50 维）→ 稠密 flow field（每像素 Δx, Δy）；
- **训练方式**：GMM + TOM 两阶段 → 端到端单阶段联合训练。

代价是计算量更大（每层都要做 warping、编码器非共享），但**对姿态变化、遮挡、服装变形的鲁棒性显著提升**，对后续"parser-free"路线（PF-AFN、CP-VTON+）有直接启发。**13 维度完整对比见 [附录 C.4](#c4-全方位对比)**。

## 三篇工作的演化脉络

```
VITON (CVPR 2018)  ── 粗合成 + 手工 TPS warp + 精修
        │           局限：依赖手工匹配，细节易丢
        ↓
CP-VTON (ECCV 2018) ── CNN 学习 TPS 参数 + 掩码自适应融合
        │           改进：端到端几何对齐 + 显式保留细节
        ↓
WUTON (2019) ── 特征级几何形变 + 端到端多任务
                改进：形变从像素级提到特征级，更鲁棒
```

共同点：
- 都基于"**几何对齐 → 合成**"两阶段思路；
- 都**不依赖 3D 信息**，仅用 2D 图像 + 姿态/解析；
- 都用 **GAN/L1 + 感知损失** 监督生成质量。

后续发展的两条主线：
1. **保留 parser**：继续改进几何匹配（如 DCI-Net、ACGPN）；
2. **Parser-free**：完全抛弃人体解析器（如 PF-AFN、S-WUTON、T-WUTON）。

## 工程要点速查

- **训练数据**：常用 **VITON dataset / Zalando Dataset**（女性上衣 + 模特图，约 19k 对，无真实试穿配对，训练时把"参考图中模特穿的衣服"作为目标衣服）。
- **预处理依赖**：
  - 关键点估计：OpenPose / 18-keypoint pose；
  - VITON / CP-VTON 还需要人体解析（LIP-SSL、JPPNet 或 CIHP_PARSER）；
  - WUTON 已尽量减少对解析的依赖。
- **训练显存**：Stage 1 + Stage 2 两阶段训练，单卡 12GB 通常可跑（输入 256×192）。
- **推理一致性**：测试时**目标人物图与目标衣服图来自不同来源**，与训练时（参考图本人穿的就是目标衣）的设定略有不同，工程上通常在训练时随机抽不同 pair 来增强鲁棒性。
- **常见失败模式**：手部遮挡、跨姿态极端变化、袖子/领口大幅度形变、纹理高频细节丢失。

## 附录 A：Shape Context Matching 与 TPS 变换

虚拟试衣的几何对齐本质上是**两幅图像之间的非刚性配准**：把商品图（in-shop clothing）变形到目标人体的姿态/体型上。VITON 用的是经典的 **Shape Context + TPS** 流程，CP-VTON 把它"端到端化"了。要看懂这两篇工作，必须先把这两个工具讲清楚。

### A.1 Thin-Plate Spline（TPS）—— 一种非刚性形变基函数

#### 直观理解

**TPS** 是描述"将一张曲面薄板弯曲贴合另一组点"所需要的**最小弯曲能量**的解析解。它定义了一种**二维空间到二维空间的非刚性映射** \(f: \mathbb{R}^2 \to \mathbb{R}^2\)，具有如下性质：

- 给定 \(K\) 对**控制点对应** \(\{(p_i, q_i)\}_{i=1}^K\)（\(p_i\) 是源点，\(q_i\) 是目标点），TPS 唯一确定一个形变；
- 形变在控制点处**精确通过**目标点（插值性）；
- 形变在远离控制点的区域**尽可能刚性**（"薄板"弯曲能量最小）。

#### 数学形式

TPS 形变可以写成两个分量的叠加：

\[
f(x, y) = a_0 + a_1 x + a_2 y + \sum_{i=1}^{K} w_i \, U(\|(x,y) - p_i\|)
\]

其中：

| 符号 | 含义 |
|----|----|
| \(a_0, a_1, a_2\) | **仿射分量**（保证整体平移/缩放/旋转） |
| \(w_i\) | 第 \(i\) 个控制点的**径向基权重** |
| \(U(r) = r^2 \log r\) | **TPS 核函数**（薄板弯曲能量对应的格林函数） |
| \(p_i\) | 第 \(i\) 个源控制点 |

直观上：仿射项处理"全局姿态"，径向基项处理"局部形变"。每远离一个控制点 \(p_i\)，影响按 \(r^2 \log r\) 平滑衰减。

#### 求解

把 \(K\) 对控制点对应代入插值条件 \(f(p_j) = q_j\)，再加上**正交约束** \(\sum_i w_i = 0, \sum_i w_i p_{i,x} = 0, \sum_i w_i p_{i,y} = 0\)（防止径向基吞噬仿射分量），可得到一个 \((K+3) \times (K+3)\) 的线性系统：

\[
\begin{bmatrix}
K & P^\top \\
P & 0
\end{bmatrix}
\begin{bmatrix}
w \\ a \end{bmatrix}
=
\begin{bmatrix}
q \\ 0
\end{bmatrix}
\]

其中 \(K_{ij} = U(\|p_i - p_j\|)\)，\(P\) 是控制点坐标拼成的矩阵。**\(K+3\) 个未知数、\(K+3\) 个方程，可一次性求解**（仿射分量独立地应用到 x 和 y 通道）。

#### 在虚拟试衣中的作用

TPS 在 VITON/CP-VTON 里被用来把**平铺/模特展示的商品衣物** warp 成**贴合目标人体的姿态**。一旦控制点对应确定，整张衣物图按 TPS 形变即可——颜色、纹理在 warp 过程中被"搬"过去，所以**纹理一致性**比纯神经网络重画更好。

### A.2 Shape Context —— 一种"点对点匹配"的描述子

#### 为什么需要它？

TPS 需要控制点对应（即"商品图上某点 = 人体图上某点"）。但**没有显式监督**告诉网络哪里对哪里，所以要：

1. 从两幅图上各取一组**边缘/轮廓关键点**；
2. 用一种**对平移、旋转、尺度鲁棒**的描述子刻画每个关键点；
3. 用最近邻 + TPS 校验筛出**正确的点对**，作为 TPS 输入。

#### Shape Context 描述子

对一个**关键点 \(p\)**，统计它周围所有其它点 \(\{q_j\}\) 的**相对极坐标分布**：

\[
h_p(k) = \#\{q_j \neq p : q_j - p \in \text{bin}_k\}
\]

即：以 \(p\) 为原点，把全图划分成**对数极坐标网格**（半径方向对数划分、角度方向均匀划分，例如 5×12 = 60 个 bin），统计每个 bin 内的点数。

```
       角度均分（如 12 个 bin）
        ↑
        |   . . . .
        |  . . . . .
        |  . . p . .   ← 关键点 p
        |  . . . . .
        |   . . . .
       ↓────────────→ 半径对数划分（如 5 圈）
```

#### 匹配

对两幅图的关键点集 \(\{p_i\}, \{q_j\}\)：

1. 计算两两之间的 Shape Context 描述子（Cost matrix \(\chi_{ij}\)）；
2. 用 **Hungarian 算法** 做最小代价匹配（双向最近邻）；
3. 用 **TPS 拟合**得到的形变对匹配做"剔除离群点"（reweight）；
4. 迭代若干轮（鲁棒估计）得到最终的对应集合。

#### 在 VITON 中的角色

VITON 把 Shape Context 用在**衣物轮廓 ↔ 人体姿态对应**上：

- 源图：商品衣服的**轮廓点**（沿衣物掩膜边界采点）；
- 目标：人体图上**人体解析后**的衣服区域边界；
- 匹配得到对应点对后，TPS 把衣物 warp 到目标姿态上。

#### 局限

- **依赖人体解析**：源/目标都需要清晰的轮廓；
- 对**自遮挡**（手臂交叉、姿态大幅变化）敏感；
- 计算复杂度高（关键点越多越慢）；
- **非端到端**，无法与下游合成网络联合训练。

### A.3 Correlation Layer —— 让"匹配"可微

CP-VTON 把 Shape Context + Hungarian 这套"离散匹配"做端到端化，最关键的一步就是用 **Correlation Layer（关联层）** 替换了"采样点 → 描述子 → 匹配"的整个 pipeline。这个算子最初由 **FlowNet**（Dosovitskiy et al., ICCV 2015）在光流任务中提出，本质是"用一张图的 patch 在另一张图上做卷积"——一种**无参数、可微**的空间匹配算子。

#### A.3.1 直观理解

拿到两张 feature map——人体特征 \(F_p\)（来自人体表征 \(P\)）和衣物特征 \(F_c\)（来自目标衣物 \(C\)）——想回答"人体上每个位置分别和衣物上每个位置有多像"。最朴素的做法是：

> 在 \(F_p\) 的位置 \(x_1\) 周围取一个 patch，在 \(F_c\) 的每个位置 \(x_2\) 各取一个 patch，**逐对做内积**——结果就是一张"匹配强度图"，把"哪里像哪里"显式写出来。

Correlation Layer 就是把这个朴素做法**工程化、可微化**后的标准实现。

#### A.3.2 数学定义

对两个人体特征位置 \(x_1\)、衣服特征位置 \(x_2\)，一个 patch 半径为 \(k\) 的 correlation 计算为：

\[
c(x_1, x_2) = \sum_{o \in [-k,k]^2} \left\langle F_p(x_1 + o),\ F_c(x_2 + o) \right\rangle
\]

其中 \(\langle \cdot, \cdot \rangle\) 是通道维的内积（\(C\) 维向量的点积），\(o\) 是 patch 内相对中心的偏移，patch 大小为 \((2k+1)^2\)。

最简形式（\(k=0\)）就是**两点特征向量的点积**：

\[
c(x_1, x_2) = \left\langle F_p(x_1),\ F_c(x_2) \right\rangle
\]

若 \(F_p\)、\(F_c\) 经 L2 归一化，这个点积等价于**余弦相似度**。这正是 FlowNet / CP-VTON 实际使用的最简形式。

#### A.3.3 输出结构：4D Correlation Volume

把"每个人体位置"与"每个衣服位置"两两配对算一遍，就得到一个 **4D 张量**：

\[
\text{Corr} \in \mathbb{R}^{H_p \times W_p \times H_c \times W_c}
\]

- 第 1、2 维 (\(H_p \times W_p\))：**查询**（人体上的每个位置都要"问"一次）；
- 第 3、4 维 (\(H_c \times W_c\))：**键**（衣服上的每个位置都是候选匹配点）；
- 固定 \((i, j)\) 切片 \(\text{Corr}[i, j, :, :] \in \mathbb{R}^{H_c \times W_c}\) 是"衣服上每个位置对这个人位置 \(x_1 = (i,j)\) 的匹配分数"——一张**软对应图 (soft correspondence map)**，是后续 soft-argmax / attention 权重的直接输入。

```
              衣服特征图  H_c × W_c
                ↓ ↓ ↓ ↓ ↓ ↓ ↓
人体 (i, j) →  [c][c][c][c][c][c][c]    ← 1×1×H_c×W_c 的一个切片
               [c][c][c][c][c][c][c]
               [c][c][c][c][c][c][c]
                  ↑
        一个人体位置的完整匹配响应
```

#### A.3.4 FlowNet 的优化（光流场景下）

朴素 4D 相关体大小为 \(H \cdot W \cdot H \cdot W\)，计算量 \(O((HW)^2 \cdot C)\)，**不可接受**。FlowNet 在光流任务里做了三项关键压缩：

| 参数 | 含义 | FlowNet 取值 |
|:---:|:---|:---:|
| \(k\) | patch 半径 | \(0\)（最简：单点比较） |
| \(d\) | 最大位移 | 20 |
| \(s_1\) | 人体侧全局步幅 | 1 |
| \(s_2\) | 衣服侧邻域内步幅 | 2 |

- **限定搜索范围**：\(x_1\) 不再和 \(F_c\) 所有位置比，只和 \(\pm d\) 邻域内 \(D = 2d+1\) 个位置比；
- **量化下采样**：\(F_p\) 按步幅 \(s_1\) 抽稀，\(F_c\) 邻域内按步幅 \(s_2\) 抽稀；
- 结果从 \(H \cdot W \cdot H \cdot W\) 压缩到 \(H' \cdot W' \cdot D \cdot D\)，其中 \(H' = H/s_1\)、\(D = 2d/s_2 + 1\)。

**这只在光流场景下合理**（连续帧之间位移有上限）。**虚拟试衣不是这样**——见 A.3.5。

#### A.3.5 CP-VTON 的"全景式"做法

CP-VTON **不限定** \(d\)，直接做 \(H_p \times W_p \times H_c \times W_c\) 的**完整 4D 相关体**：

- 编码器把 \(F_p\)、\(F_c\) 都下采样到 **16×12×64**（通道数 \(C=64\)）；
- 完整相关体大小 = \(16 \times 12 \times 16 \times 12 = 37\,632\) 维，可一次性塞进后续 3D 卷积；
- 不设 \(d\) 的依据：商品图衣物 warp 到目标人体后，**没有"小位移"假设**——衣物的领口可能对应人体的腰部，反之亦然；任何"局部搜索范围"都会丢失全局对应；
- 计算量上能接受是因为 \(H_p, H_c\) 已经很小（\(16, 12\)），且这一步只跑一次。

> 这和 FlowNet 的"局部小搜索窗"思路**正好相反**——虚拟试衣需要的是**全局对应**，光流假设的是**局部小位移**。这是同一个算子在两类任务下被"用反"的关键区别。

#### A.3.6 回归网络怎么"读"这个 4D 张量

拿到 4D 相关体后，CP-VTON 用一个**轻量 3D 卷积 + FC**把它压成 2N 维的 TPS 参数 \(\theta\)：

```
Correlation Volume [B, 1, H_p, W_p, H_c, W_c]
        ↓
Conv3D(1 → 32, k=3, padding=1) + ReLU     # 在匹配场上做局部平滑
Conv3D(32 → 64, k=3, padding=1) + ReLU
Conv3D(64 → 128, k=3, padding=1) + ReLU
        ↓
Global Average Pooling（沿 H_p × W_p 维）  # 把整个人体查询维压成 1D
        ↓
FC(128 → 256) + ReLU
FC(256 → 2N)                              # N 个 TPS 控制点 × (Δx, Δy)
        ↓
θ ∈ ℝ^(2N)        (N = 25, 5×5 网格控制点)
```

设计要点：
- **3D 卷积**处理"两个空间维 + 一个匹配维"——它在 \((H_c, W_c)\) 方向聚合"最像的衣服位置"，在 \((H_p, W_p)\) 方向保持"每个查询位置的局部匹配结构"；
- **GAP**而不是 flatten：因为整张图共用**一个全局** \(\theta\)（TPS 形变是全局参数化），把查询维压成 1D 才能输出 \(2N\) 而非 \(2N \cdot H_p W_p\)；
- 监督信号是 L1：\(\| \theta_{\text{pred}} - \theta_{\text{gt}} \|_1\)，\(\theta_{\text{gt}}\) 由"真实穿好的衣服"反算 TPS 拟合得到。

#### A.3.7 为什么 CP-VTON 选 Correlation 而不是其他"匹配算子"

| 备选 | 思路 | 在 CP-VTON 里被淘汰的原因 |
|:---|:---|:---|
| **通道拼接（concat）** | 把 \(F_p\) 和 \(F_c\) 沿通道 concat，让网络自己学 | 网络要花容量去"猜"哪里对哪里；匹配信息隐式 |
| **Cross-attention** | \(F_c\) 做 K/V，\(F_p\) 做 Q，加权求和 | 本质也是"软对应"，但需要外加 Q/K 投影；GMM 目标只是稀疏 TPS 参数，不需要密集对应 |
| **匈牙利匹配（Hungarian）** | 计算描述子 + 离散最优分配 | **不可微**——断了端到端梯度 |
| **Correlation** | 两两内积建出 4D 匹配张量 | ✅ 无参数、可微、显式、可与任意下游结构对接 |

简言之：**Correlation Layer 是"用最低成本把匹配这件事显式化"的最优折中**——它本身不学习任何参数，但把"哪里对哪里"以张量形式直接交给回归网络去读。

#### A.3.8 概念同构：传统视觉里的 Cost Volume

Correlation Layer 在概念上完全等价于传统多视图几何里的 **Cost Volume（代价体）**：

| 任务 | 特征 1 | 特征 2 | 代价体含义 | 下游读取方式 |
|:---|:---|:---|:---|:---|
| **双目立体匹配** | 左图特征 | 右图特征 | 视差搜索 | 3D 卷积 + argmax 视差 |
| **光流估计** | 帧 1 特征 | 帧 2 特征 | 运动搜索 | 3D 卷积 + argmax 位移（FlowNet） |
| **图像匹配 / SuperGlue** | 图 A 特征 | 图 B 特征 | 关键点对应 | Transformer + sinkhorn 分配 |
| **虚拟试衣（CP-VTON）** | 人体特征 | 衣物特征 | 衣物-人体对应 | **3D 卷积 + FC 回归到 TPS 参数** |

CP-VTON 的"4D 关联体 → 3D 卷积 → FC 回归"这条管线，可以看作光流/立体匹配的"3D 卷积 → argmax"流程在**形变参数化**这一目标下的一个变种——它不输出密集光流，而是输出**稀疏的全局 TPS 控制点偏移**。

> **一句话理解**：Correlation Layer 解决了"如何把两个特征图的对应关系写成可微张量"这个问题；GMM 之所以能做到端到端，**Correlation Layer 是最关键的一步**——没有它，前面的双 CNN 与后面的 TPS 回归就连不起来。

### A.4 从 Shape-Context TPS 到 CP-VTON 的 GMM

CP-VTON 的 GMM 模块本质上是把上面这套流程**全部塞进一个神经网络**：

| 手工管线（VITON） | CP-VTON 的 GMM |
|----|----|
| 关键点采样（轮廓点） | CNN 自动提取特征 |
| Shape Context 描述子 | Correlation Layer 算两两匹配张量 |
| Hungarian 匹配 | 隐式由回归网络处理 |
| TPS 拟合（线性系统求解） | 回归网络直接输出 TPS 参数 |
| 整体非可微 | **可微**，端到端训练 |

GMM 的训练目标：

\[
\mathcal{L}_{\text{GMM}}(\theta) = \| T_\theta(c) - c_t \|_1
\]

其中 \(c\) 是源衣物、\(c_t\) 是"目标人物身上穿的同款衣物"——这就是**自监督式的形变监督**：训练时同一对人物/衣物，\(c\) 与 \(c_t\) 已知；测试时只有 \(c\)，网络靠泛化推断形变。

这种"**可微化传统几何流程**"的思路（手工管线 → CNN 实现 → 端到端优化）在很多视觉任务里都出现过（如光流 SuperGlue、匹配 LoFTR、相机位姿回归 DSAC*），是现代几何深度学习的常见模式。

---

### A.5 再到 WUTON：从 TPS 到 Convolutional Geometric Matcher

WUTON 又往前迈了一步：TPS 是一种**固定的参数化形变**（用 K 个控制点 + 径向基），表达能力有限。WUTON 用 **Convolutional Geometric Matcher** 直接预测**稠密形变场**或更通用的形变参数：

- 在 U-Net 的**每一个 skip connection 上**都做一次形变（不只是最后一层）；
- 形变作用在**特征图**而非像素上，几何误差可在解码阶段被进一步修正；
- 没有"控制点对应"这一离散环节，纯回归方式 → 端到端、不依赖轮廓提取。

可以说：

> **VITON 用几何（手工 TPS）算形变 → CP-VTON 用 CNN 学几何参数 → WUTON 用 CNN 直接学形变场**。每一步都把"几何"和"学习"耦合得更紧。

而 WUTON 之所以能"端到端"地把几何形变塞进生成器内部，依赖的关键架构之一就是 **Siamese Network**（孪生网络）——它在 WUTON 中充当"双分支特征提取器"，让人体和衣物在编码阶段就被各自独立的卷积塔解读、最后再融合。详见 [附录 B](#附录-bsiamese-network-与双分支编码器)。

---

### A.6 CGM 与 STN（Spatial Transformer Network）的关系

把 CGM 单独拎出来，会发现它在"用一个可微模块做空间形变"这一点上，和 Jaderberg et al. 2015 提出的 **Spatial Transformer Network (STN)** 几乎完全同构——都遵循 *"learn-to-warp"* 的思路。但因为服务的任务不同（数字识别 vs. 虚拟试衣），二者在多个维度上存在本质区别。

#### A.6.1 核心公式上的高度同构

两者都可以写成两步：

```
Step 1: θ = LocalizationNet(Input)     # 子网络回归形变参数
Step 2: V = T_θ(Input)                  # 可微采样器对输入做 warp
```

关键的共同点：用 **可微的双线性采样**（`grid_sample`）保证梯度从后向前流通，使整个系统可端到端训练。换句话说，STN 和 CGM 共享同一段"基因"：

> "由一个子网络回归形变参数 → 用一个可微的几何变换作用于输入/特征。"

#### A.6.2 关键差异

| 维度 | STN (Jaderberg et al., 2015) | CGM (WUTON, 2019) |
|----|----|----|
| **任务场景** | 数字识别（MNIST）、通用分类 | 虚拟试衣 |
| **形变对象** | 通常作用于输入图像或浅层特征 | 作用于 Siamese 编码后的**多尺度特征图** |
| **对齐模式** | **单流自对齐**：θ 只依赖 Input 自身 | **双流交叉对齐**：θ 同时依赖 \(f_P\) 与 \(f_C\) |
| **形变类型** | 多为全局仿射（2×3 矩阵），偶用 TPS / 透视 | **稠密形变场**（或分层级 TPS / flow） |
| **形变粒度** | 全局，6 个参数 | **局部非刚性**，逐像素都有位移 |
| **使用位置** | 通常在网络最前面**一次性**做 | 在 U-Net 每一个 skip connection 上**多尺度**反复做 |
| **形变监督** | 无显式监督，靠下游分类 / 回归损失隐式驱动 | **显式监督**：匹配损失 + 形变平滑正则（\(c_t\) 已知） |

#### A.6.3 一句话理解差异

- **STN**：自己看自己，照镜子调整站姿（**自参照**），目的是增强对姿态的不变性；
- **CGM**：看了人的姿态，决定衣服该怎么变（**交叉参照**），目的是把一件衣服"搬"到另一个人的姿态上。

#### A.6.4 总结：CGM ≈ STN 的"强化版"

如果把 STN 看作 CGM 的"简化祖先"，可以一句话概括：

> **CGM ≈ 多尺度 STN + 交叉模态对齐 + 稠密非刚性形变 + 显式形变监督**

虚拟试衣对几何形变的要求远比"把数字摆正"复杂得多，所以 CGM 必须在三个维度上对 STN 做强化：

1. **从自对齐到交叉对齐**：θ 从依赖一张图变成依赖双流特征；
2. **从仿射到稠密形变场**：从全局刚性变换升级到逐像素非刚性；
3. **从单尺度到多尺度**：从网络最前端的一次性 warp 升级到每个 skip 都做一次，配合解码器上下文逐步修正。

理解了 STN，再看 CGM，就能感受到 WUTON 既保留了 STN 的 *"learn-to-warp"* 灵魂，又根据虚拟试衣的需求把它撑成了一套显著更复杂的几何模块。

## 附录 B：Siamese Network 与双分支编码器

### B.1 什么是 Siamese Network？

**Siamese Network（孪生网络）** 是 1990 年代 Bromley & LeCun 在签名验证中提出的**双分支架构**，本质特征是：

- **两个（结构相同）的子网络**分别处理两个输入；
- 两个子网络**共享权重**（或部分共享）；
- 两个子网络的输出被送入一个**比较/融合模块**得到最终结果。

```
   x1 (输入 1)             x2 (输入 2)
     │                       │
     ▼                       ▼
  ┌──────┐                ┌──────┐
  │  fθ  │ (权重共享)      │  fθ  │
  └──────┘                └──────┘
     │                       │
     ▼                       ▼
   fθ(x1)                 fθ(x2)
     │                       │
     └───────┬───────────────┘
             ▼
       ┌────────────┐
       │ Compare /  │ → 输出（相似度 / 距离 / 融合特征 / 决策）
       │  Fusion    │
       └────────────┘
```

最早期用于**度量学习**：让"同类样本"特征距离小、"异类样本"距离大。

### B.2 关键变体

| 变体 | 权重策略 | 用途 |
|----|----|----|
| **严格 Siamese** | 完全共享 | 度量学习、签名/指纹验证、ReID |
| **Pseudo-Siamese** | 不共享 | 两输入域差异较大时（如 RGB ↔ 深度） |
| **Siamese Encoder** | 共享编码器，解码器分开 | 生成任务中的**双分支编码**（WUTON 用法） |

WUTON 用的是第三种：编码器是 Siamese 的，但下游是 U-Net 解码 + 形变。

### B.3 在 WUTON 中的角色

WUTON 的编码器对**人体表征 \(P\)** 和**目标衣物 \(C\)** 分别用两个结构相同但**权重独立**的卷积塔提取特征：

```
    Person Rep P ─→ [Encoder P] ─→ {fP^1, fP^2, ..., fP^L}   (多尺度特征)
                                          ↘
                                       Concat / Fuse   (skip 形变后)
                                          ↗
    Clothing C ──→ [Encoder C] ─→ {fC^1, fC^2, ..., fC^L}   (多尺度特征)
```

为什么这里要**不共享权重**（Pseudo-Siamese）？

- 人体表征是"姿态热图 + 身体掩膜 + 脸/发 RGB"，强调**结构与空间布局**；
- 衣物图是"商品纹理 + 平面外观"，强调**颜色与图案**；
- 两者的**最优特征空间完全不同**，强行共享权重会互相拖后腿；
- 让两个分支各学各的，**解耦**这两类信息。

### B.4 与 CP-VTON 的对比

| 维度 | CP-VTON | WUTON |
|----|----|----|
| 编码方式 | 单流融合（一个 U-Net 同时处理人和衣） | **Siamese 双分支独立编码** |
| 信息耦合时机 | 编码早期 concat | 编码结束后 / skip connection 层面融合 |
| 优点 | 模型小、推理快 | 两种特征各自充分提取，**对齐更干净** |
| 代价 | 一路特征受另一路干扰 | 参数更多、显存更大 |

直觉上：**CP-VTON 是一杯混合果汁**，WUTON 是**两个独立榨汁机榨完再勾兑**。后者风味更分明。

### B.5 skip connection 上的几何形变

WUTON 的 Siamese Encoder 输出的多尺度特征 \(\{fP^l, fC^l\}_{l=1}^{L}\) 在每个尺度都会被：

1. **Convolutional Geometric Matcher** 预测该尺度下的形变参数 \(\theta^l\)；
2. 把 \(\theta^l\) 应用到 \(fC^l\) 上，得到 warp 后的衣物特征 \(\hat{fC}^l\)；
3. 把 \(\hat{fC}^l\) 与 \(fP^l\) **融合**（concat / 加权 / gated），送入 U-Net 解码器对应的 skip connection。

```
Siamese Encoder         CGM (per scale)         Decoder
─────────────         ───────────────         ────────
fP^1, fC^1 ──────────→ θ^1 ──→ warp fC^1 ──→ skip-1 ──┐
fP^2, fC^2 ──────────→ θ^2 ──→ warp fC^2 ──→ skip-2 ──┤
  ...                    ...                        ... │
fP^L, fC^L ──────────→ θ^L ──→ warp fC^L ──→ skip-L ──┤
                                                       ▼
                                                    U-Net 解码
                                                       ↓
                                                      Î
```

**多尺度形变**的好处：

- 浅层（小尺度 / 高分辨率）捕捉**局部对齐**（领口、袖口位置）；
- 深层（大尺度 / 低分辨率）捕捉**全局对齐**（肩宽、腰线位置）；
- 每层的几何误差可以被后续解码器**用上下文修正**，比一次性 warp 更鲁棒。

### B.6 何时该用 Siamese 双分支？

经验判断：

- ✅ **两路输入本质不同**（如人 ↔ 衣、RGB ↔ 深度、查询 ↔ 模板）；
- ✅ **下游任务需要两者各自充分表达**（生成、检索、密集预测）；
- ✅ 显存和算力允许；
- ❌ 如果两路输入分布接近（如同一场景的两个视角），**严格共享权重的 Siamese 更合适**，且更省参数；
- ❌ 如果下游任务是**高层决策**（分类、回归），单流 + late fusion 通常就够。

在虚拟试衣场景里，"人"和"衣"是**两类本质不同的视觉信息**，Siamese 双分支几乎成了标配；这跟通用 ReID 那种"同一类物体两幅图"用严格 Siamese 的情形形成对比。

## 附录 C：CP-VTON Correlation Matching vs WUTON 特征图几何形变

CP-VTON 的 **Correlation Matching**（A.3 已经详述）和 WUTON 的 **Convolutional Geometric Matcher** 是两套看起来很像、本质不同的"建模两路特征对应关系"的方案。本附录做**正面对比**：从一句话机制差异、关键属性摘要、13 维度对比表、为什么 WUTON 细节更优、何时该选哪套、一句话总结六个角度，把两者并排呈现。

> **演化谱**（VITON → CP-VTON → WUTON → PF-AFN → DCI-Net）见正文 [三篇工作的演化脉络](#三篇工作的演化脉络)。

### C.1 核心机制差异（一句话版）

> **CP-VTON**：把"对应关系"做成**显式张量（4D Cost Volume）** → 回归**稀疏参数（TPS）** → 在**像素空间** warp。  
> **WUTON**：把"对应关系"做成**稠密形变场（Flow Field）** → 直接在**特征空间** warp。  

二者建模"对应"的工具相同（卷积神经网络），但**对应对的产出形式、作用空间、训练方式**完全不同。

---

### C.2 CP-VTON Correlation Matching 关键属性

> 完整推导、4D Cost Volume 数学、回归网络结构详见 [A.3 Correlation Layer](#a3-correlation-layer--让匹配可微)。本节只列对比所需的"关键属性"。

- **显式对应**：4D cost volume 写出"人体每点 ↔ 衣服每点"的相似度；
- **稀疏参数化**：5×5=25 个 TPS 控制点，2N=50 维 θ；
- **像素级 warp**：TPS 在原图上对 \(c\) 做形变，warped 结果 \(\hat c\) 直接进入下一阶段；
- **两阶段训练**：GMM 单独训练 + TOM 单独训练。

---

### C.3 WUTON 的特征图几何形变（Convolutional Geometric Matcher）

> 完整架构图与数学推导详见 [WUTON 章节](#wutonwarping-u-net-for-virtual-try-on2019) 及 [A.4 / A.5](#a4-从-shape-context-tps-到-cp-vton-的-gmm)。本节只列对比所需的"关键属性"。

- **隐式对应**：没有显式 cost volume，CGM 把"哪里对哪里"直接编码进预测的形变场；
- **稠密形变**：每层都输出 \(H^\ell \times W^\ell \times 2\) 的 flow field，远比 50 维 TPS 灵活；
- **特征级 warp**：形变作用在 skip connection 的特征图上，而非原图；
- **端到端训练**：形变与合成在同一网络中联合优化，梯度可直接回传到 CGM。

---

### C.4 全方位对比

| 维度 | CP-VTON Correlation Matching | WUTON 特征图几何形变 (CGM) |
|:---|:---|:---|
| **网络阶段** | 两阶段：GMM（warp） + TOM（合成） | **单阶段**：端到端联合训练 |
| **对应建模方式** | **显式 4D Cost Volume** | **隐式**：CGM 直接输出形变场 |
| **产出形式** | 稀疏 TPS 参数（5×5 控制点，50 维） | **稠密 flow field**（\(H \times W \times 2\) 维） |
| **Warp 空间** | **像素空间**（对衣物原图 \(c\) 做 TPS 形变） | **特征空间**（对 skip connection 上的特征图做采样） |
| **Warp 次数** | 1 次（仅在最深层做一次 TPS） | **多次**（U-Net 每个 skip 都做一次） |
| **几何先验** | 强：TPS 是平滑样条，天然有低频约束 | 弱：flow field 无显式平滑，靠训练隐式学习 |
| **形变能力** | 有限：稀疏控制点难表达大姿态 | **强**：每层独立预测 flow，跨层多尺度形变 |
| **可解释性** | 高：可画出控制点漂移 | 低：稠密 flow 4 维流量难可视化 |
| **训练方式** | GMM 与 TOM 分阶段训练 | **端到端**联合训练 |
| **推理速度** | 较慢（GMM + TOM 两个前向） | **较快**（单网络一次前向） |
| **显存/参数** | 较低 | 较高（Siamese 编码器 + 多尺度 CGM） |
| **细节保留** | 中：像素 warp + L1 易模糊 | **强**：特征级 warp + decoder 合成，纹理保持更好 |
| **失败模式** | 大姿态变化下 TPS 不够 → 衣服"穿模" | 形变场估计不准 → 局部纹理错位 |

---

### C.5 为什么 WUTON 细节保留更优？

直觉上：

```
CP-VTON:  像素空间 warp ──→  L1/VGG 监督（取平均）──→  模糊
          像素本身被"硬拽"到目标位置，L1 损失"讨好"多解，
          导致高频纹理被均值化丢失。

WUTON:    特征空间 warp ──→  decoder 端到端合成 ──→  锐利
          特征图中编码了高层语义（"这件衣服的纹理是格子"），
          decoder 可以"按特征重新生成像素"，而非"按像素硬拽"。
```

更技术地说，有三个原因：

1. **梯度通路短**：合成损失 \(\mathcal{L}_{\text{syn}}\) 可以直接通过 decoder → skip → CGM 反向传播到形变场，**几何与合成联合优化**；CP-VTON 的 GMM 与 TOM 梯度解耦，合成误差难以影响 TPS 参数。
2. **多尺度形变**：浅层（高分辨率）捕捉局部对齐（领口、袖口位置），深层（低分辨率）捕捉全局对齐（肩宽、腰线）。每层几何误差可被后续解码器**用上下文修正**。
3. **特征空间的"语言"更丰富**：特征图中每个像素都是一个高维向量，warp 时携带的语义信息（颜色直方图、纹理方向、图案结构）远多于单像素 RGB；decoder 在合成时可以从这些特征"重新表达"出真实感。

> CP-VTON+ 后续引入的**二阶差分损失**正是想弥补第一点（梯度解耦）的不足，但收效有限，因为 TPS 形变本身已经过 "稀疏化"，表达能力瓶颈无法靠损失函数打破。

---

### C.6 何时该用哪一套？

经验判断：

- ✅ **CP-VTON 风格**（显式 cost volume + 稀疏 TPS）适合：
  - **形变范围小、几何结构刚性**的任务（如手写数字、票据对齐）；
  - 需要**显式可控的形变**（如可解释性、可干预的 TPS 控制点）；
  - 显存紧张、追求轻量的场景。

- ✅ **WUTON 风格**（隐式 CGM + 稠密 flow + 特征级 warp）适合：
  - **大姿态变化、复杂非刚性形变**的任务（虚拟试衣、视频驱动）；
  - 对**纹理细节保留**要求高；
  - 显存/算力允许端到端联合训练。

- ✅ **混合方案**：现代方法（PF-AFN、DCI-Net）基本都吸收了 WUTON 的思路——用**外观流/隐式对应**替代显式 cost volume，但保留**端到端可微**的优势。

---

### C.7 一句话总结

> **CP-VTON 的 correlation matching**：把"哪里对哪里"做成 4D 张量，再用它**回归稀疏 TPS 参数**，在**像素空间** warp 衣物。  
> **WUTON 的特征图几何形变**：用一个子网络**直接预测稠密 flow field**，在**特征空间** warp skip connection。  
> 前者**显式、稀疏、像素级**；后者**隐式、稠密、特征级**。后者在纹理细节与大姿态形变上显著占优，是后续 PF-AFN、DCI-Net 等工作的标配范式。
