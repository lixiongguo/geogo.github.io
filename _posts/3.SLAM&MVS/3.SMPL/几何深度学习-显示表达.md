> 与 [隐式表达](几何深度学习-隐式表达.md) 对照：本篇直接在**点云 / 参数曲面 / 三角网格**上学习或生成，输出本身就是离散几何（或可立即落成 mesh），而不是先学连续场再 Marching Cubes。  
> 线索：**点集生成（PSGN）→ 点云骨干（PointNet）→ 参数片拼表面（AtlasNet）→ 边上 CNN（MeshCNN）→ 谱几何 / 扩散层（HodgeNet / DiffusionNet）→ 序列化 mesh 生成（PolyGen）→ 着装人体多层重建（TightCap）**。OCCNet 属隐式，文末只作对照入口。

---

## 显式路线在做什么

| 表示 | 网络直接碰什么 | 典型任务 |
| :--- | :--- | :--- |
| 点云 | 无序点坐标 | 分类、分割、单视图重建 |
| 参数曲面 / atlas | 2D→3D 映射的片 | 表面生成、任意分辨率采样 |
| 三角网格 | 顶点 / 边 / 面特征 | 分割、对应、分类；或自回归生成整张 mesh |
| 模板 + 位移 / UV 场 | SMPL 等固定拓扑上的位移 | 人体 / 衣物多层重建 |

难点始终是：**置换不变、不规则邻域、拓扑可变**。下面按代表工作展开。

---

## PSGN（Point Set Generation Network）

> Fan, Su, Guibas, *A Point Set Generation Network for 3D Object Reconstruction from a Single Image*, CVPR 2017.

### 想法

单图重建时，绕开体素：网络**直接输出一组 3D 点坐标** \(\{p_i\}\)。点集无序、分辨率灵活，也不依赖固定拓扑。

单图对应的 3D 往往**多解**（背面不可见），因此更合适的目标是**条件形状采样器**：同一张图可吐出多种合理点云，而不是假装唯一 GT。

### 损失：对齐无序点集

不能用逐点 \(L_2\)（对应关系未知）。常用：

- **Chamfer Distance（CD）**：双向最近邻平方距离之和，可微、实现简单；  
- **Earth Mover’s Distance（EMD）**：最优运输意义上的一一匹配代价，更严但更贵。

训练上常 CD / EMD 组合或择一；生成多模态时用多种子 / 混合密度头采样。

### 位置

把「3D 输出 = 点坐标向量」立成标准设定之一；后续 PointNet 系做**分析**，PSGN 偏**生成 / 重建**。局限：无面片连接，要 mesh 仍需球泊松等后处理。

## PointNet

> Qi et al., *PointNet: Deep Learning on Point Sets for 3D Classification and Segmentation*, CVPR 2017.  
> 后续：**PointNet++**（分层采样 + 局部 PointNet）。

### 想法

点云是 \(\mathbb{R}^{N\times 3}\) 的**无序集合**。要对置换不变，结构必须满足：对点置换 \(\pi\)，

$$
f\bigl(\{x_{\pi(i)}\}\bigr)=f\bigl(\{x_i\}\bigr).
$$

PointNet 配方：

1. 每点共享 MLP，把 \(x_i\) 映到高维特征；  
2. **对称聚合**（通常 max pooling）得到全局描述子；  
3. 分类：全局特征 → MLP；分割：全局特征与每点特征拼接再 MLP。

另用小型 T-Net 预测对齐矩阵，减轻刚体位姿影响。

### 为何够用、又不够用

- **够用**：max 近似选「最显著」局部响应，分类 / 粗分割很强，实现极简。  
- **不够用**：单次全局池化几乎不建**局部邻域层次**；密度不均、细结构弱。PointNet++ 用 FPS 采中心 + 球邻域再套 PointNet，补上多尺度局部。

在「显式几何深度学习」里，PointNet 是点云侧的默认骨干；许多重建头（含与图像编码器对接）仍建立在「每点 MLP + 对称函数」之上。

## AtlasNet

> Groueix et al., *AtlasNet: A Papier-Mâché Approach to Learning 3D Surface Generation*, CVPR 2018.

### 想法

形状 = **多张可学习参数片（charts）** 的并集，像糊纸裱糊（papier-mâché）：

$$
\mathcal{S}
\approx
\bigcup_{k=1}^{K}
\phi_{\theta_k}\bigl([0,1]^2;\;\mathbf{z}\bigr),
\quad
\phi:\;\mathbb{R}^2\times\mathbb{R}^d\to\mathbb{R}^3.
$$

\(\mathbf{z}\) 来自点云 / 图像编码器；在单位正方形上采 \((u,v)\)，MLP 映射到表面上的点。片内规则网格可直接抬成三角网，故**分辨率任意、天然带拓扑（片内）**。

### 相对点云 / 体素

- 输出是**表面**，不是散点或占满体积的体素；  
- 参数域可挂 UV / 纹理 / 细分；  
- 片与片之间接缝、重叠、覆盖不全是主要痛点；复杂拓扑靠 \(K\) 张片硬拼，表达力有天花板。

PolyGen 等后文工作常拿 AtlasNet 作**表面重建基线**（Chamfer 等）；谱系上 AtlasNet 是「显式参数曲面」，OCCNet 是「隐式场」，两条分叉。

## OCCNet（对照入口）

> Mescheder et al., *Occupancy Networks*, CVPR 2019. **完整笔记见 [隐式表达 · OCCNet](几何深度学习-隐式表达.md#occnetoccupancy-networks)。**

把形状建成 \(f_\theta(\mathbf{x}\mid\mathbf{z})\in[0,1]\) 的占据场，再 MC 抽 mesh——属于**隐式**路线。放在显式大纲里，是为了对照：同是单视图 / 点云条件重建，AtlasNet / PSGN **直接吐表面或点**，OCCNet **吐可查询函数**。后续 DeepSDF、PIFu、UDF 都在隐式篇。

## MeshCNN

> Hanocka et al., *MeshCNN: A Network with an Edge*, SIGGRAPH / TOG 2019.

### 想法

三角网格上做真正的 CNN：**以边为「像素」**。流形三角网中每条边恰邻两个三角，从而有**固定大小的 4-邻域**（该边 + 两三角上另外四条边中的邻边结构），可定义边卷积。

- **卷积**：在边上聚集邻边特征，利用法向一致性构造对旋转 / 翻转较稳的算子；  
- **池化**：任务驱动的 **edge collapse**——学哪些边该塌，塌完拓扑仍合法，动态更新邻接供下一层用；  
- **反池化**：分割等任务可把粗边特征回投到细边。

输入常用边长、二面角等**内蕴几何**，不必先转点云。

### 位置

「网格分析」显式路线的代表：分类、分割直接吃 mesh。局限：依赖（近似）流形三角化；对重网格化敏感（同形状不同连边可能掉点）→ 后面 DiffusionNet 等强调**离散无关**。

## HodgeNet

> Smirnov, Solomon, *HodgeNet: Learning Spectral Geometry on Triangle Meshes*, SIGGRAPH / TOG 2021.

### 想法

少发明「不像几何处理」的算子，多接 **DEC（离散外微积分）** 标准件：用可学习的局部特征参数化 **Hodge star**，与固定外微分一起拼出 **Hodge Laplacian**，再取低阶特征对，做成类似 HKS / WKS 的谱描述，供分割 / 分类。

要点：

- 特征来自**可微的小规模特征分解**（带近似反传）；  
- 参数少，可直接吃较高分辨率网格；  
- 与经典谱几何同一语言，便于接到几何处理管线。

相对 MeshCNN：少「学坍边」的组合结构，多「学算子 → 谱特征」。代价是特征分解开销与近似梯度的实现复杂度。

## DiffusionNet

> Sharp et al., *DiffusionNet: Discretization Agnostic Learning on Surfaces*, TOG 2022.

### 想法

表面上信息传递用**可学习扩散时间**的扩散层，再加每点 MLP 与**空间梯度特征**（定向滤波），几乎不再手调邻域半径：

$$
\text{DiffusionNet block}
\;\approx\;
\mathrm{MLP}
\;\circ\;
\mathrm{Diff}_\tau
\;+\;
\text{gradient features}.
$$

宣称三点：

1. **采样无关**：换三角密度 / 连边仍稳，减轻 MeshCNN 式过拟合连边；  
2. **表示无关**：三角网与点云可共用思想（有梯度算子即可），甚至跨表示泛化；  
3. **实现相对简单**：谱加速预计算 Laplacian 特征后，扩散成对角缩放，训练快。

任务：可变形形状分割、分类、对应等。工程上常作为「稳健的表面骨干」替换脆弱的网格 CNN。

## PolyGen：序列化 Mesh 生成（Transformer）

> Nash, Ganin, Eslami, Battaglia (DeepMind), *PolyGen: An Autoregressive Generative Model of 3D Meshes*, ICML 2020.  
> [arXiv:2002.10880](https://arxiv.org/abs/2002.10880) · [代码](https://github.com/google-deepmind/deepmind-research/tree/master/polygen)

### 为什么重要

Mesh 对深度学习不友好：**顶点无序、面离散**。此前生成多走体素 / 点云 / 隐式，mesh 留给后处理。PolyGen **直接对顶点 + 面自回归建模**，把 PixelCNN / GPT 套路搬到 3D，用 Transformer 吃长程依赖（对称、重复部件）。在「Transformer × 3D mesh 生成」线上是较早的完整尝试；后续 MeshGPT 等仍沿 **序列化 mesh** 前进。

### 核心分解

\[
p(\mathcal{M})=p(\mathcal{F}\mid\mathcal{V})\,p(\mathcal{V}).
\]

1. **Vertex Model** 采样顶点；  
2. **Face Model** 以顶点为条件采样面索引。  
可选条件 \(h\)：类别 / 图像 / voxel。

```text
[可选 context h]
       ↓
 Vertex Transformer  →  顶点 (z,y,x) 序列 + stop
       ↓
 Face Transformer + Pointer  →  面索引序列 + new-face / stop
       ↓
   n-gon mesh（可直接用）
```

### n-gon 而非强制三角

用可变边数多边形：大平面一块面说完，并消掉多种 triangulation 带来的标签噪声。\(n>3\) 非共面时表面不唯一；实践中生成面多接近平面。

### Vertex Model

- 排序：\(z\) 升序，再 \(y\)、\(x\)；展平为 \((z,y,x,\ldots)+\) stop；  
- **8-bit 量化**坐标 → Categorical（类 WaveNet）；  
- Masked Transformer decoder；token 含坐标轴 / 顶点序号 / 取值三类 embedding；  
- 推理时可 mask 非法 logits（如 \(z\) 须单调）。

\[
p(V^{\mathrm{seq}})=\prod_n p(v_n\mid v_{<n}).
\]

### Face Model + Pointer

面索引词表大小 = 当前顶点数，**随样本变**，固定 Softmax 不够。用 **Pointer Network**：

1. Transformer encoder 得顶点 embedding \(\{e_v\}\)（含 new-face / stop）；  
2. Decoder 每步输出 pointer \(p_n\)；  
3. \(p(f_n=k)=\mathrm{softmax}_k(p_n^\top e_k)\)。

### 条件与实验印象

| 条件 | 注入 |
| :--- | :--- |
| 类别 | embedding 加到各层 |
| 图像 / voxel | 编码器序列 + cross-attention |

ShapeNet 上约 **4.26 bits/vertex**，坐标 / 索引下一步准确率约 85% / 90%；增强很关键。观感上比 Occupancy+MC 更像「人建的紧凑多边形」。

### 局限

序列二次复杂度、8-bit 精度、顶点错则面难救、难上超大 mesh。历史位置：

```text
点云 / atlas / 隐式生成
        ↓
PolyGen（2020）：AR Transformer 直接建 mesh
        ↓
MeshGPT、更强 tokenization / 扩散式 3D …
```

**一句话**：PolyGen = 量化坐标自回归 + Pointer 可变拓扑面生成，证明「mesh 当序列」可行。

## TightCap

> Chen et al., *TightCap: 3D Human Shape Capture with Clothing Tightness Field*, TOG / SIGGRAPH 2022.  
> 输入是**完整 3D 扫描 mesh**（多视 RGB 重建或深度融合），属显式网格管线上的人体应用。

### 想法

单次着装扫描上，同时恢复**贴身人体**与**服装层**。关键量是 **clothing tightness field**：服装到身体的位移，建在**全局 UV / geometry image** 域，而不是在混乱的 3D 欧氏邻域里硬回归。

流程概要：

1. 增强 SMPL 模板（衣边：领、腕、腰、踝等加密），多阶段对齐到扫描（骨架 / 轮廓 / 几何）；  
2. 扫描映成 hybrid **clothed geometry image**（位置、法向、纹理等）；  
3. 条件网络（含 GAN）在 UV 域回归 tightness；  
4. 再优化得到多层：内层身体 + 外层衣物，支持分割、重定向、动画。

配套 **Clothing Tightness Dataset（CTD）**：多样服装、姿态与真值身体。

### 与本篇其它工作的关系

| | MeshCNN / DiffusionNet | PolyGen | TightCap |
| :--- | :--- | :--- | :--- |
| 角色 | 通用网格**分析**骨干 | 通用物体 **mesh 生成** | 人体扫描 **多层分解** |
| 拓扑 | 输入已有 mesh | 从零生成 n-gon | 绑在 SMPL UV 上 |
| 和隐式人体 | 可作特征提取 | 少直接比 | 对照 PIFu 等：TightCap 吃 3D 扫描，PIFu 吃图像 |

着装数字化里：PIFu（隐式篇）走图像→场；TightCap 走**扫描 mesh → UV tightness → 身体+衣**，两条工程路径。

## 小结

```text
图像 / 扫描
  ├─ 点：PSGN 生成 · PointNet 分析
  ├─ 参数片：AtlasNet
  ├─ 三角网分析：MeshCNN → HodgeNet / DiffusionNet（更稳、更几何）
  ├─ 三角网生成：PolyGen（序列 + Transformer）
  └─ 人体多层：TightCap（SMPL UV + tightness）
隐式场（OCCNet / DeepSDF / PIFu / UDF）→ 见另一篇
```

| 方法 | 显式对象 | 网络形态 | 典型用途 |
| :--- | :--- | :--- | :--- |
| PSGN | 点集 | CNN 编码器 + 点解码 | 单图点云重建 |
| PointNet(++) | 点集 | 共享 MLP + 对称聚合 / 分层 | 分类、分割 |
| AtlasNet | 多张参数曲面 | 条件 MLP charts | 表面生成、任意分辨率 |
| MeshCNN | 边特征 | 边卷积 + 塌边池化 | mesh 分类 / 分割 |
| HodgeNet | 谱特征 | 可学习 Hodge 算子 | 高分辨率网格分析 |
| DiffusionNet | 表面点特征 | 扩散层 + 梯度特征 | 稳健分割 / 对应 |
| PolyGen | 顶点+面序列 | Transformer + Pointer | 直接生成可用 mesh |
| TightCap | 扫描 + UV 场 | 对齐 + GAN tightness | 身体与衣物多层重建 |

**一句话**：显式路线让网络直接读写点、参数片或网格（边/谱/序列/UV）；从 PSGN/PointNet 的点集，到 MeshCNN/DiffusionNet 的网格分析，再到 PolyGen 的 mesh 生成与 TightCap 的着装分解，和隐式场路线互补——一个要**立即可用的离散几何**，一个要**分辨率解耦的连续表示**。
