# MVSNet

> Yao Yao, Zixin Luo, Shiwei Li, Tian Fang, Long Quan.  
> *MVSNet: Depth Inference for Unstructured Multi-view Stereo*, ECCV 2018.  
> [arxiv](https://arxiv.org/abs/1804.02505) · [code](https://github.com/YoYo000/MVSNet)

深度学习多视图立体（MVS）里，把「逐参考视角深度图估计」做成端到端可微管线的里程碑工作。核心：用**可微单应 warp** 把多视角 2D 特征搬到参考相机视锥上的假想深度平面，堆成 3D **代价体（cost volume）**，再用 3D CNN 正则化并回归深度。

## 1. 问题设定

输入：一张参考图 $I_1$，若干源图 $\{I_i\}_{i=2}^{N}$，以及对应相机 $\{K_i,R_i,t_i\}$（通常来自 SfM）。  
输出：参考视角的稠密深度图 $D$，再经滤波与多视角融合得到点云。

与 SurfaceNet / LSM 等「把整场景塞进规则体素」不同，MVSNet **一次只解一个参考视角的深度**，场景规模由多视角深度图融合承担，更适合大场景。

和传统 PatchMatch / SGM 对比：

| | 传统深度图 MVS | MVSNet |
|:---|:---|:---|
| 匹配线索 | NCC 等手工度量 | CNN 特征 + 方差代价 |
| 正则化 | SGM / MRF / 传播 | 多尺度 3D CNN |
| 相机几何 | 显式平面扫描 | 可微单应，端到端 |
| 弱纹理 / 反光 | 易空洞 | 语义特征补全更好 |

## 2. 网络总览

```text
{I_i} ──► 共享 2D CNN ──► {F_i}
                              │
                    可微 Homography Warp（按深度假设 d）
                              │
                         特征体 {V_i}
                              │
                      方差代价度量 ──► C
                              │
                     3D U-Net 正则化 ──► P（概率体）
                              │
                      soft-argmin ──► D_init
                              │
                 参考图引导残差细化 ──► D
```

## 3. 特征提取

- 8 层 2D CNN，参数在所有视角间共享。
- 第 3、6 层 stride $=2$，特征分三档尺度；每档内两层卷积。
- 输出：$N$ 张 **32 通道**特征图，相对输入在 $H,W$ 上各下采样 **4 倍**。
- 像素邻域信息已编码进 32 维描述子，再做匹配时不会像「原图像素平面扫描」那样丢上下文。

## 4. 代价体：视锥 + 可微单应

代价体建在**参考相机视锥（frustum）**上，而不是欧氏空间规则体素——因为目标是深度图，不是整体体素占用。

对每个深度假设 $d$，把各视角特征 warp 到参考相机的正视平面，得到特征体 $\{V_i\}$。坐标映射：

$$
\mathbf{x}' \sim \mathbf{H}_i(d)\,\mathbf{x}.
$$

单应（平面扫描同型）：

$$
\mathbf{H}_i(d)
= K_i R_i
\left(
I - \frac{(t_1 - t_i)\,n_1^{\mathsf T}}{d}
\right)
R_1^{\mathsf T} K_1^{-1},
$$

其中 $n_1$ 为参考相机光轴方向。参考视角自身对应 $\mathbf{H}_1(d)=I$。采样用**可微双线性插值**，梯度可回传到 2D 特征与（若需要）相关参数。

### 方差代价度量

任意 $N$ 个特征体聚成一个代价体 $C$（尺寸与单个特征体相同）：

$$
C = \mathcal{M}(V_1,\ldots,V_N)
= \frac{1}{N}\sum_{i=1}^{N}(V_i - \bar V)^2,
$$

$\bar V$ 为各视角特征体的均值，运算逐元素。设计要点：

- **各视角对称**，不给参考图特殊地位；
- 方差直接刻画「多视角特征不一致程度」，比「先均值再靠额外 CNN 猜相似度」更显式。

记输入宽高为 $W,H$，深度采样数为 $D$，特征通道 $F$，则特征体大小约为 $\tfrac{W}{4}\times\tfrac{H}{4}\times D\times F$。

## 5. 3D 正则化与深度回归

原始代价体受遮挡、非朗伯等污染，需平滑约束。网络用类似 **3D U-Net** 的四尺度 encoder–decoder 聚合大感受野上下文：

- 首层后把 32 通道压到 8，降低算力；
- 末层输出 1 通道，再沿深度维 **softmax** 得概率体 $P$。

深度用 **soft-argmin**（概率加权期望），可微且可亚像素：

$$
D = \sum_{d=d_{\min}}^{d_{\max}} d \cdot P(d).
$$

训练时深度假设在 $[d_{\min},d_{\max}]$ 上均匀采样；期望给出连续深度。输出分辨率与特征图一致（相对输入 $\times 1/4$）。

### 概率图（光度置信）

正确匹配的 $P(\cdot)$ 常呈单峰；错误匹配则分散。用估计深度附近 **4 个最近假设**的概率之和作置信度，便于后续阈值滤除飞点。

### 参考图引导细化

3D CNN 大感受野易使边界过平滑。将初始深度（先归一化到 $[0,1]$）与下采样参考图拼成 4 通道，经几层 2D 卷积学**深度残差**，再加回初始深度。末层无 BN/ReLU，以便学负残差。

## 6. 损失

仅在有效 GT 像素上算 L1：

$$
Loss
= \sum_{p\in p_{\mathrm{valid}}}
\bigl(
\|d(p)-\hat d_i(p)\|_1
+ \lambda\|d(p)-\hat d_r(p)\|_1
\bigr),
$$

$\hat d_i,\hat d_r$ 分别为细化前后深度，$\lambda=1$。

## 7. 训练与后处理要点

**数据（DTU）**：由 GT 点云 + 法向 → SPSR 网格 → 渲染到各视角得深度监督。训练常用 $N=3$，分辨率裁到 $640\times 512$，深度假设约 $425\text{–}935\,\mathrm{mm}$、$2\,\mathrm{mm}$ 间距（$D=256$）。输入尺寸需能被 32 整除（特征下采样 + 多尺度 3D 结构）。

**选视图**：按稀疏点基线角打分，偏好合适夹角的像对（论文用分段高斯）。

**滤波**：

1. **光度**：概率低于阈值（如 $0.8$）剔除；
2. **几何**：投到邻域视角再投回，要求重投影像素误差与相对深度误差同时小，且至少与若干视角一致（文中至少三视角）。

**融合**：可见性融合（如 Merrell 类），多视角一致深度平均后反投影成点云。

评测：DTU（精度 / 完整度）、Tanks and Temples（无微调也能泛化，是当时亮点之一）。

## 8. 局限与后续

- 代价体显存随 $W\cdot H\cdot D\cdot F$ **近似立方增长**，高分辨率输入吃紧。后续三条主线：
  - **R-MVSNet**：沿深度用 RNN/GRU 扫 2D 代价，显存与 $D$ 解耦，但更慢；
  - **CasMVSNet**：级联代价体，粗到细收窄假设范围、抬高分辨率（见 [CASMVSNet.md](CASMVSNet.md)）；
  - **PatchmatchNet**：放弃稠密 3D 体正则，把传统 PatchMatch 做成可学习多尺度级联（见 [PatchMatchNet.md](PatchMatchNet.md)）——每像素只维护少量假设，靠自适应传播 / 评价，高分辨率下往往更快更省显存。
- 输出深度仍是特征分辨率量级，边界依赖 2D 细化。
- 方差度量、soft-argmin、视锥代价体成为后续大量 MVSNet 系工作的默认组件；PatchmatchNet 则改用分组相关 + 视角权重，并回到「传播式」搜索。

## 9. 一句话

**可微平面扫描 + 方差代价体 + 3D CNN + soft-argmin**：把非结构化多视图深度估计收成一条可训练的深度图管线。
