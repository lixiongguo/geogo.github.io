# CasMVSNet（Cascade Cost Volume）

> Xiaodong Gu, Zhiwen Fan, Siyu Zhu, Zuozhuo Dai, Feitong Tan, Ping Tan.  
> *Cascade Cost Volume for High-Resolution Multi-View Stereo and Stereo Matching*, CVPR 2020.  
> [arxiv](https://arxiv.org/abs/1912.06378) · [code](https://github.com/alibaba/cascade-stereo)

针对 MVSNet 一类「单次巨型 3D 代价体」的显存 / 时延瓶颈，提出**级联代价体（cascade cost volume）**：由粗到细多阶段构造代价体，逐级收窄深度假设范围、加密平面间距、提高空间分辨率。挂到 MVSNet 上即常说的 **CasMVSNet / MVSNet+Ours**；同一思想也可接到 PSMNet、GwcNet 等双目网络。

## 1. 动机

标准代价体尺寸约 $W\times H\times D\times F$。提高空间分辨率、加密深度采样都会让 3D CNN 的显存与时间近似立方涨。常见折中：

- 特征大幅下采样建代价体，再上采样 / 2D 细化（细节与几何一致性打折）；
- 换表示（如 Point-MVSNet 的点基细化）或沿深度 RNN（R-MVSNet）。

CasMVSNet 的观察：**整段深度范围不必在每一阶段用同样密的采样铺满**。粗阶段用大间隔扫全域；细阶段只在上一阶段深度附近的窄带内加密，同时提高特征分辨率。计算力花在「更可能正确」的区域上。

相对 MVSNet（论文报告量级，输入约 $1152\times 864$）：

| | MVSNet | MVSNet + Cascade |
|:---|:---|:---|
| DTU overall | 基线 | 约 **+35.6%**（相对改进） |
| GPU 显存 | 约 10.8 GB | 约 **−50.6%** |
| 推理时间 | 约 1.21 s | 约 **−59.3%** |

## 2. 级联代价体：三个旋钮

第 $k$ 阶段有假设深度范围 $R_k$、平面间距 $I_k$、平面数

$$
D_k = R_k / I_k.
$$

递推：

$$
R_{k+1} = R_k \cdot w_k,\quad w_k < 1,
\qquad
I_{k+1} = I_k \cdot p_k,\quad p_k < 1.
$$

空间分辨率随阶段升高（共 $N$ 阶段时，第 $k$ 阶段约为）

$$
\frac{W}{2^{N-k}} \times \frac{H}{2^{N-k}}.
$$

MVS 默认 **$N=3$**；双目实验常用 **$N=2$**。

直观上：

1. **Stage 1**：低分辨率特征、少而稀的深度面，覆盖**整段**深度范围 → 粗深度；
2. **Stage 2+**：以上一阶段深度为中心，缩小 $R$，减小 $I$，提高 $H,W$ → 残差式加密。

论文统计：粗阶段后，绝对深度误差分布相对全深度范围可收窄约一个数量级，因此后续 $R_k$ 可以大幅缩小而不丢太多可纠正误差。

## 3. 接到 MVSNet：CasMVSNet

整体仍是「特征 → warp → 方差代价 → 3D 正则 → soft-argmin」，但**重复多级**，且特征来自金字塔。

```text
输入图像
   │
   ▼
Feature Pyramid ──► P1 (1/16) , P2 (1/4) , P3 (1)
   │
   ├─ Stage1: P1 上建代价体 (稀疏 D) ──► D¹
   │
   ├─ Stage2: 以 D¹ 为中心窄带 + P2 ──► D²
   │
   └─ Stage3: 以 D² 为中心更窄带 + P3 ──► D³（最终）
```

### 训练时典型设置（论文）

| 阶段 | 深度假设数 $D_k$ | 间距相对原 MVSNet | 特征分辨率 |
|:---:|:---:|:---:|:---:|
| 1 | 48 | $\times 4$ | $1/16$ |
| 2 | 32 | $\times 2$ | $1/4$ |
| 3 | 8 | $\times 1$ | $1$（全分辨率） |

训练输入常 $N=3$ 视角、$640\times 512$。选视图与预处理沿用 MVSNet。

### 级联单应

第 $k+1$ 阶段在像素 $m$ 上，以上一阶段深度 $d_m^{k}$ 为中心，学习残差 $\Delta_m^{k+1}$：

$$
\mathbf{H}_i\!\left(d_m^{k}+\Delta_m^{k+1}\right)
=
K_i R_i
\left(
I - \frac{(t_1-t_i)\,n_1^{\mathsf T}}{d_m^{k}+\Delta_m^{k+1}}
\right)
R_1^{\mathsf T} K_1^{-1}.
$$

双目情形同理：在视差上变成 $X_l - (d_m^{k}+\Delta_m^{k+1})$ 的横向平移。

### 损失

每阶段都监督：

$$
Loss = \sum_{k=1}^{N} \lambda_k\, L_k,
$$

$L_k$ 与骨干网络一致（MVS 侧通常为有效像素上的深度 L1 / smooth-L1）。

消融提示：各阶段 3D 正则**不共享权重**更好；仅「拆成多段 cascade」而空间分辨率不变，收益有限；**升高空间分辨率**对精度更关键，FPN 特征再小幅加分。

## 4. 与传统粗到细 / 工业管线的关系

| 概念 | 传统几何 MVS | CasMVSNet |
|:---|:---|:---|
| 粗到细 | 图像金字塔 + PatchMatch 传播 | 特征金字塔 + 级联代价体 |
| 假设范围 | 由稀疏点 / 邻域传播隐式收窄 | 显式 $R_k,I_k,D_k$ 调度 |
| 正则 | 平滑项 / SGM | 每级 3D CNN |

在「SfM → 深度 → 融合 → 网格」管线里，CasMVSNet 常作为稠密深度模块：位姿与深度范围来自 COLMAP / OpenMVG 等；深度后处理仍可用光度 / 几何一致性过滤 + fusibile 类融合。

实践上常见加强（非论文原文，产线侧）：

- 骨干换成多尺度 U-Net，加强弱纹理；
- NAS / 剪枝换轻量结构换推理速度；
- 与前景 mask、bbox 联用，减少背景深度泄漏。

## 5. 为何省显存（直观）

- 粗阶段 $D$ 远小于「一次铺满全域的高密采样」（如 48 vs 192），低分辨率下显存小。
- 细阶段虽提高 $H,W$，但 $R$ 已大幅缩小，$D$ 可以很少（如 8），总体积仍小于单次全分辨率 $\times$ 全深度采样。
- 可用阶段数、$R_k$、$I_k$、分辨率在精度与时延之间折中。

## 6. 双目侧一笔带过

同一 cascade 接到 PSMNet / GwcNet / GANet 等：两阶段视差假设、由粗到细收窄视差带，Scene Flow / KITTI 上可同时降 EPE 与显存。MVS 与 stereo 共享的是「代价体调度」，不是同一套网络权重。

## 7. 局限

- 粗阶段若系统性偏到错误盆地，细阶段窄带可能救不回来 → $R_2,R_3$ 要留安全余量（论文用误差分布 / inlier 曲线定范围）。
- 仍依赖已知相机；位姿误差会传到所有阶段。
- 极高分辨率、极大基线变化时，阶段超参需重标定。

## 8. 与 MVSNet 对照（记）

| | MVSNet | CasMVSNet |
|:---|:---|:---|
| 代价体 | 单次 | 多级 cascade |
| 深度采样 | 全域均匀密采样 | 粗稀 → 细密、范围收缩 |
| 特征尺度 | 基本单档（下采样特征） | FPN 多分辨率 |
| 高分辨率 | 显存墙 | 可输出全分辨率深度 |
| 地位 | 可微 MVS 范式奠基 | 高分 / 高效代价体标配组件 |

## 9. 一句话

**不要一次建满分辨率 × 全深度的立方体；用级联把假设范围收窄、分辨率抬高，在更小总体积上得到更细的深度。**
