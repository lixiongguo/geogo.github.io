# SGM（Semi-Global Matching）

> Heiko Hirschmüller.  
> *Stereo Processing by Semi-Global Matching and Mutual Information*, IEEE TPAMI 2008（前身 CVPR 2005/2006）.  
> 工业与开源中极常用的稠密立体基线（OpenCV `StereoSGBM`、航空航天测绘、不少 MVS 预处理）。

**半全局匹配**：用多方向一维路径上的动态规划，近似二维全局平滑能量——比纯局部窗口更抗噪声 / 弱纹理，比 Graph Cuts / BP 等全二维全局优化快得多。复杂度约 $O(WHD)$（$D$ 为视差层数）。

## 1. 在立体四步里的位置

Scharstein–Szeliski 管线：

1. 匹配代价  
2. 代价聚合  
3. 视差优化 / 选取  
4. 视差细化  

SGM 的特色在 **2–3**：像素级代价 $C(p,d)$ 之上，用**多方向路径能量**做聚合，再 WTA；常配左右一致性、亚像素抛物线、孔洞插值等后处理。

## 2. 想近似的全局能量

理想全局能量（示意）：

$$
E(D)
= \sum_p C\bigl(p, D(p)\bigr)
+ \sum_{(p,q)\in\mathcal{N}} V\bigl(D(p), D(q)\bigr).
$$

平滑项通常鼓励相邻视差相等或缓变，大跳变付更高代价。二维 MRF 精确最小是难问题。  
**SGM 想法**：沿图像上多条一维路径分别做类似 DP 的最优，再把各方向代价相加，近似各向同性的二维平滑。

## 3. 路径代价递推（核心公式）

方向 $\mathbf{r}$（如左、右、上、下及对角，常用 **8 或 16** 向）。到达像素 $p$、视差 $d$ 的路径代价：

$$
\begin{aligned}
L_{\mathbf{r}}(p,d)
&= C(p,d)
+ \min\begin{cases}
L_{\mathbf{r}}(p-\mathbf{r},\, d) \\
L_{\mathbf{r}}(p-\mathbf{r},\, d-1)+P_1 \\
L_{\mathbf{r}}(p-\mathbf{r},\, d+1)+P_1 \\
\min_i L_{\mathbf{r}}(p-\mathbf{r},\, i)+P_2
\end{cases}
\\
&\quad - \min_k L_{\mathbf{r}}(p-\mathbf{r},\, k).
\end{aligned}
$$

含义：

| 项 | 含义 |
|:---|:---|
| $C(p,d)$ | 当前像素匹配代价 |
| 同视差无惩罚 | 鼓励平坦 |
| $\pm 1$ 视差 $+P_1$ | 小倾斜 / 缓变（$P_1$ 较小） |
| 任意其它视差 $+P_2$ | 大跳变 / 深度不连续（$P_2>P_1$） |
| 减去 $\min_k L(\cdot)$ | 数值稳定，不改变该像素上 argmin |

聚合：

$$
S(p,d)=\sum_{\mathbf{r}} L_{\mathbf{r}}(p,d),
\qquad
D(p)=\arg\min_d S(p,d).
$$

亚像素：在 $d^\star\pm 1$ 上对 $S$ 拟合抛物线取连续视差。

实现上可正向扫（左、上、左上等）再反向扫，两遍覆盖 8 向；每像素每方向 $O(D)$，总复杂度 $O(WHD)$。

## 4. 匹配代价 $C(p,d)$

| 代价 | 特点 |
|:---|:---|
| **BT**（Birchfield–Tomasi） | 采样不敏感的强度差；快 |
| **Census / Hamming** | 对局部光照单调变化稳健；嵌入式常用 |
| **Mutual Information** | 原文强调；抗较大辐射差异，需估计联合分布，算力更高 |
| 梯度 / 组合 | 实践中常见 BT+Census 等 |

原文 MI：用互信息度量左右强度对应，经近似变成可逐像素查表的代价，对曝光 / 增益差更稳（航拍等场景重要）。

$P_2$ 常随强度梯度自适应：边缘处降低大跳变惩罚，利于物体边界。

## 5. 后处理（实践里几乎必做）

1. **左右一致性**：左视差投到右再投回，不一致标为遮挡 / 误匹配。  
2. **去斑 / 中值**：去孤立飞点。  
3. **孔洞插值**：用邻域有效视差填遮挡区（注意前景膨胀偏差）。  
4. **强度一致选视差**：结构化场景里减弱条纹伪影。  
5. **多基线**：多对立体各自 SGM，再融合视差（或正交投影融合，原文大图重建）。

## 6. 与局部方法 / 全局方法对比

| | 局部窗口 | **SGM** | Graph Cuts / BP |
|:---|:---|:---|:---|
| 平滑 | 窗内隐式 | 多向 1D 近似 2D | 真 2D MRF |
| 速度 | 很快 | **线性于 $WHD$，实用快** | 通常慢很多 |
| 条纹 | 少 | 少（多向抵消单扫线 DP 条纹） | 少 |
| 弱纹理 | 差 | **明显更好** | 最好（代价高） |

「Semi-Global」：比 scanline DP 更全局，比完整二维推断更便宜。

## 7. 多视图与后续

- 经典 MVS：平面扫描得代价体后，可用 SGM 式沿深度 / 视差正则（或每像对 SGM 再融合）。  
- OpenMVS / 部分 SfM-MVS 管线仍可见 SGM 或类 SGM 聚合。  
- 学习立体：SGMNet 等把 $P_1,P_2$ 或路径聚合做成可学习；GCNet / PSMNet 用 3D CNN 正则代价体，可视为数据驱动的「更重的全局聚合」。  
- 与 PatchMatch：SGM 在**离散视差假设**上做路径 DP；PatchMatch 在**连续平面假设**上做传播搜索——一个偏「规则代价体 + 平滑」，一个偏「稀疏假设 + 空间相干」。

## 8. 调参直觉

- $P_1$：过小 → 噪声视差抖动；过大 → 斜面被拉平。  
- $P_2$：过小 → 碎片化；过大 → 跨越边界拖影。  
- 路径数：8 通常够用；16 略好、更慢。  
- 窗代价 vs 像素代价：SGM 设计偏向**像素级 $C$**，靠路径平滑；若 $C$ 已是大窗聚合，边界易糊。

## 9. 一句话

**多方向一维 DP 路径代价相加，用 $P_1/P_2$ 编码缓变与跳变，近似二维平滑全局立体——速度与质量之间的工业甜点。**
