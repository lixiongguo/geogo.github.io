# 路径追踪（Path Tracing）

> Pharr, Jakob, Humphreys. *Physically Based Rendering: From Theory to Implementation*, 3rd ed. (PBRTv3)  
> 主要章节：§14.4 光传输方程 · §14.5 Path Tracing · 实现：`integrators/path.h`、`PathIntegrator`  
> 在线书：[Path Tracing](https://www.pbr-book.org/3ed-2018/Light_Transport_I_Surface_Reflection/Path_Tracing)  
> 相关：[双向路径追踪.md](双向路径追踪.md) · [光子映射.md](光子映射.md)

Kajiya (1986) 在提出光传输方程（LTE）的同篇论文中给出了路径追踪：从相机出发，按 BSDF 逐步构造路径，用蒙特卡罗估计无限长路径和中的各项。它是第一个通用的**无偏** MC 光传输算法，也是理解 [BDPT](双向路径追踪.md) 与路径空间积分的基础。

## 1. 从 LTE 到路径积分

### 1.1 能量平衡形式（§14.4.1）

无参与介质时，出射辐射亮度 = 自发光 + 入射经 BSDF 散射：

$$
L_o(p,\omega_o)=L_e(p,\omega_o)+\int_{S^2}f(p,\omega_o,\omega_i)\,L_i(p,\omega_i)\,|\cos\theta_i|\,\mathrm{d}\omega_i.
$$

自由空间中辐射沿射线守恒，$L_i(p,\omega_i)=L_o(t(p,\omega_i),-\omega_i)$，于是只剩表面上的出射辐射未知量（式 14.13）。

### 1.2 面积形式与路径形式（§14.4.3–14.4.4）

把方向积分换成场景表面面积积分，引入几何耦合项

$$
G(p\leftrightarrow p')=V(p\leftrightarrow p')\,\frac{|\cos\theta|\,|\cos\theta'|}{\|p-p'\|^2},
$$

得到三点形式，再反复代入，展开为**不同长度路径贡献之和**（式 14.16）：

$$
L=\sum_{k=1}^{\infty}\int_{\mathcal{M}^{k+1}}L_e(p_k\to p_{k-1})\,T(\bar{p})\,\mathrm{d}A(p_0)\cdots\mathrm{d}A(p_k),
$$

其中路径 $\bar{p}=p_0,\ldots,p_k$（$p_0$ 在相机，$p_k$ 在光源），吞吐量

$$
T(\bar{p})=\Biggl(\prod_{i=1}^{k-1}f(p_i)\,G(p_{i}\leftrightarrow p_{i+1})\Biggr)G(p_0\leftrightarrow p_1).
$$

路径空间视角下：只要能以正概率采到贡献非零的路径并正确除以 PDF，估计就是无偏的——从相机走、从灯光走、两端对接，只影响权重，不改变正确性。

## 2. 两条采样思路（§14.5.2–14.5.3）

### 2.1 按面积直接采顶点（概念上）

在场景表面上按面积密度采 $p_1,\ldots,p_{k-1}$，最后在发光面上采 $p_k$。理论上无偏，但实践问题大：

| 问题 | 后果 |
|:---|:---|
| 相邻顶点常被墙挡住 | 大量路径贡献为 0，方差极高 |
| 点光源 / 镜面 delta | 面积采样几乎永远采不到 delta 支撑 |
| 高光 BSDF / 小面光源 | 贡献极低的路径占多数 |

### 2.2 增量构造（PBRT 实际采用）

从相机交点 $p_1$ 出发：在当前顶点按 **BSDF 立体角** 采样方向，射线求最近交得下一顶点。这样：

- 射线追踪**隐式重要性采样**了可见性 $V$（相邻顶点一定可见）；
- 立体角 PDF 转到面积测度需乘雅可比 $|\cos|/r^2$，正好与 $G$ 中多数项相消；
- 末端顶点仍用专门的**直接光照采样**接到灯上（否则小灯方差爆炸）。

一条长度为 $k$ 的路径估计量（示意，式 14.19）：相机侧吞吐量 × 灯上 $L_e$ / 灯采样 PDF，再乘连接处 BSDF 与几何项。

## 3. PathIntegrator 算法结构（§14.5.4）

```text
L ← 0,  β ← 1,  ray ← 相机射线,  specularBounce ← false
for bounces = 0, 1, 2, …:
  求交 isect
  if bounces==0 或 上一跳是镜面:
      累加 β · Le（可见发光 / 环境光）   // 直接光照采样覆盖不了的 delta 情况
  if 未交或 bounces ≥ maxDepth: break
  计算 BSDF；无 BSDF 的介质界面则跳过不计 bounce
  L += β · UniformSampleOneLight(...)   // 显式直接光（MIS）
  采样 BSDF → wi, pdf
  β *= f |cos| / pdf
  specularBounce ← 是否镜面分量
  ray ← SpawnRay(wi)
  if bounces > 3: Russian roulette 终止并重加权 β
return L
```

### 3.1 路径吞吐量 $\beta$

$$
\beta=\prod\frac{f\,|\mathbf{n}\cdot\omega_i|}{p(\omega_i)}.
$$

只存当前 $\beta$ 与上一顶点，不必存整条顶点链；最终某次直接光照贡献乘上当前 $\beta$ 即该路径项。

### 3.2 为何「发光」只在特定时候加

非镜面顶点上，`UniformSampleOneLight` 已经估计了**显式直接光**。若每跳再把命中的 `Le` 全加上，会**重复计数**。例外：

1. **bounces == 0**：相机直接看到的发光体，只能在此计入；
2. **上一跳是镜面**：上一跳的直接光采样无法处理 BSDF 中的 Dirac，必须在本跳把命中灯的 `Le` 加上。

环境光逃逸同理。

### 3.3 路径复用与相关性

估计 $\sum_k P_k$ 时，长度 $k$ 的路径复用长度 $k-1$ 的前缀，只再追一条射线。引入项间相关，略损估计质量，但射线数大减，**效率**通常更高。

### 3.4 Russian roulette（§13.7 / 14.5.1）

无限和不可穷举。物理上路径越长平均贡献越小（能量守恒）。PBRT：`bounces > 3` 后以

$$
q=\max(0.05,\ 1-\beta_Y)
$$

概率终止；未终止则 $\beta\leftarrow\beta/(1-q)$。低 $\beta$ 路径更易停；最小 $q$ 保证即便 $\beta$ 很大也能终止。

另有 `maxDepth` 硬上限（调试或截断高阶散射）。

## 4. 直接光与 MIS

`UniformSampleOneLight` 在「采灯」与「采 BSDF」之间做多重重要性采样（MIS），降低小灯 / 高光场景方差。这与「纯 BSDF 碰运气撞灯」相比是路径追踪实用化的关键之一。

次表面：若透射进 BSSRDF 材质，在 `pi` 上再做一次直接光与 BSDF 续径（§15.4.3）。

## 5. 方差与适用场景

| 情形 | 路径追踪表现 |
|:---|:---|
| 大面积灯、漫反射为主 | 通常很好 |
| 灯照天花板一小块再间接照房间（图 16.12） | 极难采到「第二末顶点落在亮斑」，噪声大 → 宜 [BDPT](双向路径追踪.md) |
| 点灯 + 玻璃后漫反射（镜面–漫–镜面类） | 相机侧无法正确采到灯方向 → 宜 [光子映射 / SPPM](光子映射.md) |
| 需无偏、可任意加 spp | 路径追踪最简单：加样本即可，无额外存储 |

低 spp 图像偏暗是因为少数极亮像素被显示裁切，**均值仍无偏正确**（PBRT 图 14.17）。

## 6. 与 Whitted 的关系

Whitted 只追镜面反射 / 折射树并做点光源阴影；路径追踪把漫反射 / 光泽也纳入同一蒙特卡罗框架，并用 RR 截断无限树，是其自然推广。

## 7. 一句话

**路径追踪 = 路径空间 LTE 的相机端增量采样：$\beta$ 累积 BSDF 权重，每顶点 MIS 直接光，镜面特例补 Le，RR 无偏截断；实现简单无偏，但难路径（小亮斑间接光、SDS）方差大。**
