# 实时焦散：Caustic Map 与 Hierarchical Caustic Map

> 焦散（caustics）：光经镜面反射 / 折射后聚焦到漫射面上的亮纹（水底光斑、玻璃焦线等）。离线常用光子映射；实时则多走 **光空间图像** 近似。  
> 相关：[光子映射.md](光子映射.md)（离线密度估计）· [路径追踪.md](路径追踪.md) / [双向路径追踪.md](双向路径追踪.md)（无偏难路径）

| 论文 | 出处 | 角色 |
|:---|:---|:---|
| Shah, Konttinen, Pattanaik. *Caustics Mapping: An Image-Space Technique for Real-Time Caustics* | IEEE TVCG 2007 | 定名「caustic map」、类阴影图管线 |
| Wyman & Davis. *Interactive Image-Space Techniques for Approximating Caustics* | I3D 2006 | 同期光空间光子缓冲 + 多种 gather |
| Wyman. *Hierarchical Caustic Maps* | I3D 2008 · [PDF](https://cwyman.org/papers/i3d08_hcm.pdf) | 层次剔除 / 汇聚合并 / 多分辨率 splat |

二者同属 **caustic mapping** 一族：像 shadow map 一样做光空间投影图，但存的是「经镜面后落到漫射面的光子能量」，最终再投到场景上。

---

## 1. 问题与思路

Shadow map：光→场景，每像素一次可见性（亮 / 暗）。  
焦散：同一漫射点可能经多条镜面路径接收能量，需 **计数 / 累加** 多条路径，而非二进制可见性。

实时约束下：

- 不宜在 GPU 上建完整 kd-tree 光子图（经典光子映射）；
- 宜用 **光栅化从灯光看场景**，规则采样发射光子；
- 把落点写入纹理，再 splat / 投影 —— 这就是 caustic map。

局限（各文共识）：点光源为主、依赖底层交互折射/反射近似、规则采样带来欠采样噪声与过采样浪费、无完整体散射等。

---

## 2. Caustic Mapping 管线（三遍）

Wyman 文中图 2 / Shah 文结构一致：

```text
Pass 1  从灯光渲染
        → 深度图（可兼做 shadow map）
        → Photon Buffer：每像素记录「光子最终击中漫射面」的位置
          （可选：入射方向、衰减强度）

Pass 2  把 Photon Buffer 中的点当作图元
        → VS/GS 变换到光空间投影位置
        → 以点 / 高斯 splat / 相邻光子多边形 累加进 Caustic Map

Pass 3  最终从眼睛渲染
        → 像投影阴影图一样投影 Caustic Map
        → 与直接光叠加
```

直觉：shadow map 回答「直射能否看见灯」；caustic map 回答「经镜面弯折后落在这里的光有多少」。

### 2.1 Photon Buffer 怎么来（发射）

- **规则采样**：灯光视图像素 = 一条光子（便于 GPU，易混叠）。
- 像素内做图像空间折射 / 反射近似（常接 Wyman 2005 等），追踪到 **第一个漫射面**，写入世界 / 光空间坐标。
- **Shah et al.**：可用 **vertex tracing**——只对折射体顶点发光子，无关光子少，但质量依赖网格细分。
- **Wyman & Davis**：整帧光栅化，与几何复杂度相对解耦，但大量光子根本碰不到镜面（无效光子）。

多方向灯、同时反射+折射时，可能要多遍灯光视图。

### 2.2 Gather：如何写成 Caustic Map

| 方法 | 做法 | 优劣 |
|:---|:---|:---|
| 直接画点 | R2VB / 纹理取点位置画 point | 快；低光子数极噪、动画闪烁 |
| 相邻光子连成四边形 / 三角形 | 光空间邻接 ≈ beam（类 Watt 光束） | 填率高；深度复杂 |
| 高斯 / 固定半径 splat | 把能量涂到邻域 texel | 去噪但糊；实时约 ~10⁴ 光子才流畅 |
| 变半径 splat（后续） | 发散区大核、汇聚区小核 | 保焦线锐利同时抑噪 |

能量比：相邻像素对应光束立体角 $\omega_B$，落点多边形立体角 $\omega_P$，强度比约 $\omega_B/\omega_P$（Wyman & Davis 式 1–3）。汇聚处 $\omega_P$ 小 → 亮。

### 2.3 与阴影图并用

灯光视图参数常与 shadow map **共用**，一遍出深度 + 光子落点；最终着色同时采样两张投影图。

### 2.4 早期质量–速度权衡

| 策略 | 效果 |
|:---|:---|
| 少光子 + 大高斯 | 实时，焦散极糊（Szirmay-Kalos 等） |
| 百万级光子 + 小 splat | 接近离线观感，但当时仅数 fps（Wyman & Dachsbacher 等） |
| 只增光子数 | 欠采样区变好，**汇聚区更过采样**，算力白扔 |

这直接催生 Hierarchical Caustic Maps。

## 3. Hierarchical Caustic Maps（Wyman, I3D 2008）

目标：在 **百万～千万光子** 下仍实时，并同时处理三类问题：

1. **无效光子**（未碰镜面）浪费；  
2. **过采样**（汇聚区大量光子砸同一 texel）；  
3. **欠采样**（发散区噪点）——用变 splat，但大 splat 光栅贵。

手段：光子缓冲的 **mipmap 层次** + Geometry Shader 流式处理 + **金字塔 caustic map**。

### 3.1 层次剔除无效光子（§3.1）

无效光子在缓冲里往往成片。对 Photon Buffer 建 mipmap，自顶向下 BFS：

```text
photonsForLevel[max] ← { root }
for i = maxLevel … 1:
  for each p in photonsForLevel[i]:
    if IsInvalid(p): continue          # 四子全无有效光子
    把 p 的四个 child 推入 level i-1
TransformPhotons( level 0 存活光子 )
```

粗层丢一个 texel ≈ 丢掉细层 $4^k$ 个候选。实现常从 $16^2$ 层起跳，避免空转。GS 可显式丢弃；仅靠移出视锥裁剪收益有限。

### 3.2 汇聚簇合并，降过采样（§3.2）

若某 mip 节点的子光子 **投影到 caustic map 同一 texel**，视为汇聚：

- 不再展开四子分别 splat；
- 推一条代表光子，强度乘 $4^{i}$（或等价 `intensityModifier`）；
- 存 modifier 可塞进位置的 alpha。

极端焦区可把多达 ~256 光子并成一条亮光子。完整每层都测汇聚偏贵；实践常 **只在最细一两层测**，百万光子级仍可省 30–50% gather。

### 3.3 变 splat + 多分辨率 Caustic Map（§3.3）

**半径来自缓冲几何，而非脆弱薄透镜模型。**  
光子 $p_i$ 代表立体角 $\omega_i$ 的光束，落到距灯 $d_i$ 处；邻接四光子围成面积 $A_i$。放大率 $\propto \omega_i d_i^2 / A_i$。splat 半径（式 1–2）：

$$
r_i=\sqrt{\frac{A_i\,(\mathbf{N}\cdot\mathbf{D}_i)}{\omega_i\,d_i^2}}\quad\text{（含表面朝向）}.
$$

GPU 上面积不稳时，可用邻接光子最大间距近似，略放大各向异性发散区。

**问题**：发散区 $r_i$ 可任意大，光栅代价 $\propto r^2$。  
**观察**：极大高斯又糊又暗，不必画进全分辨率图。

做法——**按 splat 直径分到不同分辨率层**（图 6）：

```text
Di = 2 ri
mip = trunc(log2(max(1, Di / 5)))   # 每层最大 splat 直径约 5
splatSize = Di / 2^mip
SplatPhoton → 该 mip 层
```

高频锐焦 → 最高分辨率层；低频糊斑 → 低分辨率层（同样「直径 5」在粗图上覆盖更大世界范围，却便宜）。

合成强度（式 3）：粗层 texel 覆盖面积是细层的 $4^i$ 倍，需归一化：

$$
C=\sum_{i=0}^{N}\frac{C_i}{4^i}.
$$

实践只累加 base + 前 3 层；直径 >40 px 量级的光子可直接丢（贡献微弱）。DX10 可一次多 RT / 选输出层；当时硬件常同分辨率 RT 只写递减子区域，模拟 render-to-mipmap。

### 3.4 实现优化（§4，与层次正交）

| 坑 | 对策 |
|:---|:---|
| FBO→VBO 拷贝占主导 | 两边精度一致（同 16 或同 32 bit），避免隐式转换 |
| SM4 顶点可采纹理 | 可不再拷贝；用 `VertexID`/`InstanceID` 算光子 texel |
| 巨型垃圾顶点数组 | 小数组 + `DrawArraysInstanced` |

论文报告：相对 Wyman & Davis 2006，caustic map 生成可快一个数量级；层次本身相对「仅优化实现」仍有数倍 gather 加速。示例：56 万三角、两灯各 400 万光子、2048²，仍可交互（约 9 fps 量级，视硬件）。

## 4. 方法对照

| | Caustic Map（基础） | Hierarchical Caustic Map |
|:---|:---|:---|
| 光子数 | 常卡在 ~10⁴ 实时或百万级卡顿 | 面向百万级实时 |
| 无效光子 | 逐点处理 / 移出视锥 | mip 层次成片丢弃 |
| 汇聚区 | 重复 splat | 子树合并为强光子 |
| 发散噪声 | 大固定核 → 糊 | 变 $r_i$ + 金字塔层 |
| 大 splat 代价 | $\propto r^2$ 打满分辨率 | 丢到粗层，保持小 splat |

相对离线 [SPPM / 光子映射](光子映射.md)：caustic map 是 **2D 光空间投影密度**，不是世界空间 kNN；更快、更易进游戏管线，但少了完整 GI、对采样规则与折射近似更敏感。

后续延伸（了解即可）：Wyman *Adaptive Caustic Maps*（延迟着色自适应发射光子，缓解规则采样）；表面对齐 splat、线追踪体焦散（Kruger et al.）等。

---

## 5. 一句话

**Caustic map = 光空间 photon buffer → splat 成投影照明图（类 shadow map 的镜面聚焦版）；Hierarchical caustic map = mip 剔无效光子 + 汇聚合并降过采样 + 按发散半径写入金字塔图，使百万光子级焦散可实时。**
