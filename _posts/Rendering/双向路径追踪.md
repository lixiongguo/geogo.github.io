# 双向路径追踪（BDPT）

> Pharr, Jakob, Humphreys. *Physically Based Rendering*, 3rd ed.  
> 主要章节：§16.3 Bidirectional Path Tracing · 实现：`integrators/bdpt.h`、`BDPTIntegrator`  
> 在线书：[Bidirectional Path Tracing](https://www.pbr-book.org/3ed-2018/Light_Transport_III_Bidirectional_Methods/Bidirectional_Path_Tracing)  
> 相关：[路径追踪.md](路径追踪.md) · [光子映射.md](光子映射.md)

[路径追踪](路径追踪.md) 只从相机造径时，若灯光能量先集中照到一小块表面再间接照亮场景，几乎采不到「关键中间顶点」，方差极高（PBRT 图 16.12）。**双向路径追踪（BDPT）** 同时从相机与灯光造子路径，在中间用可见性射线连接，无偏、不模糊照明，是路径空间积分的直接应用。

## 1. 核心思想

### 1.1 两条子路径

- **相机子路径**：$z_0$（镜头/针孔）$\to z_1\to\cdots\to z_{t-1}$，按 **辐射亮度** 传输（`TransportMode::Radiance`），在顶点用 BSDF 采样。
- **灯光子路径**：$y_0$（光源）$\to y_1\to\cdots\to y_{s-1}$，按 **重要性** 传输（`TransportMode::Importance`），表面用伴随 BSDF。

一条完整携带能量的路径可写为（光传播顺序）

$$
\bar{x}=y_0,\ldots,y_{s-1},\,z_{t-1},\ldots,z_0,
$$

在 $y_{s-1}$ 与 $z_{t-1}$ 之间连一条阴影射线；若通，乘上两端 BSDF / 相位函数与几何项，即得该连接策略的贡献（图 16.13）。

### 1.2 与光子映射的对比

| | BDPT | SPPM / 光子映射 |
|:---|:---|:---|
| 估计 | 无偏路径积分 | 密度估计，有偏（一致） |
| 连接 | 显式可见性 + MIS | 邻域光子核模糊 |
| 难路径 SDS 等 | 仍可能高方差 | 往往更稳 |
| 图像更新 | 多数策略写当前像素；`t=1` 需 splat | 按像素半径累积 |

## 2. 三项实用优化（§16.3 开篇）

1. **子路径复用**  
   相机侧 $t$ 个顶点、灯光侧 $s$ 个顶点，可组合出大量不同长度路径（约 $O(st)$），远多于「只连一次」。

2. **单顶点端点用专门采样**  
   只用灯光子路径一个顶点连相机、或只用相机子路径一个顶点连灯时，改走 `Light::Sample_Li` / `Camera::Sample_Wi` 等优化例程，而不是朴素连接。跳过 `(s,t)=(1,1)`（两边专用采样不能同时用）。

3. **多重重要性采样（MIS）**  
   长度为 $k$ 的路径可由多种 $(s,t)$（$s+t-2=k$ 的散射次数）生成。有的策略对某类路径好、对其余极差。用 Veach 式 MIS 按各策略 PDF（**面积乘积测度**）加权，是 BDPT 高效的关键。

## 3. 顶点抽象 `Vertex`（§16.3.1）

统一表示四种端点 / 散射事件，避免连接逻辑里嵌套爆炸：

| `VertexType` | 含义 |
|:---|:---|
| Camera | 镜头上的端点 |
| Light | 光源端点（含逃逸到环境光） |
| Surface | 表面散射 |
| Medium | 介质内散射 |

重要成员：

- **`beta`**：迄今为止的吞吐量（BSDF/相位 × 透射 × 余弦 / PDF；灯光侧还含 $L_e$ / 发射 PDF）。
- **`pdfFwd` / `pdfRev`**：正向生成该顶点的面积密度，以及「若反向造径」的假设密度——MIS 权重必需。
- **`delta`**：是否采到了镜面 Dirac（连接时常不可连）。

`ConvertDensity`：立体角 PDF → 面积 PDF，乘 $1/r^2$ 与（若在表面）$|\mathbf{n}\cdot\omega|$。无限环境光需特殊处理。

`IsConnectible()`：纯镜面表面顶点无法与另一子路径「任意方向连接」成功；介质与相机一般可连；方向性 delta 灯不可当连接端。

## 4. 子路径生成（§16.3.2）

```text
GenerateCameraSubpath:
  Camera::GenerateRayDifferential → path[0] = CreateCamera
  RandomWalk(..., Radiance, path+1)

GenerateLightSubpath:
  按功率分布选灯 → Light::Sample_Le
  path[0] = CreateLight, β = Le |n·d| / (p_light p_pos p_dir)
  RandomWalk(..., Importance, path+1)
```

`RandomWalk`：求交 →（可选）介质采样 → 建 `Vertex` → BSDF/相位采样续径；维护 `pdfFwd`/`pdfRev`，镜面分量把两 PDF 置 0 并标 `delta`。相机路径允许最后「撞上」灯并记为 Light 顶点（对「只经镜面才看见的面灯」很重要）；灯光路径随机撞镜头实用价值较低，PBRT 未对称实现。

相机子路径多分配一个顶点槽：`maxDepth+2` vs 灯光 `maxDepth+1`。

## 5. 连接与累计（`ConnectBDPT`）

对每对 $(s,t)$（满足深度约束）：

```text
Lpath = ConnectBDPT(..., s, t, ..., &pFilmNew, &misWeight)
if t != 1:
  L += Lpath          // 贡献落在当前像素
else:
  film->AddSplat(pFilmNew, Lpath)  // 灯光顶点直接连相机，光栅位置常变
```

因此 `BDPTIntegrator` 继承通用 `Integrator` 而非 `SamplerIntegrator`，以便任意 splat。

连接时评估测量方程中与两端顶点相关的 BSDF/相位、几何项、可见性，再乘两侧 `beta` 与 MIS 权重。

### 5.1 策略空间直觉（图 16.14，直接光四种造法）

| $(s,t)$ 直觉 | 含义 |
|:---|:---|
| 类似「BSDF 碰巧撞灯」 | 标准 PT 无显式直接光 |
| 相机径 + 阴影连灯 | PT + 直接光采样 |
| 灯光粒子 + 连相机 | 粒子追踪写胶片 |
| 灯光径碰巧进镜头 | 对称的「撞相机」 |

MIS 把这些策略融成一个估计量。

## 6. MIS 与概率测度（§16.3.4 要点）

- 路径概率用 **面积乘积测度**：各顶点面积密度之积，保证不同策略 PDF 可比。
- 对给定完整路径，枚举所有能生成它的 $(s',t')$，用平衡启发式或幂启发式组合权重。
- Delta 事件（镜面、点灯）使某些策略 PDF 为 0，权重自然倒向能处理该 delta 的策略。

## 7. 算法外层循环

```text
对每个像素样本:
  生成 cameraVertices[0..nCamera), lightVertices[0..nLight)
  for t = 1 .. nCamera:
    for s = 0 .. nLight:
      depth = t + s - 2
      跳过非法 (s,t) 与超深
      ConnectBDPT → 累加或 splat
  filmTile->AddSample(pFilm, L)
```

## 8. 何时用 BDPT

| 适合 | 不太适合 / 仍难 |
|:---|:---|
| 强间接、小亮斑中介的照明 | 极端 SDS（点灯–玻璃–漫反射–针孔）仍可能噪声大 |
| 需要**无偏**结果 | 想靠模糊换平滑时 SPPM 更讨喜 |
| 与 PT 相同场景比较方差 | 实现与调试明显重于 PT |

PBRT 强调：BDPT 相对 [SPPM](光子映射.md) 不引入密度估计模糊；相对纯 PT 对「灯→小面→间接」更稳健。

## 9. 一句话

**BDPT = 相机子路径 × 灯光子路径 + 多策略连接 + 面积测度 MIS；无偏复用前缀，专治「只从相机几乎采不到的间接光」，代价是实现与 splat / PDF 细节复杂。**
