光子映射属**粒子追踪**族：从灯出发存粒子历史，渲染时用邻域估计入射照明。PBRTv3 实现的是 **随机渐进光子映射（SPPM）**：不存全体光子图，迭代「少样本可见点 + 射光子 + 缩半径」，突破经典两遍法的内存墙，并改善抗锯齿 / 景深 / 运动模糊。

## 1. 粒子追踪理论（§16.2.1）

每次击中表面记录 $(p_i,\omega_i,\alpha_i)$：位置、入射方向、权重 $\alpha$（类似路径追踪的 $\beta$，含吞吐量 / PDF）。

Veach：若粒子分布与权重满足，对任意测量重要性 $W$，

$$
\mathbb{E}\Bigl[\sum_i W(p_i,\omega_i)\,\alpha_i\Bigr]
=\text{对应测量方程的真值}.
$$

于是同一批粒子可复用于多种测量（例如不同墙面的通量）：只改 $W$ 再求和。权重形式与路径积分截断项一致（式 16.8），可用 RR。

**限制**：单次测量若支撑很小，盲目按面积射粒子会浪费；优势在于**多次测量复用**同批粒子。

## 2. 为何需要密度估计（有偏）

想估 $L_o(p,\omega_o)$ 时，测量里含 $\delta(p'-p)$：精确落在 $p$ 的概率为 0。光子映射把 delta **换成核函数**，用邻域光子插值——引入**偏差**，换可算的估计。

核密度 / 第 $n$ 近邻估计（式 16.10–16.11）给出出射辐射的近似。误差难定量：光子越多、邻域越紧通常越好；照明空间变化剧烈处易糊掉高频。故常对**直接光**用传统方法，光子只管**间接**（间接偏低频）。

### 2.1 无偏算法采不到的路径（图 16.6）

场景：点灯 + 针孔相机 + 玻璃后漫反射面。

- 从相机穿过玻璃，交点由折射唯一确定；在漫射点**无法**采到能经玻璃折射后命中点灯的方向。
- 从灯出发同样无法保证进针孔。

[PT](路径追踪.md) / [BDPT](双向路径追踪.md) 对此类 **SDS**（specular–diffuse–specular）结构方差极高或贡献为 0。光子可先穿过玻璃沉在漫射面上，再用密度估计读出照明——这是光子映射相对无偏路径法的核心优势之一。

## 3. 算法演进

### 3.1 经典两遍光子映射

1. 从灯追光子，在表面记录，建 kd-tree 等；  
2. 从相机造径，在顶点用近邻光子估间接光。

**瓶颈**：光子数受内存限制，存满后无法靠「再加光子」提高质量（对比 PT 可无限加 spp）。

### 3.2 渐进光子映射（PPM）

先从相机存**可见点**（非镜面路径顶点：位置、法向、BSDF、路径权重），再不断射光子，命中附近可见点时累加。光子不必永久存储；内存绑在可见点上。高分辨率 / 多样本像素时可见点仍可能爆内存。

LTE 在可见点拆成：自发光 + 直接光（常规）+ 间接（续径 **或** 留给光子）。镜面 / 强光泽宜继续追射线；漫反射宜收光子。可选 **final gather**：再漫反射弹一次再用光子，减轻斑驳。

### 3.3 随机渐进（SPPM）——PBRT 所实现

每轮迭代：

1. 每像素（低采样，如 1 spp）造相机路径，得到该像素当前**一个**可见点；  
2. 射一批光子，向邻域可见点沉积能量；  
3. **丢弃**可见点，按规则缩小半径、更新累积量；  
4. 重复。新可见点位置变化 → 自然做抗锯齿、景深、运动模糊。

内存主要是每像素状态，不随光子总数线性增长。

## 4. SPPM 估计与半径更新（§16.2.2）

二维切平面上用常数核（圆盘），半径 $R$：

$$
\hat{L}\propto\frac{1}{N\,|A|}\sum_{\text{光子 }i}\alpha_i\,f(\omega_o,\omega_i),\quad |A|=\pi R^2,
$$

$N$ 为已发射光子总数。

半径随迭代缩小（式 16.13）：设第 $i$ 轮有 $M$ 个新光子落入，$N$ 为有效光子计数，$\tau$ 累积 $\beta\cdot\Phi$ 类贡献，$\gamma\approx 2/3$：

$$
\begin{aligned}
N_{\mathrm{new}} &= N + \gamma M,\\
R_{\mathrm{new}} &= R\sqrt{N_{\mathrm{new}}/(N+M)},\\
\tau &\leftarrow (\tau + \beta\Phi)\,(R_{\mathrm{new}}/R)^2.
\end{aligned}
$$

$\gamma$ 控制「早期大半径贡献」淡出速度。半径是**每像素**共享的，对像素内一系列不同可见点仍给出**一致**估计：$N\to\infty$ 时 $R\to 0$，估计趋于正确（一致，但仍有限样本有偏）。

最终像素颜色（示意）：

$$
L=\frac{L_d}{n_{\mathrm{iter}}}+\frac{\tau}{N_{\mathrm{photons}}\,\pi R^2},
$$

$L_d$ 为多轮平均的直接光 / 自发光项。

## 5. `SPPMIntegrator` 流程（§16.2.3）

```text
初始化每像素 radius ← initialSearchRadius, 清空统计
for iter = 0 .. nIterations-1:
  【相机遍】并行按 tile
    每像素造径：累加 Ld（Le + 直接光）
    遇漫反射（或末跳光泽）→ 存 VisiblePoint (p, wo, bsdf, β) 并停
    否则 BSDF 续径 + RR
  【建网格】按可见点与半径建空间哈希网格
  【光子遍】并行射 photonsPerIteration 条
    选灯 Sample_Le，β = Le|n·d|/(…)
    深度循环：depth>0 时查网格，距可见点 < R 则
      Φ += β · f(wo, wi); M++
    再 BSDF（Importance）散射 + RR
  【更新】按式 16.13 更新 N, R, τ；清空本轮 Φ, M；丢掉 vp
  周期性把图像写入 Film
```

### 5.1 实现要点

| 项 | PBRT 做法 |
|:---|:---|
| 初始半径 | `initialSearchRadius`，大约「几个像素」量级；过大早期太慢，过小找不到光子 |
| 每轮光子数 | 默认常取图像像素数 |
| 采样 | `HaltonSampler`；光子用 RadicalInverse 与迭代索引构造高维样本 |
| 可见点查找 | 均匀网格 + 原子链表头，光子只测距离平方 $<R^2$ |
| 直接 vs 光子 | `Ld` 无偏直接估计；间接靠 $\tau$ 密度估计 |

## 6. 与 PT / BDPT 选型

| | Path Tracing | BDPT | SPPM |
|:---|:---|:---|:---|
| 偏差 | 无偏 | 无偏 | 有偏、一致 |
| SDS / 焦散经玻璃 | 差 | 仍难 | **强** |
| 小亮斑间接 | 差 | **较好** | 可，但糊 |
| 实现复杂度 | 低 | 高 | 中高 |
| 加时提质 | 加 spp | 加 spp | 加迭代 / 光子 |
| 模糊感 | 无（噪声） | 无 | 有核模糊，半径→0 变锐 |

## 7. 实践注意

- 光子映射估的是**辐照/入射分布的平滑版**；镜面高光不要靠光子，应继续追。  
- 直接光分离可减少「把高频阴影糊掉」。  
- `γ`、初始 $R$、每轮光子数影响收敛速度与斑驳；需按场景调。  
- 结果与无偏算法像素级不完全可比时，看噪声形态与难路径是否出现，而非只比数值。

## 8. 一句话

**SPPM = 粒子追踪 + 核密度估计解决「精确命中概率为 0」与 SDS 难路径；渐进缩半径保证一致，随机可见点突破内存并做抗锯齿——有偏但专治 PT/BDPT 采不动的焦散与折射照明。**
