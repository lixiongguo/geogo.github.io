## 核心思想

从小的样本图像生成更大的图像，保证局部连续性。

## 四个主要步骤

### 1. 图片切分

将输入图像切分成 N×N 个小块（tiles），作为基本单元。

```matlab
imgList{N*N}=[];
pixNum=size(img,1)/N;
for i=1:N
    for j=1:N
        imgList{sub2ind([N,N],i,j)}=...
        img(((i-1)*pixNum+1):(i*pixNum),...
            ((j-1)*pixNum+1):(j*pixNum),:);
    end
end
```



### 2. 构建连通表（关键）

- 计算哪些小块可以在上下左右四个方向连接

- 使用均方根误差（RMSE）比较边缘像素

- 误差 < 40 则认为可以连接

- 结果存储在 imgAdjList 中

  ```matlab
  for i=1:N*N
      for j=1:N*N
          % 检测右连接
          rErr=sqrt(mean((rImgC-rImgS).^2));
          if rErr<err
              imgAdjList(i).r=[imgAdjList(i).r,j];
          end
          % 类似地检测左、上、下连接...
      end
  end
  ```

  

### 3. 波函数坍缩生成

- 从左到右、从上到下填充每个位置

- 对每个位置，考虑四个邻域的约束，找出可行的小块集合

- 随机选择一个可行块

- 如果无可行块，回溯到上一个位置

  ```matlab
  % 主循环
  for j=1:cols
      for i=1:rows 
          fullList=fillij(indMat,imgAdjList,N,ti,tj);
          if ~isempty(fullList)
              indMat(ti,tj)=fullList(randi([1,length(fullList)]));
          else
              indMat(ti,tj)=0;  % 回溯
          end
      end
  end
  
  % 约束函数
  function fList=fillij(indMat,imgAdjList,N,i,j)
      fList=1:N*N;
      % 考虑四个方向的约束，求交集
      fList=intersect(fList,rIndList);
      fList=intersect(fList,lIndList);
      fList=intersect(fList,uIndList);
      fList=intersect(fList,dIndList);
  end
  ```

  

### 4. 图像合成

根据生成的序号矩阵，将小块拼接成最终图像。

```matlab
newImg=zeros([rows*pixNum,cols*pixNum,size(img,3)]);
for i=1:rows
    for j=1:cols
        newImg(((i-1)*pixNum+1):(i*pixNum),...
               ((j-1)*pixNum+1):(j*pixNum),:)=...
            imgList{indMat(i,j)};
    end
end
```
