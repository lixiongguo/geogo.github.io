点定位（Point Location）是计算几何中最基本的搜索问题之一：**给定一个平面细分（planar subdivision）和一个查询点，快速确定该点位于哪个面（face）中**。本文系统梳理该问题从朴素方法到最优算法的演进。

<!--more-->

---

## 1. 问题定义

### 1.1 形式化描述

**输入**：
- 一个平面细分 $S$，由 $n$ 个顶点、$m$ 条边、$f$ 个面组成
- 一个查询点 $q \in \mathbb{R}^2$

**输出**：$q$ 所在的面 $\text{face}(q)$

### 1.2 朴素方法

**射线法（Ray Crossing）**：从 $q$ 向右发射一条水平射线，统计与细分边的交点数量——奇数在内，偶数在外。

```
function RayCrossing(q, subdivision):
    count = 0
    for each edge e in subdivision:
        if HorizontalRayIntersects(q, e):
            count += 1
    if count % 2 == 1:
        return "inside"
    else:
        return "outside"
```

**复杂度**：$O(n)$ 每次查询。

**问题**：当需要回答大量查询时（如 $10^6$ 次查询），$O(n)$ 的单次查询代价不可接受。我们需要**预处理**。

### 1.3 三个性能指标

| 指标 | 含义 |
|:---|:---|
| **预处理时间** | 构建数据结构的时间 $T_{\text{pre}}$ |
| **查询时间** | 每次点定位的时间 $T_{\text{query}}$ |
| **空间复杂度** | 数据结构占用的内存 $S$ |

理论下界（对 $n$ 个面的平面细分）：

$$T_{\text{query}} \geq O(\log n), \quad S \geq O(n)$$

即查询时间不可能低于 $O(\log n)$（信息论下界），空间不可能低于 $O(n)$（需要存储所有面）。

## 2. Slab Method（板方法）

### 2.1 基本思想

将平面通过每个顶点的 $y$ 坐标切分为**水平条带（slabs）**，每个条带内部的边是垂直不相交的——因此可以在每个条带内对边按 $x$ 排序，用二分查找定位。

### 2.2 构建

```
1. 收集所有顶点的 y 坐标，排序得到 y₁ < y₂ < ... < yₙ
2. 每个 yᵢ 定义一条水平切分线，形成 n+1 个条带
3. 对每个条带内的边按 x 排序，构建有序数组
```

### 2.3 查询

```
function SlabQuery(q):
    // 1. 在 y 坐标数组中二分查找 q 所在的条带
    slab = BinarySearch(y_coords, q.y)

    // 2. 在条带内的 x 排序数组中二分查找
    //    找到 q 左右最近的边，确定 q 在哪个面中
    face = BinarySearch(slab.edges, q.x)

    return face
```

### 2.4 复杂度

| 指标 | 复杂度 |
|:---|:---|
| 预处理 | $O(n \log n)$（排序） |
| 空间 | $O(n^2)$（最坏情况每个条带 $O(n)$ 条边，共 $O(n)$ 个条带） |
| 查询 | $O(\log n)$（两次二分查找） |

**问题**：空间 $O(n^2)$ 太大！存储所有条带的边列表需要平方级空间。

## 3. Persistent Search Tree（持久化搜索树）

### 3.1 核心观察

Slab 方法中，相邻条带之间的边列表**只差一条边**（对应一个顶点的两条关联边）。这意味着边列表的变化是**增量的**。

**持久化数据结构**正是处理这种"版本演化"的工具：它允许查询**任意历史版本**的数据结构。

### 3.2 Sarnak-Tarjan 方法（1986）

将每个条带的有序边列表视为二叉搜索树的一个"版本"。使用**部分持久化（partial persistence）**技术：

```
版本 1（slab 1）的 BST
    ↓ 插入/删除若干元素（O(log n)）
版本 2（slab 2）的 BST
    ↓ 插入/删除若干元素（O(log n)）
版本 3（slab 3）的 BST
    ...
```

每次版本更新只修改 $O(\log n)$ 个节点（BST 的从根到叶路径），因此新增 $O(\log n)$ 个节点。

### 3.3 复杂度

| 指标 | 复杂度 |
|:---|:---|
| 预处理 | $O(n \log n)$ |
| 空间 | $O(n \log n)$（每个版本 $O(\log n)$ 新增节点，$n$ 个版本） |
| 查询 | $O(\log n)$（在对应版本的 BST 中查找） |

**意义**：将 Slab 方法的空间从 $O(n^2)$ 降至 $O(n \log n)$，是第一个实用的 $O(\log n)$ 查询方法。

## 4. Kirkpatrick 层次方法（1983）

### 4.1 核心思想

Kirkpatrick 提出了一种**分层精炼（hierarchical refinement）**的方法：从最粗的三角形开始，逐层细化到原始三角剖分，查询时自顶向下定位。

$$\boxed{\text{粗网格（1 个三角形）}} \xrightarrow{\text{逐层细化}} \cdots \xrightarrow{\text{逐层细化}} \boxed{\text{原始三角剖分}}$$

### 4.2 前置条件

输入必须是**三角化的平面细分**（所有面都是三角形）。如果不是，可以先用多边形三角剖分转化为三角网格。

### 4.3 层次构建

**关键引理**：在任何三角剖分中，总存在一个大小至少为 $n/12$ 的**独立顶点集**，其中每个顶点的度数 ≤ 8。

**构建流程**：

```
function BuildHierarchy(triangulation T):
    levels = [T]

    while |T.vertices| > 3:
        // 1. 找独立顶点集（度数 ≤ 8 的顶点）
        I = IndependentSet(T)  // |I| ≥ n/12

        // 2. 移除这些顶点，产生"孔洞"
        for each v in I:
            Remove v and its incident triangles

        // 3. 对每个孔洞重新三角化
        RetriangulateHoles(T)

        // 4. 记录层次指针
        //    每个新三角形记录它"覆盖"了上一层的哪些三角形
        RecordPointers(T, levels.last)

        // 5. 保存为新的层次
        T = new triangulation
        levels.append(T)

    return levels  // 共 O(log n) 层
```

### 4.4 查询算法

```
function KirkpatrickQuery(point q, levels):
    // 从最粗的层次（单个三角形）开始
    current = levels.top.triangles[0]  // 一定包含 q

    // 逐层向下定位
    for i = |levels|-1 downto 0:
        // 当前三角形在下一层中被分解为若干子三角形
        // 由于移除顶点度数 ≤ 8，子三角形数量 ≤ 常数
        for each child in current.children:
            if q inside child:
                current = child
                break

    return current  // 原始三角剖分中包含 q 的三角形
```

### 4.5 为什么查询是 O(log n)？

- 层次数：每层移除 ≥ $n/12$ 个顶点，因此最多 $O(\log n)$ 层
- 每层定位：当前三角形被分解为**常数个**子三角形（因为移除的顶点度数 ≤ 8，重新三角化产生 ≤ 7 个新三角形）
- 因此总查询时间：$O(\log n) \times O(1) = O(\log n)$

### 4.6 复杂度

| 指标 | 复杂度 |
|:---|:---|
| 预处理 | $O(n)$ |
| 空间 | $O(n)$（每层三角形总数线性，层间指针也线性） |
| 查询 | $O(\log n)$（最坏情况） |

**Kirkpatrick 方法的意义**：首次同时达到 $O(n)$ 预处理、$O(n)$ 空间、$O(\log n)$ 查询——理论上最优。

## 5. 梯形图与随机增量方法

### 5.1 梯形图（Trapezoidal Map）

梯形图是平面细分的一种特殊形式，特别适合处理**线段集合**（而非多边形面片）的点定位。

对线段集 $S$ 中的每条线段，从其两个端点向上和向下延伸垂直射线到无穷远（或到包围盒边界），将平面划分为若干梯形。

**梯形 $\Delta$ 的定义**：由两条（非垂直）线段的部分边作为上下边界，由垂直线段（延伸线）作为左右边界，围成的区域。

### 5.2 随机增量构造

```
function BuildTrapezoidalMap(segments S):
    // 用包围盒初始化
    R = BoundingBox(S)
    T = {R 内的 1 个梯形}  // 初始梯形就是整个包围盒
    D = DAG 节点 = {R}

    // 随机排列线段
    random_shuffle(S)

    for each segment s_i in S:
        // 找到 s_i 穿过的所有梯形
        trapezoids = FollowSegment(s_i, D)

        // 删除旧梯形，创建新梯形
        // s_i 将每个穿过的梯形最多分为 4 个新梯形
        (new_traps, new_nodes) = SplitTrapezoids(trapezoids, s_i)

        T = (T - trapezoids) ∪ new_traps
        UpdateDAG(D, trapezoids, new_traps, new_nodes)

    return T, D  // 梯形图 + 搜索 DAG
```

### 5.3 搜索结构（DAG）

查询数据结构是一个**有向无环图（DAG）**：

- **叶子节点**：对应梯形图中的一个梯形
- **内部节点**：对应线段的一个端点（x-node）或线段本身（y-node）
- **边**：从节点指向其子梯形

**查询算法**：

```
function TrapezoidMapQuery(q, D):
    node = D.root
    while node is not a leaf:
        if node is an x-node (端点):
            if q.x < node.point.x:
                node = node.left
            else:
                node = node.right
        else if node is a y-node (线段):
            if q is above node.segment:
                node = node.above
            else:
                node = node.below
    return node.trapezoid  // q 所在的梯形
```

### 5.4 复杂度分析（期望）

使用**反向分析（Backward Analysis）**证明期望复杂度：

| 指标 | 复杂度 |
|:---|:---|
| 预处理（期望） | $O(n \log n)$ |
| 空间（期望） | $O(n)$ |
| 查询（期望） | $O(\log n)$ |

**反向分析直觉**：考虑将第 $i$ 条线段"撤回"后，第 $i$ 条线段穿过的期望梯形数量是 $O(1/i)$，因此总更新期望为 $\sum_{i=1}^{n} O(1/i) \cdot O(\log i) = O(n \log n)$。

### 5.5 梯形图的优势

- **不需要预先三角化**：直接处理线段集合
- **支持动态更新**：可以在线插入/删除线段
- **工程实用性强**：大多数实际实现采用此方法

## 6. 算法对比总结

| 方法 | 预处理 | 空间 | 查询 | 特点 |
|:---|:---|:---|:---|:---|
| **射线法（朴素）** | — | — | $O(n)$ | 无预处理，最慢 |
| **Slab Method** | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | 简单但空间爆炸 |
| **Persistent BST** | $O(n \log n)$ | $O(n \log n)$ | $O(\log n)$ | 第一个实用的 $O(\log n)$ 查询 |
| **Kirkpatrick** | $O(n)$ | $O(n)$ | $O(\log n)$ | **理论最优**，需要三角化 |
| **梯形图（随机增量）** | $O(n \log n)$ 期望 | $O(n)$ 期望 | $O(\log n)$ 期望 | **最实用**，支持动态更新 |

**理论最优**：Kirkpatrick（$O(n)$ 预处理 + $O(n)$ 空间 + $O(\log n)$ 查询）

**工程最优**：梯形图随机增量方法（实现简单，支持动态更新，期望复杂度与理论最优接近）

## 7. 点定位的应用

| 应用领域 | 具体用途 |
|:---|:---|
| **地理信息系统** | 点击地图确定所在行政区域 |
| **CAD/CAE** | 查询点所在的网格单元（有限元分析） |
| **机器人路径规划** | 确定机器人在导航网格中的位置 |
| **计算机图形学** | 光线-场景相交后的着色点定位 |
| **计算几何其他算法** | 作为 Voronoi 图、Delaunay 三角剖分等算法的子程序 |
