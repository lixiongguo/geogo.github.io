本文从一个每个人都见过的约束满足问题——**数独**出发，引出波函数塌缩（Wave Function Collapse, WFC）算法的核心思想，再将其推广到图像生成与程序化内容创建。

---

## 1. 从数独说起

### 1.1 数独是什么

一个 $9 \times 9$ 的网格，部分格子已填入 1-9 的数字，要求在空格中填入数字，使得**每行、每列、每个 $3 \times 3$ 宫格**都恰好包含 1-9 各一次。

这不是一个数学问题，而是一个**约束满足问题（Constraint Satisfaction Problem, CSP）**。

### 1.2 用计算机解数独

最朴素的解法是穷举：每个空格试 1-9，遇到矛盾就回溯。但一个数独有 81 个格子，穷举的复杂度是 $9^{81}$，显然不现实。

聪明一点的解法利用了**约束传播**：

> 当我们确定某个格子是 5 之后，与它在同一行、同一列、同一宫格的所有格子就**不可能**是 5 了——这就是"约束传播"。

更进一步：我们应该**优先填那些可能性最少的格子**。如果一个格子只剩 1 种可能，那它就是确定的，应该立刻填上；如果另一个格子还有 8 种可能，就先放一放。

这就是**"最小剩余值"（Minimum Remaining Values, MRV）**启发式——优先处理约束最强的变量。

### 1.3 数独求解算法

```
function SolveSudoku(grid):
    // 初始化：每个空格的可能性为 {1,2,...,9}
    for each empty cell:
        cell.possibilities = {1, 2, ..., 9}

    // 约束传播：根据已知数字削减可能性
    for each given number in grid:
        Propagate(given.cell, grid)

    // 主循环
    while 存在未确定的格子:
        // 选择可能性最少的格子
        cell = FindMinPossibilitiesCell(grid)

        if cell.possibilities 为空:
            return FAILURE  // 矛盾！需要回溯或重启

        // "塌缩"：随机选一个可能值
        chosen = RandomPick(cell.possibilities)
        cell.value = chosen
        cell.possibilities = {chosen}

        // 约束传播：更新同行/列/宫的格子
        if NOT Propagate(cell, grid):
            return FAILURE

    return grid  // 成功！

function Propagate(cell, grid):
    // 从同行、同列、同宫格的其他格子中
    // 移除 cell.value 这个可能性
    for each related cell (同行/同列/同宫):
        if cell.value in related.possibilities:
            related.possibilities -= cell.value
            if related.possibilities 为空:
                return false  // 矛盾！
    return true
```

### 1.4 数独中已经包含了 WFC 的全部要素

仔细看上面的算法，它包含了三个核心步骤：

| 步骤 | 数独中的含义 | WFC 中的对应 |
|:---|:---|:---|
| **初始化** | 每个空格可以是 1-9 中的任何一个 | 每个格子可以是任何一个 tile |
| **塌缩** | 选择可能性最少的格子，填入一个数字 | 选择熵最低的格子，放上一个 tile |
| **约束传播** | 同行/列/宫的格子不能再填这个数字 | 相邻格子的允许 tile 被削减 |

**WFC 本质上就是"数独的泛化"**——把数独的"行/列/宫约束"替换为"相邻 tile 的匹配约束"，把"数字 1-9"替换为"图像小块（tiles）"，就得到了 WFC。

## 2. WFC：从数独到图像生成

### 2.1 从数字到图像

数独中每个格子填的是一个**数字**，相邻格子的约束是"不能重复"。

WFC 中每个格子放的是一个**图像小块（tile）**，相邻格子的约束是"**边缘像素必须匹配**"。

$$\boxed{\text{数独：格子} \to \text{数字，约束} \to \text{不重复}} \xrightarrow{\text{泛化}} \boxed{\text{WFC：格子} \to \text{tile，约束} \to \text{边缘匹配}}$$

### 2.2 量子力学的类比

WFC 的命名来源于量子力学的类比：

- **"波函数"**：每个格子处于所有可能 tile 的**叠加态**（就像薛定谔的猫"既是活的又是死的"）
- **"观测/塌缩"**：选择一个格子，将其固定为某个确定 tile（就像"打开盒子观测猫"）
- **"约束传播"**：一次塌缩会影响相邻格子的可能性，像波纹一样扩散

这个类比虽然形象，但本质上是**约束满足 + 启发式搜索**——和数独求解的数学本质完全一样。

### 2.3 核心思想

> **从小的样本图像生成更大的图像，保证局部连续性。**

与数独不同的是：数独的约束规则是人为规定的（行/列/宫不重复），而 WFC 的约束规则是**从样本图像中自动提取的**。

### 3.2 步骤一：图片切分

将输入图像切分成 $N \times N$ 个小块（tiles），作为基本单元。

```matlab
imgList{N*N} = [];
pixNum = size(img, 1) / N;
for i = 1:N
    for j = 1:N
        imgList{sub2ind([N,N],i,j)} = ...
            img(((i-1)*pixNum+1):(i*pixNum), ...
                ((j-1)*pixNum+1):(j*pixNum), :);
    end
end
```

每个 tile 被赋予一个**权重**（通常就是它在样本中出现的频率）。权重越高，该 tile 在随机选择时被选中的概率越大。

> **类比数独**：这一步相当于确定"每个格子可以填哪些数字"——在数独中是 $\{1, 2, \ldots, 9\}$，在 WFC 中是 $\{\text{tile}_1, \text{tile}_2, \ldots, \text{tile}_{N^2}\}$。

### 3.3 步骤二：构建邻接表（Adjacency Rules）

计算哪些 tile 可以在上下左右四个方向相邻。这是 WFC 的**核心数据**——相当于数独中"同行/列/宫不能重复"的规则。

**判定标准**：使用**边缘像素的均方根误差（RMSE）**：

$$\text{RMSE} = \sqrt{\frac{1}{k} \sum_{i=1}^{k} (p_i^{\text{left}} - p_i^{\text{right}})^2}$$

其中 $k$ 是边缘像素数量。RMSE < 阈值（如 40）则认为可以连接。

```matlab
for i = 1:N*N
    for j = 1:N*N
        % 检测右连接：i 的右边缘 vs j 的左边缘
        rErr = sqrt(mean((rImgC - rImgS).^2));
        if rErr < err
            adjList(i).right = [adjList(i).right, j];
        end
        % 类似地检测左、上、下连接...
    end
end
```

**结果**：每条规则形如 "tile $i$ 的右边可以接 tile $j$"，存储在邻接表中。

> **类比数独**：邻接表相当于数独的约束规则——数独中"同行不能有相同数字"是一种约束，WFC 中"tile $i$ 的右边必须能接 tile $j$"也是一种约束。区别在于数独的约束是人为规定的，WFC 的约束是从样本中**自动学习**的。

### 3.4 步骤三：波函数塌缩生成

这是 WFC 算法的核心——与数独的 MRV 启发式完全一致：**优先处理可能性最少的格子**。

#### 初始化

创建一个 $R \times C$ 的网格，每个格子初始状态为**所有 tile 的叠加态**：

$$\text{cell}(i,j).\text{possibilities} = \{1, 2, \ldots, N^2\}$$

#### 主循环

```
function WFC(rows, cols, adjList, weights):
    // 初始化：每个格子可以是任何 tile
    grid = Grid(rows, cols)
    for each cell in grid:
        cell.possibilities = {ALL_TILES}

    while 存在未塌缩的格子:
        // 1. 选择熵最低的未塌缩格子（类比数独的 MRV）
        cell = FindLowestEntropyCell(grid)

        // 2. 塌缩：根据权重随机选择一个 tile
        chosen = WeightedRandom(cell.possibilities, weights)
        cell.possibilities = {chosen}  // 塌缩为单态

        // 3. 约束传播（类比数独中更新同行/列/宫）
        if NOT Propagate(cell, grid, adjList):
            return FAILURE  // 矛盾！某格子可能性清零

    return grid  // 成功！
```

#### 熵的计算

WFC 使用**加权香农熵**来选择塌缩顺序：

$$H = \log\left(\sum_{i} w_i\right) - \frac{\sum_{i} w_i \log w_i}{\sum_{i} w_i}$$

其中 $w_i$ 是 tile $i$ 的权重（频率），求和遍历该格子当前所有可能 tile。

**为什么选熵最低的格子？** 熵最低意味着可能性最少，约束最强。优先塌缩最受限的格子可以**尽早发现矛盾**——这和数独中"先填只剩 1 种可能的格子"是完全一样的策略。

为避免熵相同的格子产生随机性，实际中通常加一个微小的随机扰动：$H' = H + \epsilon \cdot \text{random}()$。

#### 约束传播（Constraint Propagation）

这是 WFC 的**精髓**，也是数独求解器中的核心机制。

```
function Propagate(startCell, grid, adjList):
    stack = [startCell]

    while stack 非空:
        cell = stack.pop()

        for each neighbor of cell (上下左右):
            // 获取 neighbor 在 cell 方向上允许的 tile
            allowed = GetAllowedTiles(cell, neighbor, adjList)

            // 从 neighbor 的可能性中剔除不允许的 tile
            removed = neighbor.possibilities - allowed

            if removed 非空:
                neighbor.possibilities -= removed
                if neighbor.possibilities 为空:
                    return false  // 矛盾！
                stack.push(neighbor)  // 继续传播

    return true
```

> **类比数独**：
> - 数独中：格子填了 5 → 同行/列/宫的格子不能再填 5
> - WFC 中：格子放了 tile $A$ → 右边格子只能放 $A$ 的允许邻居（比如 tile $B$ 或 tile $D$）
>
> 传播机制完全相同——都是"确定一个格子的状态后，削减相关格子的可能性"。

### 3.5 步骤四：图像合成

根据最终塌缩结果，将 tile 拼接为输出图像。

```matlab
newImg = zeros([rows*pixNum, cols*pixNum, size(img,3)]);
for i = 1:rows
    for j = 1:cols
        newImg(((i-1)*pixNum+1):(i*pixNum), ...
               ((j-1)*pixNum+1):(j*pixNum), :) = ...
            imgList{indMat(i,j)};
    end
end
```

## 4. 数独 vs WFC：一张表看懂本质

| 维度 | 数独 | WFC（Tiled Model） |
|:---|:---|:---|
| **格子状态** | 数字 $\{1, \ldots, 9\}$ | 图像 tile $\{\text{tile}_1, \ldots, \text{tile}_k\}$ |
| **约束类型** | 同行/列/宫不重复 | 相邻 tile 边缘像素匹配 |
| **约束来源** | 人为规定 | 从样本图像自动提取 |
| **塌缩策略** | 选可能性最少的格子 | 选熵最低的格子 |
| **约束传播** | 削减同行/列/宫的可能性 | 削减相邻格子的可能性 |
| **矛盾处理** | 回溯或重启 | 回溯或重启 |
| **输出** | 唯一解（有解数独） | 多种可能（随机性生成） |

核心观察：**WFC 的算法骨架与数独求解器几乎完全相同**，只是把"数字 + 行列宫约束"泛化为了"tile + 邻接约束"，并加入了权重随机性以产生多样化的输出。

## 5. 两种模型

### 5.1 Tiled Model（拼贴模型）

将样本图像切分为若干个小块（tiles），分析它们之间的邻接关系，然后基于这些关系生成新图像。

- **输入**：一张样本图像 + tiles 的切分信息
- **规则来源**：手工指定或自动提取 tiles 之间的邻接关系
- **优点**：概念简单，可控性强
- **缺点**：需要预先定义 tiles 和邻接规则

### 5.2 Overlapping Model（重叠模型）

不预定义 tiles，而是从样本图像中提取 $N \times N$ 的**像素模式（patterns）**，分析这些模式之间的重叠关系。

- **输入**：仅一张样本图像
- **规则来源**：自动从样本中提取模式及其允许的重叠方式
- **优点**：完全自动化，不需要手工定义规则
- **缺点**：模式数量可能很多，计算开销更大

## 6. 矛盾处理：回溯 vs 重启

当约束传播导致某个格子的可能性清零时，算法遇到了**矛盾**——就像数独中某个格子没有任何合法数字可填。

| 策略 | 方法 | 优点 | 缺点 |
|:---|:---|:---|:---|
| **重启（Restart）** | 放弃当前结果，从头开始 | 实现简单 | 可能多次失败，浪费计算 |
| **回溯（Backtracking）** | 撤销上一次塌缩决策，尝试其他 tile | 更高成功率 | 实现复杂，可能指数级回溯 |

原始 WFC 实现使用**重启策略**。实践表明，对于合理设计的邻接规则，重启几次后几乎总能成功。但对于约束很紧的问题（类似于数独中的"极难数独"），回溯更可靠。

## 7. WFC 与其他程序化生成方法的对比

| 方法 | 原理 | 输入 | 优点 | 缺点 |
|:---|:---|:---|:---|:---|
| **WFC** | 约束传播 + 熵塌缩 | 一张样本图 | 自动学习规则，局部连续性好 | 全局结构不可控 |
| **L-System** | 字符串重写规则 | 产生式规则 | 适合植物/分形结构 | 规则需手工设计 |
| **噪声函数（Perlin/Simplex）** | 梯度噪声插值 | 参数 | 连续平滑，计算快 | 不适合结构化内容 |
| **Cellular Automata** | 局部邻域规则 | 规则 + 初始状态 | 简单直观，适合洞穴生成 | 规则需手工设计 |
| **Voronoi 图** | 最近邻划分 | 种子点 | 天然分区效果 | 生成结果模式单一 |

WFC 的独特优势在于**数据驱动**——只需提供一张样本，算法自动提取规则。不需要手工编写规则，也不需要机器学习训练。
