## 从 PGP 到 N-Symmetric：把方向场设计成可参数化的全局结构

这篇文章想串起两类看起来分开的工作：

1. `PGP` 关心的是：给定一组曲面上的方向，怎样真正算出一张全局参数化。
2. `N-Symmetric direction field` 关心的是：怎样描述、分析并设计带奇异点的方向场拓扑。

如果把两者放在同一条主线上，它们其实分别回答了两个连续的问题：

- 先决定“我希望曲面上有什么样的方向结构”；
- 再把这个方向结构变成真正可用的参数线、图块和最终参数化。

下面按这个逻辑，把图片里的内容重新组织一遍。

## 1. 为什么要研究曲面上的方向场

在曲面展开、四边形网格生成、纹理铺设这些问题里，我们往往并不是直接去解一张 UV 图，而是先指定一个“希望参数线沿着哪里走”的方向场。  
最自然的例子就是主曲率方向场 `Principal Curvature Directions`：它描述了曲面局部弯曲最强和最弱的两个正交方向，因此很适合作为 quad mesh 或参数线的引导。

但这里马上会遇到两个困难：

1. 主曲率方向只在一般位置上定义良好，在脐点 `umbilic` 附近会退化。
2. 即使每个局部区域都能定义方向，想把它们拼成全局一致的参数化也并不容易。

所以，向量场设计和全局参数化，本质上是在处理“局部方向信息如何变成全局结构”这个问题。

## 2. PGP：从局部方向到全局参数化

### 2.1 全局参数化不是一张图，而是一组互相兼容的 chart

先看全局参数化的基本图像：

![image-20251111171425686](..\..\..\imgs\image-20251111171425686.png)

这张图表达的是：一个全局参数化通常不是单独一个映射，而是一组局部参数化$(\varphi ,\varphi',...)$以及它们之间的转移函数。  
换句话说，曲面太复杂时，很难一次性铺平成一个平面区域，于是就需要多个重叠 chart 共同描述整个曲面。
局部都能用平面坐标表示，全局则通过 chart 之间的 transition function 粘起来。

### 2.2 关键不在单个 chart，而在 chart 之间怎么连续

下面这张图强调了已有工作的一个核心思路：

![image-20251111171130926](..\..\..\imgs\image-20251111171130926.png)

图中的意思是，`inter-chart relaxation` 会显式引入 chart 之间的转移函数，然后优化这些转移函数，使不同 chart 在重叠区域里的连续性尽量好。  
因此，全局参数化问题不是“每一块单独铺开得漂不漂亮”，而是“不同块之间能不能平顺地接起来”。

### 2.3 共形结构方法说明：奇异点往往不可避免

再看这张图：

![image-20251111171211269](..\..\..\imgs\image-20251111171211269.png)

图中提到的意思是：Gu 和 Yau 用曲面的 conformal structure 提取一组彼此兼容的局部参数化，但这种连续性通常只能在除了若干奇异点之外的区域成立。  
最直观的例子是球面。球面不可能被一个单一、无畸变且无奇异的平面参数化完整覆盖，所以总要有“极点”那样的特殊位置。

这给后面所有算法都定下了一个现实前提：  
全局参数化往往不是“完全没有奇异点”，而是“在允许少量奇异点的前提下，让整体尽量连续、尽量规则”。

### 2.4 PGP 的输入：曲面网格和两组正交方向

PGP 的输入如图所示：

![image-20251111171257281](..\..\..\imgs\image-20251111171257281.png)

图中的原文意思是：算法输入是一张三角网格，以及两组正交向量场 $\vec K$ 和 $\vec K^\perp$。  
最常见的输入就是估计出来的主曲率方向，但只要满足正交关系，也可以换成用户指定的其他方向。

这里可以把 PGP 理解成一句话：

> 你给我一组你想跟随的方向，我来把它变成全局参数化。

也就是说，PGP 不负责定义“什么方向是最好的”，它主要负责把给定方向转化成真实可解的参数结构。

### 2.5 PGP 的预处理：先把输入方向场变得更适合参数化

PGP 的流程图中，首先提到了两个可选的预处理：

![image-20251111171337407](..\..\..\imgs\image-20251111171337407.png)

这张图里有三个要点。

第一，`vector field smoothing`。  
如果输入的是主曲率方向，那么在各向同性区域或者脐点附近，主方向会不稳定，因为这些地方本来就不存在唯一的“最大/最小”弯曲方向。  
所以需要先做平滑，把这些区域处理成更稳定、更适合后续计算的方向场。

第二，`curl correction`。  
如果方向场本身带有比较强的旋度，那么它通常不能直接积分成全局参数函数，这会迫使参数化产生很多奇异点。  
因此可以先对输入向量场做一次重标定或修正，尽量减少 curl，从而减少后面不可避免的奇异点数量。

第三，PGP 把平移和旋转自由度显式纳入优化变量。  
图中高亮句子强调的是：为了在参数化公式里显式处理 translational 和 rotational degrees of freedom，作者采用了一组替代变量，而不是直接在最终参数值上优化。

这一步的直觉很重要：  
直接优化 UV 容易被“绕了几圈”“平移了多少”这些自由度干扰，而改用三角函数形式的替代变量，会让优化形式更稳定。

### 2.6 PGP 的输出不是直接一张图，而是先得到 chart layout

继续看后两张流程图：

![image-20251111171350367](..\..\..\imgs\image-20251111171350367.png)

![image-20251111171359776](..\..\..\imgs\image-20251111171359776.png)

这两张图说明，PGP 的后处理大致分成几步：

1. 先从优化结果中恢复每个三角形上的局部参数化。
2. 然后检测这些局部参数化中出现的奇异点。
3. 接着根据每个三角形的参数化去定义全局的 `chart layout`。
4. 最后再对每个 chart 重新组装或重参数化，得到真正可用的 per-chart parameterization。

这里最值得注意的是第 3 步。  
PGP 的思想并不是“一开始就知道 chart 怎么切”，而是先在每个三角形上求出局部参数，再从这些局部结果中反推出一张全局图块布局。  
也就是说，chart layout 不是先验输入，而是参数化结果里长出来的结构。

### 2.7 小结：PGP 解决的是“如何把方向场落地”

到这里可以把 PGP 的角色概括成：

- 输入：一张网格和一组希望参数线遵循的正交方向。
- 过程：平滑、减 curl、求解参数化替代变量、恢复局部参数、检测奇异点、构造图块。
- 输出：全局连续、局部可解释的 chart parameterization。

所以 PGP 更偏几何计算和参数化实现层面，它解决的是“已知方向，如何出图”。

## 3. N-Symmetric Direction Field：如何描述带奇异点的方向场

如果说 PGP 更关心“求解”，那么 `N-Symmetric` 工作更关心“表示”和“拓扑控制”。

它研究的是一类更一般的方向场：  
向量方向不是唯一的，而是相差 $2\pi/N$ 的方向视为等价。  
例如：

- `N = 1` 时就是普通向量场；
- `N = 2` 时像线场、纹理流线那样，正反方向等价；
- `N = 4` 时就对应常见的 cross field。

### 3.1 分数指标奇异点是怎么来的

先看图：

![image-20251111163816759](..\..\..\imgs\image-20251111163816759.png)

这张图给了两个典型例子：

- 左边是立方体状物体上的平滑 cross field，出现了 `+1/4` 的奇异点；
- 右边是指纹上的方向场，出现了 `+1/2` 和 `-1/2` 的奇异点。

这说明一个很重要的现象：  
对于 N-symmetric direction field，奇异点指标不再一定是整数，而可能是分数。  
这并不是“异常”，而是因为方向本身只在模 $2\pi/N$ 的意义下有定义，所以绕一圈后的净旋转也 naturally 允许出现分数化的 index。

### 3.2 用 turning number 来研究方向场拓扑

对应的理论入口如下：

![image-20251111164006268](..\..\..\imgs\image-20251111164006268.png)

这张图的重点是：作者用 `turning number` 来系统研究 N-symmetry direction field 的拓扑。  
奇异点 index 只是局部量，而 turning number 则是沿一条闭合曲线统计方向场总共“转了多少圈”，它更适合描述全局拓扑类别。

### 3.3 同伦等价：哪些方向场能连续变形成彼此

![image-20251111164118941](..\..\..\imgs\image-20251111164118941.png)

它表达的是同伦 `homotopy` 的概念：  
如果一个方向场能通过连续变形变成另一个方向场，那么两者就是同伦等价的；反之就不是。

对方向场设计来说，这一点非常关键，因为我们并不只关心“局部角度长什么样”，更关心“它属于哪个拓扑类”。  
有些方向场看着只是局部弯了一点，但其实已经跨越了一个拓扑边界，不能靠平滑变回去。

### 3.4 先定义 curvature，再定义 turning number

下面两张图给出了连续定义：

![image-20251111164530207](..\..\..\imgs\image-20251111164530207.png)

这张图里说，沿着一条曲线链 `\gamma`，它的 curvature 描述的是切向方向随弧长的角变化。  
也就是说，曲线本身会转，而方向场也会相对这条曲线发生额外转动。

再看 turning number：

![image-20251111164356051](..\..\..\imgs\image-20251111164356051.png)

这张图的核心公式可以理解成：

$$
T_{\vec d}(\gamma)=\frac{1}{2\pi}\oint_\gamma (\kappa_{\vec d}-\kappa_\gamma)\,ds
$$

它衡量的是：当你沿着一条闭合曲线走一圈时，方向场相对于曲线切向到底净旋转了多少。  
因此 turning number 是一个“沿环路的拓扑不变量”。

### 3.5 turning number 决定同伦类

对应的定理如下：

![image-20251111164424288](..\..\..\imgs\image-20251111164424288.png)

图中说：如果两个定义在同一个曲面上的方向场，在一组同调基 `H(S)` 的所有环上都有相同的 turning number，那么它们就是同伦等价的。

这个结论非常强。  
它说明要控制方向场的全局拓扑，并不需要记住每个点的方向，只需要控制若干代表性闭环上的 turning number 即可。

### 3.6 奇异点指数与 Euler 示性数

奇异点局部指标的定义在这里：

![image-20251111164629687](..\..\..\imgs\image-20251111164629687.png)

图中给出的意思是：在奇异点附近取一个小环路，统计方向场相对参考方向的净旋转角，再除以 `2\pi`，就得到这个点的 index。  
对于普通向量场，这个值通常是整数；对于 N-symmetric field，则会出现分数指标。

再看全局约束：

![image-20251111164729785](..\..\..\imgs\image-20251111164729785.png)

这就是 Poincare-Hopf 类型的结论：  
闭曲面上所有奇异点指标之和，必须等于曲面的 Euler 示性数。

这句话的含义是：  
奇异点不能随便增删。你如果想把某个位置的 index 改掉，就必须在别的地方做补偿，全局拓扑账必须平。

## 4. 离散表示：用 period jumps 来编码方向场拓扑

连续理论很好，但算法最终要落到三角网格上。  
N-Symmetric 的一个关键贡献，就是把 turning number 的拓扑信息转化成了一个非常适合离散计算的数据结构：`period jumps`。

### 4.1 turning number 最终只依赖于 period jumps

先看这张图：

![image-20251111165518808](..\..\..\imgs\image-20251111165518808.png) 
方向场的 turning number，在离散数据结构里最终只依赖于 period jumps。  
这意味着，只要我们控制好这些整数跳变量，就等于控制了方向场的拓扑。

### 4.2 period jump 的离散定义

下面这张图给出离散化公式：

![image-20251111164825645](..\..\..\imgs\image-20251111164825645.png)

它的意思是：

1. 在每个三角形面上选一个参考方向 $\vec d_0$。
2. 用一个角度标量 $\theta$ 表示实际方向 $\vec d$ 相对参考方向转了多少。
3. 在每条对偶边上引入一个整数 `p`，表示由于 `N` 重对称造成的周期跳变。

离散曲率满足

$$
\kappa_{\vec d}=\kappa_0+d\theta+\frac{2\pi p}{N}.
$$

这里最关键的是最后一项。  
它表示方向场在跨越离散单元时，允许发生一个整周期的“跳层”；这种跳不是误差，而是 N-symmetry 自带的等价关系。

### 4.3 一个方向场由三部分数据完全确定

接着看这张图：

![image-20251111164844596](..\..\..\imgs\image-20251111164844596.png)

因此，一个离散方向场实际上由三类量决定：

1. 每个面上的局部参考方向 `d0`；
2. 每个面上的角度标量 `\theta`；
3. 每条对偶边上的整数 `period jump`，也就是 `p`。

这一步是整个理论落地的关键，因为它把一个“看起来是连续对象”的方向场，拆成了：

- 实值变量 `\theta`；
- 整数变量 `p`；
- 以及一个固定的局部参考系 `d0`。

后面算法就可以在这个离散表示上直接做优化和拓扑约束。

## 5. Zipper：如何在给定奇异点指标后构造 period jumps

现在问题就变成了：  
如果我事先指定了每个顶点希望出现什么奇异点指标，能不能反过来求出一组合法的 `p`？

这正是 `Zipper` 算法要解决的事情。

### 5.1 问题形式

先看问题定义：

![image-20251111165152292](..\..\..\imgs\image-20251111165152292.png)

图中的意思是：  
给定每个内点顶点的约束奇异点指标 $I_c(v_i)$，求对偶边上的整数 `p`，使得最终方向场在这些顶点上的实际 index 恰好等于目标值。

通过公式改写后，会变成一个围绕每个顶点的整数守恒关系：

$$
\sum_{e^*\in \partial v^*} p(e^*)=\Delta I(v).
$$

也就是说，围绕一个顶点的一圈 period jumps 之和，必须补足该顶点所需要的 index 差额。

### 5.2 Zipper 的核心思想：把对偶边分成三类

算法流程图如下：

![image-20251111165215004](..\..\..\imgs\image-20251111165215004.png)

图里把对偶边分成三类：

1. `null edges`：对应的 period jump 可以直接设为 0，不会约束 turning number。
2. `free edges`：这些边决定的是同调基上的 turning number，也就是全局拓扑自由度。
3. `dependent edges`：这些边的 period jump 不能自由选，而是为了满足各个顶点的奇异点指标约束而被动决定。

所谓 `Zipping`，就是用一个贪心过程逐步完成这三类边的分类，并在分类的同时建立 dependent edges 对 free edges 的依赖关系。  
于是，原本很难同时兼顾的“局部奇异点约束”和“全局拓扑自由度”，就被拆开管理了。

### 5.3 有了拓扑结构之后，再做几何优化

接着看方向场设计的优化模型：

![image-20251111165259490](..\..\..\imgs\image-20251111165259490.png)

这张图给出的目标函数，本质上是在说：

- 给定网格；
- 给定每个顶点希望出现的奇异点指标；
- 可能还给定一部分面的方向约束；
- 在满足这些条件的前提下，让方向场尽可能平滑。

因此，这一步回答的是“几何长相”问题，而前面的 Zipper 回答的是“拓扑类型”问题。  
两者合起来，才构成完整的方向场设计。

### 5.4 设计算法整体流程

最后一张图给了完整算法：

![image-20251111165315826](..\..\..\imgs\image-20251111165315826.png)

把它翻成更好懂的话，大致就是：

1. 先设置目标奇异点指标。
2. 在每个面上选参考方向 `d0`。
3. 计算各对偶边上的基准角差 `\kappa_0`。
4. 计算各顶点的角缺陷和基准 index。
5. 得到每个顶点所需补偿的 `\Delta I`。
6. 应用 Zipper 算法，构造合法的 period jumps。
7. 建立关于 `\theta` 和自由整数变量的线性系统。
8. 先解连续变量，再对整数变量做取整或修正。
9. 最终恢复每个面上的方向。

从这个角度看，N-Symmetric 的整套框架已经非常完整：

- 连续理论上，用 turning number 描述拓扑；
- 离散表示上，用 period jumps 编码拓扑；
- 算法上，用 Zipper 和线性系统把目标拓扑转成一个实际可计算的方向场。

## 6. 把 PGP 和 N-Symmetric 串起来看

现在就可以把两部分真正连成一条线了。

### 6.1 N-Symmetric 负责“设计什么方向场”

N-Symmetric 告诉我们：

- 什么叫方向场的奇异点；
- 奇异点为什么可能有分数指标；
- turning number 如何决定方向场的拓扑类别；
- 怎样用 period jumps 在网格上离散地控制这些拓扑性质；
- 如果我想要某些顶点出现指定 index，该怎样构造一组合法的方向场。

所以它解决的是“方向场设计”和“拓扑控制”。

### 6.2 PGP 负责“把方向场变成参数化”

而 PGP 告诉我们：

- 给定一组方向，尤其是两组正交方向；
- 先做平滑和 curl 修正；
- 再求局部参数；
- 最后从局部参数中恢复全局 chart layout 和 per-chart parameterization。

所以它解决的是“参数化求解”和“结构提取”。

### 6.3 一个完整工作流

如果把两者结合起来，一个很自然的工作流就是：

1. 先从主曲率方向、用户交互约束或者其他几何特征出发，设定方向场目标。
2. 用 N-Symmetric 的语言分析其拓扑，决定哪些地方应该有奇异点、这些奇异点应当是什么 index。
3. 用 period jumps 和 Zipper 算法构造一个满足目标拓扑的离散方向场。
4. 如果需要正交双方向，可以再从该方向场中导出一对正交场。
5. 把这组方向送入 PGP，进行平滑、curl correction 和参数化求解。
6. 最终得到图块布局、每个 chart 的参数化，以及适合 quad mesh 提取的参数线结构。

换句话说：

> N-Symmetric 更像“设计蓝图”，PGP 更像“把蓝图施工落地”。

## 7. 总结

这组图片合起来，其实讲的是一个非常完整的故事。

第一步，我们从曲面几何中提取或设计一组方向。  
第二步，我们意识到方向场不是只有几何形状，还有拓扑类别，而奇异点和 turning number 正是描述这种拓扑的核心语言。  
第三步，我们用 period jumps 把这种拓扑信息离散化，进而通过 Zipper 算法把“目标奇异点配置”变成实际可计算的方向场。  
第四步，再把这个方向场交给 PGP，真正求出全局参数化和 chart layout。

因此，`PGP` 和 `N-Symmetric` 并不是两个彼此孤立的话题：  
前者解决“如何参数化”，后者解决“参数化应该沿着什么拓扑结构走”。  
只有把方向场设计与参数化求解连起来看，才能真正理解现代 quad mesh 和全局参数化算法的完整框架。
