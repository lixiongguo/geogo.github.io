## 1. 双曲空间的几何基础

### 1.1 什么是双曲空间

欧式空间是曲率为零的空间，双曲空间是常曲率为负的空间。

- 在二维情况下，称为**双曲平面**（hyperbolic plane），记作 $\mathbb{H}^2$
- 特点：
  - 三角形内角和 < 180°
  - 过直线外一点有**无穷多条**平行线
  - 圆的周长和面积随半径**指数增长**（而非欧氏的线性/二次）

但双曲空间无法**等距嵌入**到三维欧氏空间中（Hilbert 定理），所以我们需要**模型**来研究它。

### 1.2 庞加莱圆盘

庞加莱圆盘是一种特殊的双曲空间模型。

庞加莱圆盘具有**共形性**，适合进行可视化。庞加莱圆盘 = 双曲平面的"地图投影"——就像墨卡托投影之于地球，虽有形变，但忠实保留了关键几何性质（这里是角度）。

**边界圆代表无穷远**。

在常规的欧几里得几何中，圆的周长与半径之间存在正比关系，但在双曲几何中，这种关系则变为指数型。我们可以观察到，在双曲圆盘的边界附近，堆积的三角形数量呈现出指数级的增长。

### 1.3 伪球面与双曲圆盘

![image-20251216202024945](..\..\..\imgs\image-20251216202024945.png)

- 伪球面是由**曳物线（tractrix）** 绕其渐近线旋转而成的旋转曲面
- 它具有**常负高斯曲率** $K = -1$，与双曲平面相同

> **伪球面是双曲平面的一个局部等距嵌入（仅覆盖一部分），而庞加莱圆盘是整个双曲平面的完整、共形模型。**
> 伪球面**不能**代表完整的双曲空间，而庞加莱圆盘可以。

## 4. 双曲四面体与Lobachesky函数

### 4.1 从双曲三角形到双曲四面体

在欧氏几何中，三角形的面积由底×高决定；而在双曲几何中，**面积完全由角度决定**——这就是著名的 **Gauss-Bonnet 公式**：

$$\text{Area}(\triangle) = \pi - (\alpha + \beta + \gamma)$$

其中 $\alpha, \beta, \gamma$ 是双曲三角形的三个内角。这个**亏量**（defect）$\pi - (\alpha+\beta+\gamma)$ 正比于面积。

将这一思想推广到三维双曲空间 $\mathbb{H}^3$，我们考虑最简单的多面体——**双曲四面体**（hyperbolic tetrahedron）。与双曲三角形类似，双曲四面体的体积也由其**二面角**（dihedral angles）唯一决定。

### 4.2 Lobachevsky 函数

**Lobachevsky 函数**（也记作 $\Lambda(x)$ 或 $\Pi(x)$）是研究双曲几何的核心特殊函数：

$$\boxed{\Lambda(x) = -\int_0^x \ln|2\sin t|\, dt}$$

该函数具有以下关键性质：

| 性质 | 表达式 |
|:-----|:-------|
| **奇函数** | $\Lambda(-x) = -\Lambda(x)$ |
| **周期性** | $\Lambda(x + \pi) = \Lambda(x)$ |
| **Duplication 公式** | $\Lambda(2x) = 2\Lambda(x) + 2\Lambda\left(\frac{\pi}{2} - x\right)$ |
| **特殊值** | $\Lambda\left(\frac{\pi}{2}\right) = 0$, $\quad \Lambda\left(\frac{\pi}{3}\right) = \frac{G}{3}$ （$G$ 为 Catalan 常数） |
| **级数展开** | $\displaystyle\Lambda(x) = \sum_{n=1}^{\infty}\frac{\sin(2nx)}{n^2}$ |

> **注：** 该函数最早由 N.I. Lobachevsky 在其关于非欧几何的研究中引入，用于表达双曲四面体的体积。C.L. Siegel 后来对其进行了深入研究。

### 4.3 双曲余弦定律（二面角形式）

设双曲四面体的六个二面角分别为：

$$\theta_{ij}, \quad i < j,\quad i,j \in \{0,1,2,3\}$$

其中 $\theta_{ij}$ 是以边 $e_{ij}$ 为公共棱的两个面的夹角。

对于任意一个顶点 $i$ 处相交的三条棱上的三个二面角，满足**双曲余弦关系**。以顶点 0 为例，有：

$$\cos\theta_{23} = \cos\theta_{12}\cos\theta_{13} + \sin\theta_{12}\sin\theta_{13}\cos\alpha_0$$

其中 $\alpha_0$ 是顶点 0 处的**立体角**（solid angle）。这可以看作是球面余弦定律在双曲空间中的推广。

更一般地，六个二面角必须满足一定的相容条件才能构成合法的双曲四面体——它们对应于 Gram 矩阵的正定性约束。

### 4.4 双曲四面体的体积公式

双曲四面体的体积可以用 **Lobachevsky 函数**精确表达。最经典的形式是 **Murakami-Yano 公式**（1995）以及更早的 **Milnor-Schlafli 公式**：

#### 基本形式

设双曲四面体的六个二面角为 $\theta_{01}, \theta_{02}, \theta_{03}, \theta_{12}, \theta_{13}, \theta_{23}$。则体积可表示为：

$$V = \frac{1}{8}\sum_{i=0}^{7}\varepsilon_i\,\Lambda(\phi_i)$$

其中 $\phi_i$ 是由二面角通过特定线性组合构造的角度参数，$\varepsilon_i = \pm 1$ 为符号系数。

#### 更直观的形式（Chen 形式）

对于**理想四面体**（ideal tetrahedron，即所有四个顶点都在无穷远处），体积只取决于三个**边参数** $z_1, z_2, z_3 \in (0, \pi)$：

$$V(z_1, z_2, z_3) = \Lambda(z_1) + \Lambda(z_2) + \Lambda(z_3) + \Lambda(z_1 + z_2 + z_3 - \pi)$$

这三个边参数满足 $z_1 + z_2 + z_3 > \pi$ 且每个 $z_i < \pi$。

#### 一般情形（非理想四面体）

对于一般的（紧致或有理想顶点的）双曲四面体，体积公式更为复杂，需要用到 **五项恒等式**（pentagonal identity）：

$$V = \sum_{k=1}^{6}(-1)^{s_k}\,\Lambda(\omega_k)$$

其中 $\omega_k$ 由二面角的加减组合给出，符号 $s_k$ 取决于具体配置。

### 4.5 Schläfli 微分公式

理解双曲体积的一个有力工具是 **Schläfli 微分公式**，它描述了体积对二面角变化的响应率：

$$\boxed{dV = \frac{1}{2}\sum_{\text{edges } e} \ell_e\, d\theta_e}$$

即：**体积的变化等于各边长度乘以该边二面角变化之和的一半**。

这意味着：
- 若固定所有边长，仅变化二面角，则体积由上述积分确定
- 对理想四面体（边长趋于无穷），需取极限处理
- 该公式适用于任意维度的常曲率空间中的单形

### 4.6 与计算几何的联系

在计算几何应用中，双曲四面体的体积公式有以下实际意义：

1. **3D 双曲网格处理**：在 $\mathbb{H}^3$ 中进行网格生成/简化时，需要计算单元体积以控制误差度量
2. **体积比较与验证**：给定一组二面角，快速判定是否能形成有效双曲四面体（检查 Gram 矩阵正定性）
3. **离散 Ricci 流**：在双曲背景下的曲面参数化中，四面体体积作为能量泛函的一部分出现
4. **理想剖分体积估计**：双曲流形的理想剖分体积可通过各理想四面体体积求和得到，这是 3-流形拓扑的重要不变量

### 4.7 数值示例

以下是一些典型值：

| 四面体类型 | 二面角特征 | 近似体积 |
|:-----------|:-----------|:---------|
| 理想正四面体 | 全部二面角 = 60° | $V \approx 1.0149416...$ |
| 极薄四面体（退化） | 一个二面角 → 0 | $V \to 0$ |
| 最大体积紧致四面体 | 特殊优化配置 | $V < 3.330...$（Jørgensen 定理）|

最大体积的理想四面体体积约为 $V_{max} \approx 1.01494$（当所有二面角相等时达到），而紧致（有限体积）双曲四面体的体积上界约为 $V_{compact} < 3.330$。

### 4.9 Lobachevsky 函数与圆填充（Circle Packing）的深层联系

圆填充（Circle Packing）是离散共形几何的核心工具，而 Lobachevsky 函数在其中扮演着**能量函数**的关键角色。这一联系最早由 Thurston（1985）提出，后经 Colin de Verdière、Rivin、Bobenko-Springborn 等人系统化。

#### 4.9.1 从连续到离散：双曲余弦定律的离散化

在 $\mathbb{H}^3$ 中，一个理想四面体 $T$ 的体积由其三个**边参数** $z_1, z_2, z_3$ 完全确定：

$$V_T(z_1,z_2,z_3) = \Lambda(z_1) + \Lambda(z_2) + \Lambda(z_3) + \Lambda(z_1+z_2+z_3-\pi)$$

这些边参数与理想四面体的**内二面角** $(\theta_{01},\theta_{12},\theta_{20})$ 通过双曲余弦定律关联：

$$\cos\theta_{ij} = \frac{\cos z_k + \cos z_i\,\cos z_j}{\sin z_i\,\sin z_j}, \qquad (i,j,k)\text{ 为 }(0,1,2)\text{ 的循环排列}$$

> **关键洞察**：若将圆填充中的相邻圆之间的夹角视为"离散化的二面角"，则每个三角形对应一个**理想双曲四面体的截面**，整个圆填充的能量就是所有四面体体积之和。

#### 4.9.2 圆填充的基本设定

考虑曲面上的**三角网格**，在每个顶点 $v$ 放置一个圆（或双曲圆/欧氏圆），使得：

- **相邻约束**：两个共享边的圆之间满足指定的相交角 $\Theta_e$（通常为 0 表示相切）
- **半径变量**：每个顶点 $v$ 有一个（双曲）半径 $r_v > 0$

![circle-packing-schematic](../../imgs/circle-packing-schematic.png)

对于欧氏圆填充，相邻两圆的几何约束为：

$$\cosh d_{uv} = \cosh r_u\,\cosh r_v - \sinh r_u\,\sinh r_v\,\cos\Theta_{uv}$$

其中 $d_{uv}$ 为边 $e=(u,v)$ 的长度。当 $\Theta_{uv} = 0$（外切）时简化为：

$$d_{uv} = r_u + r_v$$

#### 4.9.3 Rivin 的变分原理

**I. Rivin (1996)** 证明了以下深刻的变分原理：

设 $\mathcal{T}$ 是拓扑球面上的三角剖分，$\{r_v\}_{v\in V}$ 是一组正实数（半径），则由这组半径确定的圆填充的 **Rivin 能量函数**定义为：

$$E(\mathbf{r}) = \sum_{f\in F} V_f(\mathbf{r}|_f)$$

其中 $V_f$ 是以面 $f$ 对应的理想四面体的体积（用该面的三条边对应的半径参数通过 Lobachevsky 函数表示），求和覆盖所有面。

**核心定理（Rivin, 1996；Bobenko-Springborn, 2004）：**

$$\boxed{\frac{\partial E}{\partial r_v} = K_v - 2\pi}$$

即：**Rivin 能量的梯度等于离散高斯曲率减去目标曲率**。因此：

| 条件 | 结论 |
|:-----|:-----|
| $\frac{\partial E}{\partial r_v} = 0$ 对所有 $v$ | 圆填充具有常曲率（离散共形映射存在性证明） |
| Hessian 矩阵 $\nabla^2 E$ 正定 | 解是唯一的（模整体缩放） |
| 能量严格凸 | 牛顿迭代法保证收敛 |

这意味着 **Lobachevsky 函数的和构成了圆填充问题的凸势能**——寻找指定曲率的圆填充等价于求解这个能量的临界点！

#### 4.9.4 具体公式推导

取一个三角形面 $f = (u,v,w)$，设其三边对应的交角参数为 $z_u, z_v, z_w$（与半径的关系取决于具体模型），则该面对能量的贡献为：

$$E_f = \Lambda(z_u) + \Lambda(z_v) + \Lambda(z_w) + \Lambda(z_u+z_v+z_w-\pi)$$

对某个半径 $r_u$ 求偏导（利用 $\frac{d}{dx}\Lambda(x) = -\ln|2\sin x|$）：

$$\frac{\partial E_f}{\partial r_u} = -\ln(2\sin z_u)\cdot\frac{dz_u}{dr_u} - \ln(2\sin(z_u+z_v+z_w-\pi))\cdot\frac{dz_u}{dr_u}$$

经过复杂的三角恒等变换，可以证明：

$$\sum_{f\ni v}\frac{\partial E_f}{\partial r_v} = K_v - K_v^{target}$$

其中 $K_v = 2\pi - \sum_{f\ni v}\alpha_f^v$ 是顶点 $v$ 处的角度和亏量，即**离散高斯曲率**。

#### 4.9.5 三种圆填充模型及其统一框架

Bobenko 和 Springborn (2004) 提出了一个统一的**变分框架**，涵盖三种经典圆填充：

| 模型 | 曲率类型 | 半径范围 | 能量形式 |
|:-----|:---------|:---------|:---------|
| **欧氏圆填充** | $K=0$（平面） | $r_v \in (0,+\infty)$ | $\displaystyle E=\sum_f\big[\Lambda(\theta_f^u)+\Lambda(\theta_f^v)+\Lambda(\theta_f^w)+\Lambda(2\pi-\theta_f^u-\theta_f^v-\theta_f^w)\big]$ |
| **双曲圆填充** | $K=-1$（双曲平面） | $r_v \in (0,+\infty)$ | 同上，但角度在双曲几何中计算 |
| **球面圆填充** | $K=+1$（球面） | $r_v \in (0,\pi)$ | 需用**球面 Lobachevsky 函数** $\tilde{\Lambda}$ 替代 |

三种情形下，能量函数的**一阶条件**均为：

$$\frac{\partial E}{\partial r_v} = K_v - K_v^{target},\quad \forall v$$

这就是著名的 **Bobenko-Springborn 变分原理**，它将圆填充问题统一到了**离散微分几何的能量泛函框架**下。

#### 4.9.6 与虚拟半径法（Virtual Radius Method）的联系

在实际的曲面参数化中（如 LSCM、ABF 等），**虚拟半径法**是一种广泛使用的技巧：

1. 给定目标曲率 $\bar{K}_v$（如 $K=0$ 用于平面参数化）
2. 初始化各点虚拟半径 $\{r_v\}$
3. 计算当前曲率 $K_v$
4. 更新：$r_v^{new} = r_v + \tau(K_v - \bar{K}_v)$ （梯度下降）
5. 重复直至收敛

这正是 **Rivin 能量的梯度流**！每一步更新都在最小化由 Lobachevsky 函数构成的势能：

$$r_v^{new} = r_v - \eta\,\frac{\partial E}{\partial r_v}$$

因此：
- **牛顿法**对应于利用 Hessian 矩阵的二阶优化
- **加权 Delaunay 三角化重连**对应于改变能量定义域的拓扑结构
- **全局最优解的存在性与唯一性**直接源于能量的严格凸性

#### 4.9.8 应用实例

##### 实例1：离散 Ricci 流

**离散 Ricci Flow** (Jin et al., 2008; Gu-Yau, 2008) 的核心方程：

$$\frac{dr_v(t)}{dt} = -(K_v(t) - \bar{K}_v)$$

其右端正是 $-\frac{\partial E}{\partial r_v}$，因此 Ricci 流就是 Rivin 能量的**梯度流**。最终稳态解即为能量极小值点，对应于目标曲率的圆填充配置。

##### 实例2：曲面参数化

将闭曲面共形映射到平面上（$K_{target}=0$），等价于找到满足 $K_v = 0$（内部顶点）的圆填充。此时：

$$E_{min} = \sum_f V_f^{euclidean}$$

给出参数化后的**最优形状**度量。Lobachevsky 函数保证了此过程有唯一的全局最优解。

##### 实例3：Voronoi 图的对偶关系

圆填充生成的 **Delaunay 三角剖分**与 **Voronoi 图**互为对偶：

```
  圆填充 (Circle Packing)          Voronoi 对偶图
  ┌────────────────────┐          ┌────────────────────┐
  │   ○     ○           │          │   ╲   │   ╱         │
  │  / \   / \          │   ↔      │    ╲  │  ╱          │
  │ ○───●───○    ●=中心 │          │     ╲│╱    ← 单元  │
  │  \ /   \ /          │          │      ×              │
  │   ○     ○           │          └────────────────────┘
  └────────────────────┘
  Delaunay 三角形              Voronoi 多边形（对偶）
```

每个 Voronoi 单元的面积变化率也通过 Lobachevsky 函数的导数与曲率关联。

#### 4.9.9 总结：Lobachevsky 函数的角色定位

| 角色 | 说明 |
|:-----|:-----|
| **原初角色** | 双曲四面体体积的表达式 |
| **推广角色** | 离散共形几何的**势能密度函数** |
| **物理类比** | 弹簧系统的弹性势能——曲率偏差是"力"，半径位移是"坐标" |
| **算法价值** | 保证圆填充/参数化/Ricci 流问题的**凸性和唯一可解性** |
| **理论桥梁** | 连接**连续双曲几何**与**离散组合几何** |

> **一句话总结**：**Lobachevsky 函数不仅是计算双曲四面体体积的工具，更是圆填充方法乃至整个离散共形几何理论的"能量基石"——它将纯几何的约束问题转化为光滑凸优化问题，从而保证了算法的收敛性和解的唯一性。**

### 总结

| 特性 | 欧氏空间 | 双曲空间 |
|:---|:---|:---|
| **曲率** | $K = 0$ | $K = -1$（常负） |
| **体积增长** | 多项式（$O(r^n)$） | 指数（$O(e^{(n-1)r})$） |
| **适合数据** | 相对均匀分布的数据 | 层次化/树形结构数据 |
| **平行线** | 过一点只有一条 | 过一点有无穷多条 |
| **三角形内角和** | $= 180°$ | $< 180°$ |
| **异常检测优势** | 特征变形大 | 层次结构保持好 |
| **可视化** | 直观 | 需要模型（如庞加莱圆盘） |
