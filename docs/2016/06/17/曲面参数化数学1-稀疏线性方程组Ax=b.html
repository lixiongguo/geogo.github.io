线性方程组 $Ax = b$

我们先不讨论方程的解存在性问题，假设解是存在的，我们考虑数值求解的算法

1.Jacobi与Gauss-Seidal方法

都是迭代方法

将方程Ax=b展开

Jacobi方法

充分利用数据，并借助并行化可以优化为Gauss-Seidal

可以证明如果矩阵是对角占优的，那么将收敛

CG方法(Conjugate gradients)

线性方程解，等价于二次型的最优化

梯度下降路径的选择是关键

算法

迭代法的不足

稀疏对称矩阵的sparse Cholesky分解 A=LLT

如果矩阵不是稀疏对称的，则无法使用

其他分解包括LU分解等，但是效率不如Cholesky分解

Eigen库

适用于大规模稀疏系统（如 PDE 离散、图问题），主要是使用直接法，这些方法都是Eigen自带的无需引用其他三方包

求解器 适用矩阵 依赖 特点
SimplicialLDLT 对称正定 内置 轻量，适合 2D 问题
SimplicialLLT 对称正定 内置 比 LDLT 更快但更不稳定
SparseLU 任意方阵 内置 基于 SuperLU，支持非对称
SparseQR 任意矩阵 内置 用于最小二乘，内存高 
#include <Eigen/Sparse>
#include <Eigen/SparseLU>

Eigen::SparseMatrix<double> A(n, n);
// ... fill A ...

Eigen::VectorXd b(n);
// ... fill b ...

Eigen::SparseLU<Eigen::SparseMatrix<double>> solver;
solver.compute(A);

if (solver.info() != Eigen::Success) {
    std::cerr << "Decomposition failed!" << std::endl;
    return -1;
}

Eigen::VectorXd x = solver.solve(b);
