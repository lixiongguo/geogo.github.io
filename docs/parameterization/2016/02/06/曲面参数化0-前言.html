曲面参数化系列——前言
2016/02/06

写在前面

这是一系列关于曲面参数化（Surface Parameterization） 的技术文章，旨在以直观、实践的方式，带领读者从基础走向前沿。我们相信：

数学是美的，美丽的风景值得被画下来。

本系列追求少而深刻的数学概念，通过动手编程、可视化工具、公式推导，让抽象的数学变得可触摸、可玩味。

一、什么是曲面参数化？

1.1 基本定义

曲面参数化是指建立三维曲面与二维平面区域之间的一一对应映射。用数学语言描述：

设 $S \subset \mathbb{R}^3$ 是一张三维曲面，$\Omega \subset \mathbb{R}^2$ 是平面区域，参数化即寻找映射：

\[f: S \to \Omega\]

使得 $f$ 是双射（一一对应），且具有某种”良好”性质（如保持角度、面积等）。

1.2 为什么需要参数化？

参数化是数字几何处理中的基础核心技术，几乎所有需要将三维曲面”展开”到平面的任务都依赖它：

应用领域 具体用途
纹理映射 将二维图像贴到三维模型表面
网格处理 网格重剖、网格简化、网格修复
几何建模 曲面重建、曲面编辑
数值计算 在曲面上求解偏微分方程（PDE）
物理仿真 弹性体模拟、流体仿真
3D 打印 将曲面展开以便加工
医学影像 大脑皮层展平、血管展开

1.3 核心挑战

参数化的核心矛盾在于：曲面的高斯曲率决定了它能否被无扭曲地展平。

根据 Theorema Egregium（绝妙定理），高斯曲率是内蕴量，不能通过等距变换改变。因此：

  • 高斯曲率为零的曲面（如柱面、锥面）可以无扭曲地展平
  • 高斯曲率非零的曲面（如球面）不可能无扭曲地展平

这意味着，对于一般曲面，参数化必然引入扭曲。算法设计的目标就是：在满足约束的前提下，最小化扭曲。

二、发展脉络：2000—2020

曲面参数化领域在过去二十年经历了蓬勃发展。以下是按时间顺序的主要里程碑：

2.1 奠基期（1997—2003）

年份 算法 核心贡献
1997 Tutte’s Barycentric 基于重心坐标的凸组合映射，保证无翻转但扭曲较大
1997 Floater 推广 Tutte 方法，提出更灵活的重心坐标权重
2000 ABF (Angle Based Flattening) 从角度出发，通过非线性优化求解参数化
2002 LSCM (Least Squares Conformal Maps) 将保角性转化为线性最小二乘问题，计算高效
2002 DCP / GIM 离散共形映射与几何图像方法
2003 Gu_GCP 顾险峰团队的全局共形参数化方法
2003 Bobenko Circle Patterns 的变分原理

2.2 发展期（2004—2010）

年份 算法 核心贡献
2004 Bobenko-Springborn 完善 Circle Patterns 的变分理论
2005 Gortler PGP / Alliez 几何图像与参数化质量优化
2006 Tong / Morse / Nsymmetric 处理高亏格曲面的全局参数化
2007 QuadCover 四边形网格生成的基础——全局参数化
2008 CirclePatterns 完整的 Circle Patterns 参数化算法实现
2008 ARAP 尽可能刚性参数化，保持局部形状
2008 CETM 离散等温坐标方法
2008 Ricci Flow 离散 Ricci 流参数化
2009 MIQ / Holonomy 混合整数四边形网格生成
2010 Trivial Connection 基于平凡联络的全局参数化

2.3 成熟期（2011—2020）

年份 算法 核心贡献
2012 Incremental / Lipmann 增量式参数化方法
2014 Frame Fields 基于标架场的参数化与四边形网格生成
2015 BDHM 边界敏感的高质量参数化
2016 Analytical Eigen 特征值问题的解析方法
2017 BFF (Boundary First Flattening) 边界优先展平，快速且可控制边界
2017 SLIM 可扩展局部保角映射
2017 Global Harmonic 全局调和参数化

三、核心数学概念

参数化涉及深刻的数学理论。以下是本系列将要涉及的核心概念：

3.1 复分析

概念 与参数化的关系
全纯函数 共形映射的复解析表示
柯西-黎曼方程 保角映射的微分条件
黎曼映射定理 单连通区域到单位圆盘的共形映射存在性
解析延拓 局部共形映射的全局延拓

3.2 微分几何

概念 与参数化的关系
第一基本形式 曲面的内蕴度量
等温坐标 第一基本形式为对角形式，共形参数化的基础
高斯曲率 决定曲面能否无扭曲展平
单值化定理 任意曲面可赋予常曲率度量
高斯-博内定理 曲率与拓扑的关系

3.3 拓扑与代数拓扑

概念 与参数化的关系
亏格（Genus） 曲面的”洞”的数量，决定参数化复杂度
同调群 曲面的”环”结构
基本群 非单连通区域的处理
割线 将高亏格曲面切分为单连通区域

3.4 凸优化

概念 与参数化的关系
凸函数 保证优化问题的唯一解
拉格朗日乘子 处理约束优化问题
变分原理 能量泛函的临界点对应最优解

四、待深入的问题

本系列将逐步回答以下核心问题：

4.1 理论层面

  1. CETM 能量与 CirclePatterns 能量的联系

    CETM（Combinatorial Equilateral Triangle Mesh）的能量泛函与 Circle Patterns 的能量泛函形式相似但又有差异，这些奇怪的表达式是如何推导出来的？它们与双曲几何有何联系？

  2. Riemann 定理与单值化定理

    Riemann 映射定理如何保证单连通区域的共形映射存在性？单值化定理如何推广到任意拓扑？它们与离散参数化有何对应关系？

  3. Yamabe 方程与等温坐标

    Yamabe 方程是寻找常曲率度量的 PDE，它与离散共形参数化有何关系？如何在数值上求解？

4.2 算法层面

  1. 不同方法的适用场景是什么？

    • Tutte 方法简单但有局限
    • LSCM 快速但需要固定两点
    • ABF 质量高但计算量大
    • Circle Patterns 理论完美但实现复杂
    • BFF 灵活但需要边界指定

  2. 如何度量参数化质量？

    • 保角扭曲
    • 保面积扭曲
    • 等距扭曲
    • 翻转检测

五、本系列的定位与目标

5.1 写作目的

  1. 记录与分享

    数学是美的，美丽的风景值得被画下来。本系列尽可能用少而深刻的数学概念，勾勒出曲面参数化的理论图景。

  2. 为后来者铺路

    就像当年学习图形渲染时，冯乐乐的博客给予我巨大启发一样，我希望将离散几何的知识传递下去，为后来人提供一个攀登知识高峰的阶梯。

5.2 本系列的作用

  1. 直观理解抽象概念

    通过非常直观、可操作、可玩的方式，将大学到研究生阶段的专业数学知识串联起来（复分析、微分几何、凸优化）。读者可以借助本系列对相关知识有非常直观的理解，从玩中学。

  2. 理论与实践结合

    带领大家动手编写程序计算，通过工具观察，推导公式。代码与公式相互印证，让抽象的数学落地。

  3. 通往前沿的阶梯

    通过对本系列的学习，掌握相关知识后，可以进一步学习顾险峰老师更深入的理论（计算共形几何、最优传输），从而到达时代前沿的数学知识。

九、开始之前

在开始本系列之前，建议读者具备以下基础：

  • 线性代数：矩阵运算、特征值问题
  • 微积分：多元微积分、偏导数
  • 编程能力：熟悉 Python 或 C++
  • （可选）复分析：全纯函数、柯西-黎曼方程
  • （可选）微分几何：曲面论、基本形式

如果某些基础薄弱，也不必担心——我们会在需要时进行补充讲解。

让我们开始这段旅程，一起探索曲面参数化的美妙世界。
