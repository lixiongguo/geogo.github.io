## 2D 交互水面

本 demo 用**二维波方程**在规则网格上模拟水面高度场，支持鼠标/触摸制造涟漪，以及**浮球与波面的双向耦合**（浮力、坡度推力、反作用涟漪）。

与 Gallery 中的 [WebGL 水面焦散](/gallery/WebGL%20Water.html) 不同：这里是纯 Canvas 2D、俯视水面 + 法线着色，侧重**快速交互**与**刚体-流体简化耦合**，而非 3D 折射焦散。

---

### 波方程离散

将水面高度记为 $h(x,y,t)$。在均匀网格上用** Verlet 型**差分近似二维波动方程：

$$h^{n+1}_{i,j} = \frac{h^n_{i-1,j}+h^n_{i+1,j}+h^n_{i,j-1}+h^n_{i,j+1}}{2} - h^{n-1}_{i,j}$$

每步乘以阻尼 $\gamma \in (0,1)$ 模拟能量耗散。边界格点固定为 0（固壁）。

| 参数 | 作用 |
|:---|:---|
| **波速** | 缩放 $\Delta t$ 等效步长，越大 ripple 传播越快 |
| **阻尼** | $\gamma$ 越大，波纹消失越快 |
| **扰动** | 点击/拖拽注入的高斯 bump 强度 |

---

### 交互

| 操作 | 效果 |
|:---|:---|
| **点击** | 局部抬高水面，产生圆形涟漪 |
| **拖拽** | 连续注入扰动，可推起波浪 |
| **点中浮球** | 给球初速度，并激起水花 |
| **雨滴** | 随机落点持续扰动 |
| **重置** | 清空高度场与球速度 |

---

### 浮球物理（简化）

每个浮球有归一化位置 $(x,y)$、速度 $(v_x,v_y)$ 与半径 $r$。每帧：

1. **采样波面**：在球下 disk 内平均高度 $\bar h$，估计浮力 $F_y \propto -\bar h$
2. **坡度力**：有限差分 $\partial h/\partial x,\partial h/\partial y$，球沿坡向加速
3. **阻尼与池壁反弹**
4. **反作用**：球对局部 grid 施加负向 splash，模拟排开液体

球在渲染时随局部 $h$ **上下 bob**，阴影与高光随位置变化。

---

### 渲染

由高度场梯度算法线 $\mathbf{n} \propto (-\partial h/\partial x,\,-\partial h/\partial y,\,1)$，再与固定方向光做点积得到漫反射 + 高光，得到类似浅水池的蓝色调。浮球用径向渐变绘制在波面之上。

---

### 局限

- 线性波方程，无破碎、飞溅真实流体
- 浮球为 2D 简化模型，非刚体全耦合
- 分辨率 $180\times135$，大扰动时可能有轻微数值反射
