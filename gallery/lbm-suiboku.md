## LBM 水墨动画

水墨画的视觉本质是**墨水在水中的扩散与流动**。本 demo 用 D2Q9 LBM 提供速度场，墨水浓度用**标量场**在平流-扩散方程下演化，模拟落笔、晕染与提笔后的静止晕开。

---

### D2Q9 流体（速度场）

二维 D2Q9 在每个格点追踪 9 个方向的分布函数 $f_i$，宏观密度 $\rho$ 和速度 $\mathbf{u}$ 由矩求得：

$$\rho = \sum_i f_i, \quad \rho\mathbf{u} = \sum_i \mathbf{c}_i f_i$$

采用 **pull scheme**（先沿格点拉取邻域分布，再 BGK 碰撞），边界用 bounce-back，比 collide-then-stream 更稳定：

$$f_i^{\text{eq}} = w_i\rho\left[1 + 3(\mathbf{c}_i \cdot \mathbf{u}) + \frac{9}{2}(\mathbf{c}_i \cdot \mathbf{u})^2 - \frac{3}{2}\mathbf{u}^2\right]$$

每步后对速度场施加衰减，避免余流长期搅动墨水。

---

### 墨水标量场（浓度 $C$）

墨水**不再**用第二套 LBM 分布函数 $g_i$ 求解（见下方「问题记录」）。当前实现：

$$\frac{\partial C}{\partial t} + \mathbf{u} \cdot \nabla C = D_{\text{eff}} \nabla^2 C$$

| 步骤 | 做法 |
|:---|:---|
| **平流** | 半拉格朗日回溯：$C(\mathbf{x}) \leftarrow C(\mathbf{x} - \mathbf{u}\,\Delta t)$，双线性插值 |
| **扩散** | 五点拉普拉斯显式扩散，系数 $D_{\text{eff}} = D \cdot (0.35 + 0.65\,C)$ |
| **注入** | 鼠标落笔向 $C$ 直接加墨，并沿笔触方向给局部速度脉冲 |
| **渲染** | $t = \bigl(1 - e^{-4.2C}\bigr)^{0.78}$，灰度 $252 - 228t$，避免硬裁切为纯黑 |

**提笔后**：扩散系数降为落笔时的约 28%；流速接近零时跳过平流插值，减少数值耗散导致的「越晕越淡」。

---

### 控制参数

| 参数 | 效果 |
|:---|:---|
| **粘度** ($\tau$) | 流体弛豫时间；越大流速衰减越快、墨迹越「定」 |
| **扩散** ($D$) | 晕染速度；越小墨心保持越久 |
| **笔触强度** | 单次落笔注入浓度与笔锋半径 |

---

### 水墨效果

- **笔触**：拖拽落笔，墨迹随流体自然扩散
- **晕染 (Nijimi)**：适当扩散 + 流体搅动 → 边缘晕开
- **叠加**：多层墨迹在浓度上限 $C \le 1$ 内叠加产生浓淡变化

### 问题记录（开发与调参）

#### 1. 提笔后墨团变黑块（原始 bug）

**现象**：每次落笔再提笔，墨迹中心逐渐变成不自然的浓黑团块。

**原因（多重叠加）**：

1. **主循环仅在 `drawing === true` 时步进** — 提笔后模拟冻结，高浓度墨停在落笔点无法继续扩散，视觉上像「凝固的黑斑」。
2. **墨水用 $g_i$ BGK 被动标量** — 在浓墨、高梯度区域，$\tau_g$ 接近稳定性下限时 BGK 易产生数值振荡与局部堆积。
3. **注入过强**（原 `×1.8`）+ **线性渲染硬裁切** — 浓度快速饱和后显示为纯黑。
4. **边界 stream 的 bounce-back** — 边界格点反射分布，与上述问题叠加时局部浓度更易异常。

**第一次修补（效果更差）**：持续模拟 + `DYE_CAP` 钳制 + 减弱注入 + 柔和 tone mapping。黑块减轻，但整体偏淡、晕染不自然，用户反馈「好像更差了」。

#### 2. 架构调整（当前方案）

**思路**：流体仍用 LBM 求 $\mathbf{u}$；墨水改为**标量场 $C$** + 半拉格朗日平流 + 显式扩散。

- 去掉 $g_i$ 分布函数与 `clampDyeField` 等补丁逻辑
- 每格 $C \in [0,1]$ 硬上限，从物理量层面防止 blow-up
- pull-scheme 流体 + 速度衰减，落笔时沿笔触注入速度

**结果**：提笔后墨迹能自然晕开，黑块问题消除。

#### 3. 墨迹偏淡

**调整**：提高注入系数（`0.22 → 0.32`）、加强渲染对比（`exp(-d·2.8) → exp(-d·4.0)`）、默认笔触滑块略增。

#### 4. 静置后淡化过快

**现象**：停笔一段时间后，笔画整体变淡、墨心被冲散。

**原因**：拉普拉斯扩散使浓度从峰向周围摊薄；半拉格朗日插值在有余流时带来额外数值耗散；随机速度扰动延长搅动时间。

**调整**：

| 项 | 改动 |
|:---|:---|
| 默认扩散 | `diffK` 降低，滑块默认 5 |
| 提笔后 | 扩散 ×0.28 |
| 非线性扩散 | $D_{\text{eff}} \propto (0.35 + 0.65C)$，浓墨区更抗扩散 |
| 低速跳过平流 | $\|\mathbf{u}\| < 0.015$ 时不做回溯插值 |
| 速度衰减 | `velDamp` 0.965 → 0.92，余流更快静止 |
| 渲染 | 低浓度 gamma 0.78，淡墨仍可见 |

### 实现要点（`lbm-suiboku.html`）

```
主循环 (!paused):
  stepFluid()   // D2Q9 pull + 速度衰减
  stepDye()     // 半拉格朗日 + 扩散（提笔后降扩散）
  render()      // tone mapping 出图

落笔:
  inject() → C += 墨量, ux/uy += 笔触方向脉冲
```

格点分辨率 `200×150`，与画布等比映射；模拟在 `requestAnimationFrame` 中每帧 1～2 子步。
