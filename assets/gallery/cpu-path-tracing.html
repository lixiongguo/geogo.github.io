本页为浏览器内 渐进式路径追踪，场景布局与材质角色对齐仓库 cpp/CPUPathTracing/src/main.cpp：四尊「主体」+ 镜面小球 + 无限地面 + 环境光（此处用程序化天空近似 EXR 无限光源）。 场景现在由 assets/renderer/Scenes/*.json 描述（可包含相机、天空、地面、球体、OBJ 网格与材质）， 渲染器会按 JSON 动态加载并追踪；大网格会自动抽样并构建简易 BVH 加速。 因静态站无 buddha.obj / HDRI 资源，主体用大球体代替三角网格 Buddha；BSDF 含余弦漫反射、理想镜面、Schlick 电介质、粗糙金属（GGX）。 完整 BVH / MIS / 与 C++ 逐位一致需在本地编译 CPUPathTracing 输出 EXR。
