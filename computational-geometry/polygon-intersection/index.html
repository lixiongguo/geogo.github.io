凸多边形相交检测实验（扫描线算法）

算法说明

扫描线算法（Sweep Line Algorithm） 用于检测多边形相交，核心思想是"降维"：将二维问题转化为一系列一维问题。

算法步骤：

  1. 将多边形的所有边按端点排序
  2. 使用扫描线从上到下（或从左到右）扫描
  3. 维护当前扫描线与多边形边的交点列表
  4. 当扫描线遇到边的端点时，更新交点列表
  5. 检查相邻交点之间的区间是否来自不同多边形

时间复杂度：O((n+k) log n)，其中 n 是边数，k 是交点数。
